# bloodSimulator

一个以“心”为主题的东方 Game Jam 项目：操控细胞尺度的微型机器人，在血管中穿行、清除病原体与病变组织，并尽量避免损伤正常组织。

项目名暂定。设定背景为永远亭医疗设施与爱丽丝的无人机，人物、剧情和过场之后再细化。

## 当前状态

目前处于前期设计阶段，仓库只有设计与工程计划，尚无可运行的游戏、Godot 工程或 Rust 模拟内核。

- [设计草案](docs/superpowers/specs/2026-10-19-blood-simulator-design.md)：已确认的玩法、模拟范围、技术边界及待决事项。
- [首轮工程计划](docs/superpowers/plans/2026-10-19-engine-foundation.md)：工程接通、软体实验场和网络驱动的实施顺序。

## 游戏方向

- 2D 抽象血管网络，保留心脏与核心器官的循环关系，空间尺度按玩法压缩。
- 机器人略大于红细胞，以自由移动为主；血流轻微推动机器人，红细胞交通带来逆行、推挤和堵塞。
- 同时包含刺击与射击。软体细胞参与碰撞，让战斗与交通相互干扰。
- 免疫细胞起初对机器人中立；感染、局部损伤和机器人的攻击触发不同反应。
- 每关经历若干次循环，完成治疗目标后从指定地点撤离，目标时长为 10–20 分钟。
- 机器人被毁或累计正常组织损伤达到上限时失败；关间有升级与过场。

## 技术方向

采用 **Rust 模拟内核 + Godot 表现层**，通过 GDExtension 接入。

| 部分 | 职责 |
| --- | --- |
| Rust 模拟库 | 物理状态、Rapier 接触与软体、血管网络、局部流场；后续加入命中与受力 |
| Rust 接入层 | 将 Godot 输入转换为模拟输入，将模拟结果转换为显示数据 |
| Godot | 输入采集、绘制、场景、声音、界面与调试显示 |

同一物体只由 Rust 一侧推进物理，模拟库不依赖 Godot。

血流先采用 **0D 集总参数网络 → 局部二维流场 → 细胞运动** 的单向驱动。全局网络求压力与分支流量；初版局部使用简化速度场。二维流体求解、细胞对流场的反馈及堵塞对全局网络的反馈分别研究，不作为首轮工程的完成条件。

优先验证 Rapier 原生二维软体能否满足细胞挤压、通过窄口和恢复形状的需求。具体依赖版本及效果仍待实编译和实验确认。

## 首轮工程范围

1. 接通 Rust、GDExtension 与 Godot，提供构建和运行入口。
2. 制作一个含分岔、收窄通道、软体红细胞及可控机器人的物理实验场。
3. 加入小型血管阻力网络和单向速度场驱动。
4. 随工程提供暂停、单步、重置、基础参数与性能显示。

关卡、敌人种类、战斗实现、完整器官地图、剧情和成品美术暂不进入这一轮。

## 开发与验证

尚无构建或运行命令。工程接通时将补充经过实际验证的步骤，并锁定依赖。

开发环境调查记录：Linux x86_64、Rust/Cargo 1.98.1、Godot 4.7.1。这是本机工具记录，不代表已经验证的兼容组合或正式最低版本。

按改动运行必要的已有检查。新增测试围绕具体行为和物理不变量；页面与画面验证以截图为主，操作手感由人工体验。不默认增加浏览器交互测试或大规模 CI。

## 制作约束

三周、单人制作，优先发挥引擎和物理模拟优势。美术与声音尽量采用程序化方法及许可明确的免费素材；生物、医学图像可用于参考或纹理，使用时记录来源与授权条件。

本项目采用生物学启发的游戏规则与二维近似，不用于医学判断。
