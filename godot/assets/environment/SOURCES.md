# 背景纹理来源

`tissue.png` 与 `endothelium.png` 由内置imagegen基于项目已认可的 `docs/art/microscopy/style-reference.png` 生成；是游戏美术材质，不是真实显微照片裁切。没有新增第三方图像像素来源。

- `tissue.png`：提示制作外围结缔组织方形纹理，无血管、管腔、血细胞或文字；米白/暖灰米色和极弱灰紫，低对比交织半透明纤维、斑驳基质、稀疏梭形细胞核。均匀光照，不做3D、亮粉色或聚焦构图，要求四边可平铺。
- `endothelium.png`：提示制作横向可平铺的单排4～5个内皮细胞，浅米白暖灰与灰紫细胞核，扁长不规则轮廓、柔和细胞连接、细微斑驳，无血液、管腔或文字。实际输出细胞排位于中央，渲染仅取V=0.45～0.55的纹理带。

生成工具请求了无缝，但尚未做逐像素接缝验收；已查看实际普通与分块场景截图。PNG保持原始生成文件，没有覆盖已确认的细胞纹理。


## 管腔内部纹理

`lumen.png` 通过内置imagegen从文字生成，无外部参考图片。提示：制作暖白浅桃红、接近#F2E2DA的低对比管腔背景，宽缓不规则透射光明暗，约6～10%亮度差及极细摄影颗粒；保持清透、低对比、没有明显重复图案，四边可平铺。明确排除组织纤维、细胞、核、膜、气泡、水波、流向、尖锐云团、暗角、反光、文字与3D效果。作为游戏艺术化背景，不能称真实血浆照片。渲染时再与原底色混合以控制强度。
