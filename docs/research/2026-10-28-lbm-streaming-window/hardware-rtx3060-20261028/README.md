## 已确认的原因

用户要求全新、独立的 Sol high 子代理调查。[独立报告](independent-investigation.md)确认：当前低 lattice 黏度／MRT 松弛参数下，固定速度出口重建存在增长的横向边界模。出口通量仍可精确匹配目标，但内部扰动逐步放大并产生负密度。

- 移除所有机械耦合后，四个生产 API 基准的失败帧与实卡逐一相同；冻结压力也会失败。
- 仅切回周期边界，或仅将出口改为固定密度重建，2240 步控制均完成。
- 独立线性分析预测增长率 `1.059363489`；向临时生产 WGSL 副本注入同一模后，实测每步增长 `1.05936214`。
- 简单的出口局部应力正则化仍会失败，不能视作已验证修复。

先前实卡研究的 x 边界是周期回绕，未验证正式窗口新增的固定速度出口。当前没有同时保持各开口精确目标通量、并通过稳定性验证的生产修复；固定密度出口仅为因果控制，它会改变流量边界契约。生产代码、参数和默认配置均未因本次调查改变。

## 复现与验真

原始结果的 18 个文件哈希、源码包和二进制哈希已核对。可在本目录执行 `sha256sum -c results-manifest.sha256`。`investigation/` 保存独立调查的最小源码、日志和模式输入；在该目录执行 `sha256sum -c artifacts-manifest.sha256` 可核对归档。

独立报告记录了原始命令和临时路径。复现时将 `investigation/` 内容放回 `/tmp/lbm-independent-sol-20261028/`，按报告先构建项目 release 依赖，再用相应 `.rlib` 路径编译诊断程序。`.rlib` 哈希文件名可能随编译器或构建环境改变；模式输入路径由诊断程序固定到上述临时目录。这些诊断模块仅用于研究，不属于生产 crate 依赖，也不是新增永久测试。

实例 `57988490` 已在取回并校验结果包后停止，`final-stop-status.json` 确认 `cur_state: stopped`、`actual_status: exited`；磁盘保留，存储费用可能继续产生。独立调查只使用本机临时诊断，没有重新启动云实例。
