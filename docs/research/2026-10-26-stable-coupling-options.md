## 推荐

**优先实验“点力欠松弛，每个机械子步一次完整 Stokes 求解”。** 它与目前失败的反馈映射直接对应，新增的主要数据只是上一子步的点力；固定几何下保持原来的自洽解作为目标。若稳定性或动态误差仍不合适，再研究有限次校正或以上一子步点力作初值的 CG。

目前不优先建设 Aitken/Anderson 历史加速框架、逐细胞精确响应矩阵或新的网格联合求解器。它们有成熟依据，但在本项目里仍需证明额外成本值得付出。

## 已有证据

[密集64细胞实验](2026-10-26-stokes-64-cells.md)中，一次更新方案在基线/优化、串行/四线程都于第16帧停止。冻结几何、不运行 Rapier 后，64细胞扰动交替放大，最后几次范数比约1.82053；16细胞布局则约0.47874。故本轮重点是有限阻力的迭代反馈，不能直接把它归为固体惯性造成的附加质量失稳。

已有自洽参照可完成相同64细胞场景。重新读取其第31–360帧：平均每帧约17.397次点力 CG 迭代、21.397次完整 Stokes 调用；流体阶段均值36.985ms，Rapier阶段3.812ms，整步40.922ms。每帧有两个机械子步，因此每子步约8.7次点力 CG。固定标记速度下的流体闭合不等于 Rapier 质量、弹性和接触也做了联合隐式积分。

## 1. 点力欠松弛为何值得试

记 `K` 为完整 Stokes 速度响应，`J` 为格点到标记的速度插值，`S` 为标记力的散布，`R` 为各点阻力的对角矩阵。冻结几何、目标速度和背景力，令 `u₀=K f₀`，则目标方程为：

```text
u = u₀ + K S F
F = R (V − J u)
(R⁻¹ + J K S) F = V − J u₀
```

当前一次更新直接取 `F_next=R(V−Ju_old)`。对于同一固定算子且旧场由旧点力生成的情况，力误差满足 `E_next=−M E_old`，其中 `M=R J K S`。

候选更新为：

```text
F_trial = R (V_current − J_current u_old)
F_new   = (1 − ω) F_old + ω F_trial
u_new   = K_current (f₀_current + S_current F_new)
```

Rapier 接收同一 `−F_new Δt`，仍按当前标记的机械插值权重回传。正常连续推进时，每个机械子步仍只做一次完整 Stokes 求解；背景初始化按现有口径另计。

在固定几何条件下，上式是阻尼 Richardson 型更新，力误差变为：

```text
E_next = [I − ω (I + M)] E_old
```

这是对当前模型的推导；预条件 Richardson 的通用更新形式也可见 [PETSc 官方说明](https://petsc.org/release/manualpages/KSP/KSPRICHARDSON/)。在精确离散 Stokes 响应、正阻力和伴随插值/散布下，`M` 与一个对称半正定算子相似。若全部特征值非负，固定算子所有模态收缩要求 `0 < ω < 2/(1+λ_max)`。

**已有1.82053只是所激发方向的观测范数比，不是严格的最大特征值。** 将该交替主导方向近似看成 `λ≈1.82053` 时：

| ω | 该模态预测的误差乘数 |
| ---: | ---: |
| 1.0，现有未松弛更新 | −1.82053 |
| 0.5 | −0.41026 |
| 0.3 | +0.15384 |

因此0.5有明确的实验动机，但不能宣布它对移动、接触或更密布局必然稳定。0.3对这个模态更强抑制，不代表所有模态收敛更快；接近零的模态会分别保留0.5和0.7倍误差。

### 保留什么、付出什么

- 固定点、固定驱动下的目标仍是原 Γ=0.25 的自洽方程；改变的是逼近目标的更新方式。
- 以同一份 `F_new` 作用于流体和细胞，可保留离散合力和节点/标记力矩的一致性。当前 `J/S` 的空间伴随关系也不需改变。
- 每个标记需保存上一子步点力，并保持身份对应；本轮64细胞共256标记，二维 f64 力本体约4KiB。当前固定对象实验可直接沿用顺序，尚不设计区域切换或对象增删的历史转移机制。
- 力包含数值历史，会引入响应延迟；当前新场一般仍不严格满足 `F_new=R(V−Ju_new)`。应继续报告 RMS、最大单点闭合残差和与自洽参照的轨迹差。
- 等量反作用不等于严格耗散。欠松弛后的力与当前相对速度可能暂时不同向，`F_new·(Ju_new−V)` 未必总为非正，不能只凭合力守恒宣布稳定。
- 移动标记或变化背景下，`u_old` 通常不等于用当前几何从 `F_old` 重建的流场，冻结误差式不再精确。真正判断还需动态对照。

不建议只平滑新流速、却把未平滑的力回传给 Rapier：这样显示/求解场与机械反馈不再来自同一批界面力。候选直接混合点力，然后用当前散布算子求新场，口径更清楚。

## 2. 其它候选与取舍

| 候选 | 流体调用成本与优点 | 主要限制 | 次序 |
| --- | --- | --- | --- |
| 固定点力欠松弛，一次更新 | 正常每子步1次完整 Stokes；改动较小，针对已观测交替放大 | 动态滞后、闭合误差，权重未验证 | 首选小实验 |
| 冻结当前子步状态，做2次松弛校正 | 每增加一轮约再做1次完整 Stokes；可减少同一步残差 | 不保证2次就足够，预算近似增加 | 单次稳定但误差偏大时再试 |
| 上一步点力初值＋CG | 保留可检查的残差；缓慢变化时可能减少迭代 | 当前几何的真实初始残差也需流体解；固定轮数不是收敛保证 | 第二条主要候选 |
| Aitken / Anderson / IQN | 根据历史残差选择更新，可加快或稳定某些耦合迭代 | 需要更多历史、最小二乘或参数管理，当前没有本项目收益证据 | 暂缓 |
| 网格上联合有限阻力方程 | 消除外层点力与流体反复交换，保留同一个有限阻力模型 | 新的较大鞍点系统及预条件路线，工程工作更多 | 单独研究路线 |

preCICE 官方提供固定欠松弛、Aitken 和拟牛顿加速，说明这些是常见的耦合工具，但其推荐场景和参数不构成本项目的稳定保证；也没有建议安装 preCICE。[官方配置说明](https://precice.org/docs/configuration/basics/acceleration/)

Anderson 使用残差历史和最小二乘组合；在线性问题上与 Krylov 方法存在联系，其实际实现还需考虑历史矩阵条件。这是为何目前不优先加入完整历史加速机制。[Walker 与 Ni，2011](https://users.wpi.edu/~walker/Papers/Walker-Ni,SINUM,V49,1715-1735.pdf)

### CG warm start 的实际账目

当前实现每次从零点力起步；一次完整自洽求解大致是“背景流1次＋每次CG迭代1次＋最终场1次”。从旧点力起步后，在当前几何计算真实初始残差通常还要多做一次 `K S_current F_old`。背景可复用或已知为零时能够省掉背景求解，但不能把旧几何的流场当作当前几何的精确残差。

因此应先在原容差下测旧点力初值能省多少迭代，再讨论有限轮数和适度闭合容差；不能先把“只做两次 CG”称为可靠自洽解。每次额外 matvec 仍是完整 Stokes 求解。沿用非零初值是常见求解器能力，是否有利取决于问题变化与实际残差。[PETSc 初值接口](https://petsc.org/main/manualpages/KSP/KSPSetInitialGuessNonzero/)

局部自响应或每细胞8×8块预条件可以处理一部分局部作用，但不能自动消除已观测的集体反馈。用完整流体响应逐列精确建立64个8×8块，朴素做法需512次完整响应；当前没有理由先付这笔成本。

### 网格联合路线

将点力代入流体动量方程，可得：

```text
(A + S R J) u + G p = f₀ + S R V
D u = 0
```

它与当前有限阻力模型相同，但需要处理新的速度—压力块系统。已有块预条件/多重网格 Stokes 方法和约束浸入边界方法可作参考，不能直接承诺实时成本。[Cai 等](https://arxiv.org/abs/1308.4605)、[Kallemov 等](https://arxiv.org/abs/1505.07865)

这里的有限秩标记拖曳与旧实验的高强度体积惩罚不相同；旧实现慢不能直接否定这个候选，也不能据方程更整齐就认定它更快。
