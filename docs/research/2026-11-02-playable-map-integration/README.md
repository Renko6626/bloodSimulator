## 单位统一图结果

[unit-graph.csv](unit-graph.csv)直接由生产GraphNetwork、默认黏度0.05、全局drive=1生成69条真实边数据。泵边7的Q=3.393265724，最大节点f32守恒残差1.7881393e-7，所有压强/流量有限。没有采用旧Q48/烘焙域，没有确定新图最终Q或压差，也没有把结果接入runtime。

符号按实际边from/to；负流边为14–20、31、34、47–55，表示相对绘制方向反向，不作异常或修改方向。绝对Q低于泵Q的1%：32（0.4707324%）、35（上D3，0.2397576%）、46（0.4089145%）、55（-0.4844286%）、63（B D3，0.0654821%）、68（0.9481806%）。保留低流，不强制同径均流。

肺下口北路边29 Q=0.647272527（19.0752089%），南路边30 Q=0.825693905（24.3333116%），合计43.408519%；其余56.591481%继续肺中上部。分母是串联循环泵Q，未将肺出/肺回绝对值相加。Q/D只是平面通量诊断，不能当作心腔实际速度或已校准流场。
