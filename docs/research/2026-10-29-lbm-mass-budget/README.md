精确恒等式 `ΔM = ΣΔbulk + Σjn2 + Σ(B1−C1) + Σ(Δtangent+2Δknown_out)` 闭合。整个重建增量3.027500078包含正常开放交换，不能直接叫泄漏。微观link交换与宏观J也不能混同：重建改写渠道分别为incoming +4.746090585、known_out +1.719857239、tangent −3.438447746，存在明显抵消；同一rho下unknown-only与all9的当步总质量相同，known项非零不能独立判因。
