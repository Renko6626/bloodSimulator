# 固定分叉窗口试接结果

2026-10-26。用户批准固定 64² 窗口、带状 Cholesky 速度逆、压力 Schur-CG 和自然牵引开口后完成数值原型。**数值检查通过，但实际一步约 59 ms，当前不适合设为默认实时场景，按已确认设计停在显式数值入口。**

后续用户批准[稀疏速度分解实验](2026-10-26-stokes-sparse.md)：匹配短测整步降至 22.11–26.65 ms，并补充独立速度逆计时。以下保留初次带状试接的历史结果和当时未验证项，最新状态以该后续报告及状态文档为准。

## 与此前六毫秒实验的差异

此前 5.92–6.06 ms 是规则周期直管的整步耗时，包含约 3.56–3.66 ms 流体。该结构允许沿 x 做 FFT，每个 Fourier 模式只解一维三对角问题，并使用固定壁面的快速压力作用。

真实分叉引入斜壁阶梯遮罩、开放边界和半控制体，原可分离速度逆不再适用。本次采用已确认的带状分解处理实际速度矩阵，每次前回代要访问更宽的非零带。新的压力 Schur 系统收敛也更慢：此前优化轨迹平均约 7.02 次压力迭代/帧，本次约 37.33 次/帧。每次压力迭代都要调用一次速度逆；加上两个子步的初始残差与最终速度求解，实际约从 13 次速度逆/帧增到 43 次/帧。

两项变化叠加，抵消了原专用解法的速度优势。同为 64² 不代表相同的线性代数成本。两组轨迹时长和几何不同，不把上述阶段数据当作严格同场景的加速倍数；本次结果也不能用消费级 CPU 的可能单核优势直接折算为此前 6 ms。

## 速度逆的含义与成本

将黏性及壁面约束写为速度算子 A，忽略离散权重和边界载荷的记号差异，动量方程可以写为 `A u = f − Gp`。速度逆指给定受力和压力后求解这组方程，即应用 `A⁻¹` 得到整片速度。程序用分解后的前回代求解，没有显式存储完整逆矩阵。

黏性将相邻位置的速度关联起来，单个位置的受力会影响其他位置；这是一个全域线性子问题。初始化预分解只省去重复分解矩阵的开销，每次受力或压力修正变化后，仍需执行前代和回代。当前每个速度分量有 2,458 个未知量，因子带宽约 58/57，每轮需要反复访问整条非零带。

压力迭代要评估“压力修正如何改变速度及流量收支”，所以每次 Schur 算子作用都调用一次速度逆。当前两个机械子步各有一次初始受力速度解、一次初始压力残差作用及一次最终速度解。因此，正常每帧速度逆调用数为“压力迭代总数 + 6”；约 13 次与 43 次的对比由代码调用结构和迭代统计推算，未新增逐次计时埋点。

实现入口见[速度逆与压力迭代](../../crates/simulation/src/fluid/grid.rs)和[带状前回代](../../crates/simulation/src/fluid/linear.rs)。流体阶段的 48.336 ms 还包含标记准备、散布、向量操作与诊断，目前没有单独量化速度逆的净耗时，不能将这整个数值都归给前回代。

## 分叉段待解决的问题

1. **真实几何下的快速速度求解。** 周期直管的 FFT/Thomas 利用了平直、可分离结构；当前分叉遮罩、固壁和开口改变了算子。带状 Cholesky 能给出满足检查的解，运行成本仍偏高。后续需要保留真实边界条件，评估怎样降低速度子问题成本；约 59 ms 是当前实现的实测结果，不是一般 Stokes 方法的性能下限。
2. **压力系统的迭代成本。** 当前每帧约 37.33 次压力迭代，且每次嵌套速度逆。真实边界下的收敛和速度逆成本必须分别考虑。旧直管与新窗口的驱动、初值及统计窗口也不同，当前数据不足以把全部迭代增量归因于分叉几何，或精确分摊两项原因造成的耗时。
3. **二维局部场与血管网络的衔接。** 开口采用外部压力自然牵引，局部流量由求解结果决定，没有同时强制网络的全部压力和流量。圆管网络与二维平板的压力缩放只经过直管均速匹配；分叉的各开口流量比例、窗口外围混合场及细胞分流体验仍待验证。局部原始场的散度检查不代表混合后的全地图速度场严格无散度。
4. **真实跟流和近壁行为。** 阶梯壁面具有几何近似误差；每细胞四内部阻力点仍允许透流。弱耦合 Γ=0.25 与原速度松弛率 20 的响应不同，现有一秒结果不能证明跟流手感、长期通行或密集堵塞符合游戏需求。不能仅通过放大拖曳系数假定问题已解决。

本轮已经明确的是：真实分叉能够数值求解、默认参数短测没有明显数值异常，但当前成本不支持默认实时接入。尚未完成单次速度逆的独立分段计时、同口径的几何／边界对照及长期动态验收。预条件器、多重网格、其他速度逆或边界近似只是后续待选择的方向，未据此启动实现；新算法和依赖仍需展示取舍并取得确认。

## 当前停点与后续交接

保留 `Simulation::new_local_world` 和 `circulation_probe ... local` 供显式数值验证，Godot 默认世界继续使用网络解析驱动。固定窗口范围、带状速度分解和自然牵引方案已经批准，后续无需重复询问这些既定选择；进一步更换求解路线需要另行确认。

此前用户接受的约 6 ms 仅对应周期直管候选。服务器和消费级 CPU 的差异没有目标设备实测，不能用硬件推测代替真实分叉的性能验证。后续优先依据当前原始记录区分速度逆单次成本与压力迭代次数，再提出有界方案，不自动扩大为全面求解器重写或大规模验证。

## 实现范围

- 在 `simulation::fluid` 内构建中心 (-14,0)、边长 16、64² 固定域，来自现有地图及墙厚；2,484 个压力格、两个速度分量各 2,458 个未知量，速度带宽约 58/57，因子约 2.2 MiB。
- 对速度半控制体统一黏性能量和压力／散度面通量；开口使用外部压力自然牵引，拒绝无开口的流体连通块，不沿用周期压力去均值。
- 每子步一次局部反馈，单位泵压背景场预求，四内部标记与机器人反冲量、窗口外解析驱动按权重分摊。
- 应用生命周期复用四线程 Rayon 池，启用 Rapier parallel；u/v 分量的速度逆并行计算。重置保留数值原型场景，不重复初始化全局池。
- `Simulation::new_local_world` 和现有 circulation probe 的 `local` 模式显式调用。Godot、bridge 和默认入口没有切换到该窗口。

## 短时测量

共享 Xeon Gold 6330，release、锁定离线依赖、同插槽物理核 CPU 2–5、共用研究文件锁。各 72 个细胞、60 步、1 模拟秒，包含初始动态反馈，不包含构造、快照和绘制；没有剔除热身帧。初始化单列。p95 沿用探针的排序口径。

| 场景 | 初始化 ms | 整步均值 / p95 ms | 局部流体均值 / p95 ms |
| --- | ---: | ---: | ---: |
| 固定分叉窗口 | 239.6 | 59.249 / 74.862 | 48.336 / 62.337 |
| 原解析世界对照 | 153.4 | 8.376 / 9.414 | 无 |

窗口内仅 3–5 个细胞参与反馈，另含机器人；该成本不能归因于活跃细胞达到 64 个。未固定核心的初测整步约 60.08 ms、流体约 48.74 ms，固定核心后的结果接近，因此本次差距不能主要解释为线程落点。

这次短测没有足够证据细分各项净耗时，但重复带状速度逆及压力迭代是明确的后续审阅对象。若继续，应先选择和验证真实边界下的快速求解方案，不能直接沿用周期直管的性能承诺。

## 数值与审阅

新增三个生产逻辑检查通过：直管解析流量及压力平移；等压静止、封闭域拒绝；真实分叉的真残差与开口净流量。原暂停／单步／重置检查扩展到局部场景，检查反冲量、残差和模式保留。

短测最大面积偏差约 1.22%，未观察到粒子越壁；最大交换冲量误差约 `3.85e-10`。帧末子步的散度 RMS 最大约 `3.39e-9`、动量 RMS 约 `2.44e-14`、开口净流量约 `4.46e-8`。残差与净流量由每帧最后子步快照统计，不能作为所有子步的最大值。仅一秒不能证明持续拥堵、长时稳定或操控手感。

一次只读代码审阅未发现阻止保留数值原型的 Critical/Important 问题；确认了 A 装配、D/G、反冲量、驱动顺序及重置线程池。审阅指出上述残差采样口径，已在此明确，未扩大验证范围。

`bash scripts/check.sh` 最终退出码 0：格式、workspace 编译、7 个单元测试、5 个集成测试、扩展构建及世界／lab 场景无界面导入与短时启动通过。首次沙箱内执行时 Godot 无法写入用户配置／日志并崩溃；获准在沙箱外重跑后通过，没有改动求解代码来规避该环境问题。没有自动输入或 UI 交互。
