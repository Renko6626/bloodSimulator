# 六次采样候选的进一步 profiling

2026-10-27。用户接受六次解析采样近似后，要求继续 profile，定位待优化位置。本轮只增加独立测量，不改变算法、材料、容差、更新频率或正式入口。

后续用户已批准并完成[几何查询复用](2026-10-27-geometry-query.md)，两轮解析驱动均值约减少 1.1 ms，保存输出一致。以下保留优化前 profiling 及当时建议，避免混用计时口径。

## 测量对象与范围

固定真实分叉、72 细胞、每细胞 12 个物理节点、六次解析流速采样并插值、零拖曳查询跳过、局部四个内部流体标记、稀疏 Cholesky + 压力 CG 参数 `1e-4`。默认无操作输入，每帧两个机械子步。

复用已归档研究输入，构建临时副本。各 30 秒、1,800 帧，前后各一条关闭深层计时的控制轨迹，中间分别运行几何、流体、Rapier 内部计时轨迹。固定 CPU 2–5，四线程、release、offline、共享研究锁，不剔除初始帧。几何和流体不在同一轮同时计时，减少细分埋点相互干扰。

服务器 `perf_event_paranoid=4`，实际执行 `perf stat -e task-clock true` 被系统拒绝。本轮未改 sysctl 或申请额外权限，使用 Rust 定时埋点和 Rapier 已有的 `profiler` 功能。后者仅在独立诊断构建启用，诊断锁文件另存，原工程依赖与锁文件不变；已有包版本不得改变。

## 口径

- 深层计时仅在 `Simulation::step_inner` 期间启用，退出前关闭，快照、绘制、探针几何检查和 CSV 写入不计入热点。
- 几何记录解析查询、最近管段、带符号距离、管段投影、管长、路口搜索与混合。混合包含部分投影／管长，不能重复相加。
- 流体记录标记准备、散布、网格求解、场合并、诊断与反冲量；Schur、速度逆、梯度、散度和残差测量存在嵌套。
- 稀疏分解中的重排、前代、回代和恢复记录两个并行分量的耗时和，不是帧墙钟。每次速度逆另保存两个分量较大耗时，逆总时间减去其和的余量包含调度、等待、拼接与计时等，不能全部称为线程开销。
- Rapier 内部计时依其现有覆盖范围；部分并行子项可能未埋点，零计时不代表没有相应计算。
- 五条轨迹均需与六次采样已归档观测核对，确认埋点未改变保存结果。只做相关构建、复算和数值比对，不新增正式永久测试或 UI 交互。

## 结果与优化次序

**当前优先处理解析流速中的重复几何遍历，其次是速度逆成本和重复调用；Rapier 的主要成本在约束求解。** 五条轨迹及 Rapier profiler 功能构建均与已归档六次采样候选的保存输出一致，本轮没有实施任何优化。

### 控制轨迹与埋点影响

| 轨迹 | 整步均值 / p95 ms | 解析驱动 ms | 流体调用 ms | Rapier ms |
| --- | ---: | ---: | ---: | ---: |
| 控制，第一轮 | 11.805 / 14.905 | 2.646 | 5.990 | 3.117 |
| 几何细分 | 12.213 / 15.768 | 3.067 | 5.805 | 3.262 |
| 流体细分 | 11.516 / 14.800 | 2.473 | 5.800 | 3.181 |
| Rapier 内部计时构建 | 12.374 / 15.449 | 2.759 | 6.289 | 3.271 |
| 控制，第二轮 | 11.850 / 14.689 | 2.643 | 6.048 | 3.109 |

控制轨迹关闭深层埋点，保留此前一致的外层阶段计时。表中流体调用是 runtime 包装计时，与内部 `FluidStats.solve_ms` 略有边界差异。几何细分增加大量计时调用，对阶段成本有可见影响；细分轨迹之间的绝对时间不可视作算法快慢比较。本轮没有剔除尖峰，也未验证目标设备的稳定帧率。

### 解析流速：重复几何占主要部分

几何轨迹每帧平均 737.5 次解析流速查询，其中细胞 735.5 次，机器人 2 次。相关均值如下；“路口混合”包含部分管段投影和管长查询，不能重复加和。

| 几何工作 | ms/帧 | 调用次数/帧 |
| --- | ---: | ---: |
| 解析流速查询总计 | 3.005 | 737.50 |
| 最近管段查询 | 1.020 | 737.50 |
| 距血管并集边界的带符号距离 | 0.984 | 737.50 |
| 管段中心线投影 | 0.319 | 1,521.09 |
| 管长计算 | 0.031 | 420.25 |
| 路口搜索 | 0.318 | 737.50 |
| 路口混合（含嵌套调用） | 0.295 | 359.77 |

最近管段与带符号距离会在同一次查询、同一位置分别遍历地图的全部 12 条血管中心线，重复计算“到路径的距离减管宽”。两项合计约占解析查询时间的三分之二。`nearest_edge` 已计算最小距离却只返回编号，后续 `signed_distance` 又算一次，这是明确的优先审阅对象。

建议下一个局部实验在一次查询内复用最近管段编号和对应距离，保持原几何定义、并集边界与路口混合语义，不必先引入空间索引或新的近似。当前 0.984 ms 是带有埋点的阶段成本，仅是机会量级，实际净收益须匹配测量。

路口搜索也会为每次查询重新扫描节点及其关联边，计算固定地图的路口半径；后续可评估固定量预计算。管长在当前数据中仅约 0.031 ms，单独缓存管长不应被当成主要提速来源。本轮未改缓存、地图数据结构或查询接口。

### 流体：速度逆仍是重点

流体细分轨迹每帧平均 15.711 次压力迭代、21.711 次完整速度逆。

| 流体工作 | ms/帧 | 口径 |
| --- | ---: | --- |
| 局部流体更新总计 | 5.799 | 包含下列阶段 |
| 标记准备 | 0.085 | 细胞状态、核权重与力 |
| 标记散布 | 0.012 | 点力散布到右端 |
| 网格 Stokes 求解 | 5.394 | 包含压力循环、速度逆和真残差 |
| 速度逆 | 4.326 | 包含两分量任务、前回代、分配与拼接 |
| 场合并 | 0.010 | 背景和反馈叠加 |
| 完整场诊断 | 0.261 | 包括已有长期探针的全场检查 |
| 反冲量及收尾 | 0.025 | 冲量回传、统计和字段更新 |

速度逆约占网格求解时间的 **80.2%**，单次平均约 **0.199 ms**。标记准备和散布合计不到 0.1 ms，当前没有证据需要优先减少四个流体标记或改变其耦合机制。压力梯度约 0.429 ms、散度约 0.358 ms，但它们也出现在 Schur 和残差测量中，不能再与网格总计直接相加。

两个并行速度分量累计的前代／回代耗时和约 **2.594 / 2.662 ms**；这是跨两个任务的累计耗时，不能相加后当作帧墙钟。分量内部输入重排和输出恢复合计约 0.368 ms（同样是累计任务口径），只占分量内部总耗时约 6.5%；单靠复用这部分缓冲不太可能产生大幅提速。

逐次取 u/v 两个分量较大耗时后相加，约 3.220 ms；完整速度逆为 4.326 ms，余量约 **1.106 ms**。其中含任务启动、等待、并行重叠不足、拼接、计时等，不能全部认定为线程池开销，也不能直接据此改串行。

建议依次评估稀疏前回代存储／访问方式，以及小任务的调度和拼接；如果需要进一步减少速度逆次数，再选择压力预条件或完整 Stokes 联合分解。后两者仍是待确认的算法路线，本轮没有实施。全场诊断约 0.26 ms，属于较小的可评估项，不以删除有效检查来宣称解决主要成本。

### Rapier：约束求解比碰撞检测更重

单独启用 Rapier 0.36.1 的 profiler 功能，记录两个机械子步的原生计数器。各级存在包含关系，不应平铺相加。

| Rapier 工作 | ms/帧 | 关系 |
| --- | ---: | --- |
| 外层 `physics.step()` | 3.271 | 总墙钟计时 |
| 约束求解阶段 | 2.459 | 约占外层 75% |
| 约束装配 | 0.383 | 求解阶段的子项 |
| 迭代解算 | 2.070 | 求解阶段的子项 |
| 碰撞检测 | 0.371 | 包含下列宽／窄相相关项 |
| 宽相 | 0.099 | 碰撞候选生成 |
| 窄相 | 0.229 | 详细接触检测 |
| 末尾宽相更新 | 0.043 | 更新场景查询结构 |
| 用户修改传播 | 0.056 | 小项 |
| 岛构建 | 0.013 | 小项 |
| 约束维护 | 0.012 | 小项 |

当前首要 Rapier 热点是约束的迭代解算。仅根据墙段数量多而优先重写碰撞结构，缺少本轮成本依据。约束阶段同时涉及软体内部与接触约束，本轮没有分别计时，不能将 2.459 ms 全归给某一种约束。减少真实软体节点、迭代次数或引入远处分级会改变物理或模块职责，仍需后续单独选择；本轮没有据此调整参数。

## 验证与复现

`run.py` 完成五条 30 秒轨迹，全部退出 0。`analyze.py` 核对原始六次采样指纹、所有逐帧非计时诊断、细胞／箭头采样和通行事件，五条轨迹一致；机械范围和全场有限值保持原检查。新增 Rust 计数器格式、Python 语法、本地文档链接、源文件哈希及正式源码快照比对通过。

Rapier 诊断 feature 没有修改正式依赖或原锁文件。保存的诊断锁文件、Cargo metadata 功能解析记录和构建命令共同记录实际解析环境；计时器来源为已缓存的 Rapier profiler 及其计时依赖，不涉及更换模拟库版本。

没有执行 Godot/UI 交互、扩大长期场景或新增正式永久测试。原始数据、命令和复现入口见[实验目录](experiments/2026-10-27-six-profile/README.md)。
