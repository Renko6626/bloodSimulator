# 运行时分段计时与零拖曳采样实验

2026-10-26。用户批准上一轮后续优化列表的第 1 项：拆分非流体开销，并试验跳过无效计算。本轮沿用独立稀疏 Stokes + `1e-4` 候选；不实施完整联合分解、不改流体更新频率或 LOD，不修改正式源码及依赖。

## 范围与方法

此前 120 秒测量的整步均值约 18.79 ms，流体约 7.60 ms，差值 11.19 ms 仅能称为非流体余量，不能全归给 Rapier。本轮将该余量拆成网络更新、流体背景准备、机器人驱动、细胞解析驱动、Rapier 与其他调度。

候选只在细胞解析拖曳恰为零时跳过解析速度采样。源码核对发现 Rapier `set_particle_velocity` 除写速度外，还会清除 kinematic target 并标记 modified；因此候选保留原 setter 调用，不将整个零拖曳路径直接删掉。非零拖曳路径和所有流体、机械参数不变。

在临时复制的 `Simulation` 中添加同样的可选分段计时；默认主性能关闭计时，独立 profiling 开启。每帧六个互斥阶段的时间与整步时间相减，得到未覆盖的调度余量。细胞解析驱动阶段包括局部权重计算、逐节点采样和速度设置，不等于纯采样函数净耗时；Rapier 阶段为 `physics.step()` 墙钟耗时，包含其线程协调。

72 细胞、64² 固定真实分叉、默认无操作输入、每帧两个子步。每条 30 模拟秒、1,800 帧，覆盖活跃细胞逐渐增多和开始接触的过程；不剔除初始帧。两轮主性能反序，另有基线／候选各一条 profiling 轨迹。CPU 2–5、四线程、release、offline、locked、共用研究锁。

逐帧比较全部细胞顶点、机器人和流向箭头的 f32 快照指纹，逐秒比较细胞／箭头 CSV，并比较每帧非计时诊断与通行事件。该指纹是 FNV-1a 回归诊断，不是完整内部状态或密码学证明。复用已有细胞挤压恢复检查，不新增正式永久测试。

## 结果

**主要非流体开销是细胞解析驱动，独立 profiling 均值约 6.73 ms；Rapier 约 3.53 ms。** 零拖曳候选将解析采样减少约 15%，驱动阶段降至约 6.09 ms。两轮主性能均观察到非流体余量下降，但整步结果一轮略慢、一轮更快，不能承诺稳定的整体加速。

### 独立分段计时

表中为 1,800 帧均值，单位 ms。两个互斥流体包装阶段与内部 `FluidStats.solve_ms` 的计时边界略有差异，不能交叉相加。

| 阶段 | 基线 | 零拖曳跳过 |
| --- | ---: | ---: |
| 血管网络更新 | 0.0007 | 0.0008 |
| 局部流体准备 | 0.0057 | 0.0061 |
| 机器人驱动 | 0.0124 | 0.0146 |
| 细胞解析驱动 | 6.7271 | 6.0934 |
| 局部流体调用 | 7.7420 | 7.9517 |
| Rapier 步进 | 3.5260 | 3.6538 |
| 其余调度 | 0.0485 | 0.0459 |

非流体余量的主要部分已被解析驱动和 Rapier 覆盖，没有依据把此前约 11.19 ms 全算成物理求解。此表是当前 30 秒场景的独立 profiling，不直接拆解此前 120 秒测量的每项精确成本。

基线每帧实际调用 1,728 次细胞解析流速采样（72 × 12 × 2）。零拖曳节点平均为每帧 258.58 个，候选实际查询降至 1,469.42 次，减少 **14.964%**；每帧查询减少量与零拖曳节点计数完全一致。驱动阶段下降约 0.634 ms，包含计数、权重与速度设置等成本，不将该差值当作独立采样函数的净耗时。

### 数值与范围

六条轨迹的每帧全部细胞顶点、机器人和箭头快照指纹一致；逐秒细胞和箭头 CSV、通行事件、所有非计时帧诊断也一致。两种构建各运行一次已有的细胞挤压恢复检查并通过；没有放宽残差或机械阈值来获取收益。

本轮只确认零拖曳查询可以省去、主要非流体热点位于解析驱动。该路径对每个节点重复进行血管定位、中心线投影、路口混合和近壁衰减；尚未分别量化这些几何步骤的净耗时，不将整个驱动阶段全部归给其中某个函数。源码、命令、原始记录和复算入口见[实验目录](experiments/2026-10-26-runtime-hotpaths/README.md)。

## 追加：用户指定六个采样点近似

用户进一步要求直接减少细胞拖拽节点数，改成六个试验。本轮按减少解析流速采样来实现：保留 12 个软体粒子，每隔一个粒子采样，共六次；其余六个粒子的目标流速由两侧采样值线性平均，再以原有拖拽系数更新全部 12 个粒子的速度。圆环末尾按周期邻接插值。

这一近似不减少软体几何节点、不将总拖拽强度简单减半、不改变局部 Stokes 的四个内部阻力点。两种新配置均保留前述零拖曳跳过，以隔离 12 次／6 次采样的差别。均匀流下应保留原有全环响应；真实曲率、路口及近壁场下允许插值误差，须报告形变、通行与耗时差异。

独立新数据位于 `results/six-sample/`，不覆盖前面的严格数值等价试验。两种新配置各运行两条 30 秒轨迹，第二轮反序；另各运行一条独立 profiling。场景、时长、计时与记录方法沿用本报告前述约定。

### 六次采样的成本

| 配置 | 非流体均值 ms | 流体均值 ms | 整步均值 / p95 ms |
| --- | ---: | ---: | ---: |
| 12 次采样，第一轮 | 9.648 | 7.960 | 17.607 / 20.798 |
| 6 次采样，第一轮 | 5.862 | 5.545 | 11.407 / 15.928 |
| 6 次采样，第二轮 | 5.558 | 5.336 | 10.894 / 14.177 |
| 12 次采样，第二轮 | 8.539 | 5.799 | 14.338 / 19.037 |

主性能两轮均观察到非流体及整步均值下降。共享主机仍有明显波动，基线两轮自身差别较大，且流体阶段的计时也变化，不能把整步节省的 6.200 / 3.444 ms 全部归给查询次数减半。候选最大整步尖峰仍达 306.248 ms，没有剔除，不构成稳定 60 Hz 保证。

独立 profiling 中，解析驱动均值由 **5.466 ms 降至 2.409 ms**，Rapier 由 3.439 ms 至 3.258 ms。实际解析采样每帧平均从 **1,469.42 次降至 735.50 次**；每个需要解析驱动的细胞严格为 12→6 次，全场均值因后续细胞位置与零拖曳数量改变而并非精确 1/2。

压力 CG 每帧平均迭代由 15.586 至 15.711，并没有减少。Stokes 网格、四个内部标记及求解次数没有变化，因此不把流体计时降低当成六点采样改变流体算法的收益。

### 六次采样的行为

均匀流响应检查通过：十二个粒子均保留原拖曳系数下的速度松弛响应，未将一半粒子留成不受拖曳状态；已有挤压恢复检查也通过。六条轨迹正常退出，同一种配置的两轮主轨迹与 profiling 的快照指纹、采样及非计时诊断一致；不同配置之间有预期的近似误差，不再要求逐帧轨迹相同。

| 30 秒观测 | 12 次采样 | 6 次采样 |
| --- | ---: | ---: |
| 最大细胞面积偏差 | 3.3701% | 3.3617% |
| 最大越壁值 | 0 | 0 |
| 活跃细胞范围 | 3–21 | 3–21 |
| 细胞平均累计路程 | 65.32473 | 65.31655 |
| 分叉上／下通行事件 | 9 / 4 | 9 / 3 |
| 局部累计流入量 | 329.53869 | 329.46570 |
| 上出口累计流体份额 | 49.3573% | 49.2884% |

平均路程相对变化约 **−0.0125%**，局部累计流入约 **−0.0221%**，上出口流体份额相差 **−0.0689 个百分点**。候选全场速度、压力、标记力和细胞坐标保持有限，散度 RMS 峰值约 `2.05e-4`、交换冲量误差约 `1.08e-9`；没有数值爆炸或记录到越壁。相同细胞 ID 的采样中心最大差约 4.888 单位，30 秒时有 3 个细胞处于不同管段；不能称为轨迹或通行事件完全不变。

**六次解析采样值得保留为游戏近似候选。** 本轮支持它降低主要非流体热点，并在所测 30 秒内保留接近的宏观运动与形变。它尚未进行两分钟验证、强操控和玩家辨识验收；前一轮 `1e-4` 的两分钟结果不能直接当作该新近似的长期证据。正式源码、默认入口和拖拽节点配置尚未改动。

## 本轮验证与产物

已执行 `run.py` / `analyze.py`，以及用户追加的 `six_sample.py` / `analyze_six.py`。每个实验六条轨迹均退出 0；零拖曳组保留数值等价，六次采样组按近似误差报告。两种零拖曳构建各通过原挤压恢复检查，两种采样构建各通过挤压恢复和均匀流全环响应检查。

Rust 探针格式、Python 语法、来源哈希、文档本地链接和正式源码快照比对通过。没有执行 Godot／UI 交互，没有增加正式永久测试，也没有自动继续其他优化路线。
