# 分叉 Stokes 求解候选与实验 1

2026-10-26。用户要求记录候选，并批准先做实验 1。当前正式游戏入口保持原方案；以下算法选择只授权独立研究，不能据此自动替换后端。

最新补充：按用户要求完成 `1e-4` 与严格容差各 120 秒的同场景对照。两组保持稳定，宏观通行接近，逐细胞轨迹出现明显分岔。完整数据和游戏适用判断见下文“120 秒验证”；正式默认值未改。

## 候选与选择

| 候选 | 内容与取舍 | 状态 |
| --- | --- | --- |
| 1：重排序的稀疏速度分解 | 保留压力 Schur-CG，只替换速度矩阵的分解与前回代；固定几何复用因子，减少填充和运行时访问 | 本轮已批准实验 |
| 2：完整 Stokes 稀疏直接求解 | 对速度—压力不定系统作 LU / LDLᵀ 分解，争取省去外层压力迭代；增加初始化、内存和库接入成本 | 后续用户批准联合 LU 小试，性能有效；[记录](experiments/2026-10-27-joint-stokes/README.md)，正式未接入 |
| 3：压力预条件 | 为真实几何构造廉价 Schur 近似，降低压力迭代次数；不能假定常数黏度下乘一个常数就能改善 CG | 后续 SIMPLE 小试为负，见文末；其他方案未实施 |
| 4：分块多重网格 | 降低速度及压力子问题成本，适合继续扩大网格；粗网格边界与对称性处理增加实现成本 | 记录，未实施 |
| 5：误差预算 | 依据开口流量、分流比例、反馈力和轨迹评估容差，减少过度求解；须先量化误差 | 用户随后提出放宽精度，本轮追加独立容差短测；正式参数不变 |

压力热启动已存在，不列为新候选。已有带状回代的遍历优化可单独评估，不与本次算法比较混入。

## 实验 1 范围

- 在独立实验目录冻结当前 simulation 源码，以带状 Cholesky 为匹配基线。
- 采用确定性的贪心最小度重排序与稀疏 Cholesky；这是研究实现，不新增正式或实验外部依赖，不声称是 SuiteSparse 的 AMD 实现。
- 原速度矩阵、压力 Schur-CG、`2e-9 * max(||b||, 1)` 容差、压力热启动、自然牵引、f64、ω=0.5、每帧两个子步与四线程均保持。
- 比较初始化、因子条目及持久数组内存、单次速度逆、流体及整步耗时；分别保存无埋点性能与有埋点诊断。
- 复用现有三个流体检查；在真实分叉上补充同一矩阵、同一右端的带状／稀疏速度解和真残差对照，独立检查变换没有改变方程。
- 两轮反序的 72 细胞、60 帧真实窗口短测，CPU 2–5、共用研究锁，不剔除初始帧。记录逐帧数值、细胞及流场差异；不覆盖历史 CSV。
- 不接入 Godot，不改压力预条件、耦合强度、求解频率或边界，不扩展长期拥堵验证。

## 实验结果

**稀疏候选两轮流体均值为 12.659 / 15.491 ms，匹配带状基线为 34.352 / 41.577 ms；整步从 43.702 / 51.486 ms 降到 22.111 / 26.655 ms。** 每帧压力迭代均为 37.333 次，收益来自降低单次速度逆成本。当前仍高于 60 Hz 的整步预算，未切换正式原型。

共享 Xeon Gold 6330、CPU 2–5 同插槽四物理核、release、offline、locked、共用研究锁。72 细胞、固定真实分叉窗口，实际反馈细胞为 3–5 个，另含机器人。每条 60 帧、一模拟秒，不剔除初始帧。第二轮反序，性能与 profiling 分开。表中单位 ms；p95 按原始逐帧 CSV 的 nearest rank 复算，原 circulation probe 的整步 p95 索引口径略有不同。

| 配置 | 流体均值 / p95 | 整步均值 / p95 | 整步最大值 |
| --- | ---: | ---: | ---: |
| 带状，第一轮 | 34.352 / 54.069 | 43.702 / 63.608 | 78.693 |
| 稀疏，第一轮 | 12.659 / 14.898 | 22.111 / 24.502 | 25.300 |
| 稀疏，第二轮 | 15.491 / 18.289 | 26.655 / 30.609 | 106.629 |
| 带状，第二轮 | 41.577 / 59.439 | 51.486 / 69.859 | 70.913 |

两轮均观察到流体均值约 2.7 倍、整步约 1.9–2.0 倍的改善。共享主机有明显波动，稀疏第二轮仍有 106.629 ms 尖峰；不能承诺固定倍数或逐帧性能。与旧 59 ms 记录不同，本表采用本轮匹配基线，不跨轮折算加速倍数。

## 速度逆与内存

独立 profiling 中，带状／稀疏每帧均为 43.333 次完整速度逆；单次墙钟均值为 0.930 / 0.265 ms，每帧速度逆合计为 40.317 / 11.483 ms。该计时覆盖 u/v 并行前回代、排列恢复、分配和线程协调，不能视为纯算术耗时。稀疏候选仍有约 83% 的网格求解时间用于速度逆，压力迭代未减少。

两个速度分量的因子存储条目从 287,586 降至 61,754。持久数组有效载荷由 2,300,688 字节（约 2.19 MiB）降至 988,064 字节（约 0.94 MiB）；稀疏值包含行索引、排列及对角，带状值包含填充带。该口径不包含 Vec 头、容量余量、初始化临时图及求解缓冲，不能当作整个进程峰值内存。

代价是初始化中的排序与分解：每分量带状约 6.8–14.7 ms，稀疏约 30.2–33.0 ms。整个世界初始化还包含地图和物理等阶段，波动较大；本次只确认速度因子初始化更贵、运行时更便宜。固定几何只分解一次，动态过程没有重新排序或分解。

本轮同时改变了排序、存储和三角求解的访问方式，未进一步隔离各部分净收益，不能把全部加速都归于减少非零条目。

## 数值检查

两种实验构建各运行原有三个流体检查，以及一个同矩阵速度逆对照，均通过。在真实分叉的 u/v 矩阵、两组非平凡右端下，稀疏解相对带状解的最大绝对差为 `1.53e-15`；用原装配矩阵独立计算的最大 `|A x − b|` 为 `6.74e-15`。这些是对照结果，不是用户或游戏要求达到的精度。

完整动态短测中，逐帧细胞中心与面积记录在输出精度下完全相同；流向箭头最大分量差约 `2.84e-14`。同配置两轮记录相同。帧末子步的散度 RMS 最大约 `3.39e-9`、动量 RMS 最大约 `2.44e-14`、交换冲量误差约 `3.85e-10`、开口净流量约 `4.46e-8`，均通过保留的检查。流向箭头是快照采样，不等同于保存并对比每个网格压力和速度自由度。

`1e-15` 差异来自两种 f64 直接求解的舍入误差；实际压力 CG 停止条件仍为 `2e-9 * max(||b||,1)`。不能把此数值解释成游戏正以 `1e-15` 的容差迭代。放宽压力容差的后续短测与上表分开归档。

源码、命令、原始数据与复算入口位于[实验目录](experiments/2026-10-26-stokes-sparse/README.md)。

## 追加：游戏精度的压力容差对照

用户随后提出游戏不需要 `1e-15` 精度。本轮追加参数实验，沿用同一稀疏速度分解，只将压力停止条件中的参数由 `2e-9` 改为 `1e-6` / `1e-4`；同时影响初始化背景压力求解与动态反馈求解。Cholesky 仍使用 f64 直接求解，没有用新算法近似速度逆。

为量化收支误差，在三个临时构建中统一记录每个机械子步的所有开口总流入和总流出。定义相对流量不平衡为 `|Q_out−Q_in| / ((Q_in+Q_out)/2)`。严格／中等／宽松各两条 60 帧轨迹，第二轮反序；除记录流量外与实验 1 场景一致。下表采用本组新的严格基线，不能与上表 profiling 或主性能混算。

| 压力停止参数 | 每帧压力迭代 | 流体均值，第一 / 二轮 ms | 整步均值，第一 / 二轮 ms |
| --- | ---: | ---: | ---: |
| `2e-9` | 37.333 | 14.335 / 15.408 | 24.713 / 26.231 |
| `1e-6` | 24.533 | 10.036 / 11.306 | 19.529 / 22.638 |
| `1e-4` | 15.000 | 7.839 / 7.414 | 18.624 / 17.409 |

每帧速度逆调用数由代码结构推算分别约 43.33、30.53、21 次；本组未开启逐次计时埋点。两轮宽松候选流体均值比本组严格基线下降约 45%–52%，整步均值下降约 25%–34%；该比例仅描述本组共享主机短测。

误差表的两轮结果在记录精度下相同。细胞中心差采用二维距离，参考直径为 1.4；不是压力残差或速度分量误差。箭头为混合场采样，仍不代表全场每个自由度的误差。流量指标只覆盖窗口总收支与总流入变化，尚未验证各分支流量比例。

**本场景中放宽压力容差有实际收益，`1e-4` 可保留为游戏精度候选。** 它尚未达到稳定 60 Hz 的整步预算，也没有长期累积误差、密集堵塞、强操控或目标玩家设备验证。`1e-6` 可作为更保守的候选，成本也更高。这些参数不自动改为正式默认值。

宽容差的散度残差已超出原 `1e-8` 严格检查界，因此不能称为“通过原严格精度验收”。原测试及其阈值保持原样；追加组只构建并运行参数对照，保存有限值、轨迹和流量观测，没有删除或放宽原测试换取通过。

## 120 秒验证：稳定、宏观接近，个体轨迹分岔

用户随后要求验证 `1e-4` 并计算长期表现。本轮在同一冻结稀疏求解器上，将 `2e-9` 与 `1e-4` 各运行 120 模拟秒、7,200 帧、14,400 个机械子步。72 细胞、默认脉动与默认无操作输入，CPU 2–5、四线程、共用研究锁；没有改模型、求解频率、边界或正式入口。两条长轨迹均正常退出。

### 流量与通行量

120 秒累计局部流入量，严格／候选约为 1,328.304 / 1,328.996，候选相对变化约 **0.0521%**。累计上支路流体流出份额为 48.9863% / 49.0826%，相差 **0.0963 个百分点**。

从主干进入两个分支的细胞通行事件，严格为上 44 / 下 16，候选为上 43 / 下 17，合计均为 **60**。逐细胞累计路程均值约 213.728 / 212.241，候选低 **0.696%**。这些是同一初始布置的一对轨迹，不是多种布局的统计等价证明；各出口通量与地图网络的物理标定也未因此完成。

候选的最大瞬时开口相对流量不平衡约 **0.00841%**。积分得到总流出减总流入约 **−0.060934**，占累计流入的 **−0.004585%**；绝对缺口积分几乎相同，说明本轨迹偏差基本同向，并非完全随机抵消。二维固定域流体面积约 155.25，该积分相当于域面积的 **0.03925%**（单位深度诊断口径）。

这里积分的是连续性缺口，**不是实际保存的流体体积或细胞数量损失**。当前每子步重新求解准稳态 Stokes，未保存并推进流体密度库存。因此不能将 0.00841% 乘以帧数当作实际质量损耗，也不能据一次瞬时误差线性推算任意长时间的细胞位置。误差能通过反馈力进入机械状态，随后受阻尼、接触及分流影响。

### 个体轨迹与画面差异

在每秒采样中，相同细胞 ID 的最大中心距离从一秒约 `4.22e-5` 增至十秒 0.313、三十秒 4.937、六十秒 29.249、一百二十秒 85.498 游戏单位。120 秒时 72 个细胞中有 34 个处于不同管段；这包含走入不同支路及沿环路相位的差异，不应把它解释成所有细胞都发生了同方向漂移。

按当前 Godot `SCALE=24` 的几何比例，十秒最大世界坐标差约 7.5 像素，三十秒约 118.5 像素。约七秒的采样已达到一个像素量级。这只是同一细胞位置差的屏幕尺度换算：未运行 Godot、未模拟相机平滑、未做真人辨识试验，不能将“一像素”当成人眼感知阈值。当前默认画面会高亮细胞 0，该细胞十秒位置差约 0.134 单位、120 秒约 5.386 单位；并排追踪同一细胞能够观察到不同。

为排除“相同参数重放本来就不同”的解释，补做严格方案相同二进制、相同初始状态的 30 秒重放。保存的全部非计时帧统计，以及采样的细胞位置、面积、管段和路程，与第一条严格轨迹一致。此结果支持容差改变触发了本次早期轨迹分岔；没有据此证明该系统在数学意义上混沌，也没有检查所有平台的确定性。

### 对游戏的判断

**这组结果支持将 `1e-4` 作为背景血流的游戏候选：两分钟内稳定、局部总流量和分流份额接近、细胞总体通行相近，流体成本约减半。** 对普通游玩，是否能认出哪条轨迹来自更严格的数值求解，仍缺少直接的玩家证据。逐帧或逐细胞并排比较会看到差异，不能声称长时间画面基本一样。

“不爆炸”只说明一种稳定性要求。游戏更有用的验收依据是通行、流速、分流、形变和操控是否合适，通常无需逐个复现严格方案的细胞轨迹。本轮只覆盖默认无操作交通；强操控、不同初始密度、超过两分钟的运行以及玩家主观辨识没有验证，不自动扩大后续实验或更改正式默认值。

### 当前结构与成本

正式 `crates/simulation/src/fluid/grid.rs` 的 `schur` 将压力依次经过梯度、速度逆、散度，即 `S = B A⁻¹ Bᵀ`；`solve` 使用上次压力作初值。迭代方向直接从残差开始，更新使用 `rᵀr` 和普通 CG 的 beta，没有 `M⁻¹r` 或预条件器。正式容差仍为 `2e-9`，独立研究副本才使用已验证的 `1e-4`。

依据[faer 对照中自写基线](experiments/2026-10-27-faer-speed/results/summary.json)，候选平均每帧压力迭代 15.711 次，即每机械子步约 7.856 轮。每个子步还各有一次构造右端、一次计算热启动残差、一次恢复速度的速度逆，共 `压力迭代 + 6` 次／帧，实际为 21.711 次。单次速度逆墙钟均值约 0.220 ms。这组计数不支持将当前压力迭代形容为成百上千轮；实际成本主要来自每轮算子应用较贵。

若预条件器能把每子步平均迭代降至 3 轮，固定其他成本时，约可少调用 9.71 次速度逆／帧，毛节省约 2.14 ms／帧；还需扣掉预条件器应用时间。此为成本估算，没有测得这一迭代数或加速。本轮尚未测量逐轮真残差或谱，不能确定最难收敛的模式或最终收益。

### 可用组件

| 组件 | 可直接参考或复用的内容 | 针对本项目的判断 |
| --- | --- | --- |
| AMGCL | `schur_pressure_correction<USolver, PSolver>`，分别配置速度与压力求解；可用速度对角近似构造 Schur 预条件矩阵 | 最值得评估的嵌入式库候选。它是 header-only C++，Rust 接入仍需桥接、构建和矩阵适配；不能把接入成本算成一个 Cargo 依赖。 |
| PETSc | `PCFIELDSPLIT`、Schur `selfp`、`PCLSC`，可组合现成 Krylov 与子块求解器 | 最适合参考算法及做独立数值对照；直接纳入游戏运行时的构建、数据接口与生命周期接入范围更大。 |
| hypre | MGR 接收变量分块信息，借助 BoomerAMG 做粗层校正 | 若以后扩大网格或区域规模可评估；当前约 2,484 个压力未知量，是否值得构建多层结构没有测量依据。 |

AMGCL 的[官方模块文档](https://amgcl.readthedocs.io/en/latest/components/preconditioners.html#schur-pressure-correction)给出 Schur 压力修正及 `adjust_p`、`approx_schur` 等选项，[官方仓库](https://github.com/ddemidov/amgcl)说明其 C++ header-only 形态。作者的 [Stokes 实验论文](https://arxiv.org/abs/2006.06052)也评估了这种库用于鞍点系统的组合策略；其离散、规模与我们不同，不能外推论文加速倍数。

PETSc 的[分块求解手册](https://petsc.org/release/manual/ksp/)描述 `selfp`：用速度块对角或块对角的逆近似构造稀疏 Schur 预条件矩阵；[LSC 文档](https://petsc.org/release/manualpages/PC/PCLSC/)通过辅助压力 Laplacian 的求解近似 Schur 逆。LSC 每次应用涉及两次辅助求解，应用成本必须实测。hypre 的 [MGR 文档](https://hypre.readthedocs.io/en/latest/solvers-mgr.html)明确要求利用变量分块信息，并以 BoomerAMG 处理粗层。

### 优先的算法方向

推荐先评估 diffusive SIMPLE 类压力预条件，保留当前真实 Schur 算子、速度精确求解、热启动、容差和耦合。令 `D_A = diag(A)`，可用几何相关的稀疏近似 `P = B D_A⁻¹ Bᵀ` 构造预条件作用；重点是廉价近似施加 `P⁻¹`，直接乘 `P` 并不等价于预条件逆。

这一方向与 PETSc selfp、AMGCL 的近似 Schur 构造相符。[狭窄几何 Stokes 论文](https://arxiv.org/abs/2307.05266)针对交错有限差分分析复杂边界下的 Schur 谱，并评估 diffusive SIMPLE；离散结构比一般有限元示例更接近本项目。论文结果提供试验依据，尚不能证明我们带自然牵引开口的分叉也会获得同样收益。

还需区分几个条件：

- [PETSc Stokes 教程](https://petsc.org/main/tutorials/physics/guide_to_stokes/)中的压力质量阵近似在部分离散下很合适；本项目为常黏度、等体积压力网格，最简单的质量阵近似退化为 `cI`，精确算术下只是常数缩放，不能改善 CG 的谱条件。不能直接把这个教程配置当作新增有效加速。
- 用近似 Schur 作预条件时，原 `S` 仍应承担真实算子应用。不能只把昂贵的 `A⁻¹` 换成对角近似，仍声称解的是原方程；AMGCL 的 `approx_schur` 需要结合是否存在完整系统的外层校正来理解。
- 保留 PCG 要求矩阵和预条件作用满足对称正定等条件，见 [PETSc KSPCG](https://petsc.org/release/manualpages/KSP/KSPCG/)。若使用非对称或每轮变化的内部求解，需要选择兼容的外层方法，例如相应的 GMRES／FGMRES 配置，不能直接塞进现有普通 CG。
- 换库时不能只对齐名为 `tol` 的数值。应保留原始真残差／散度、动量、开口流量和已有动态检查口径，并统计预条件应用、速度逆调用、初始化与流体净耗时。

### 调研阶段的建议与边界

低成本方向是先在现有 Rust 结构上做 SIMPLE 类预条件的独立对照，以便回答“廉价预条件能否净省时”，不用同时引入外语库。若明确希望直接复用库，推荐首先考察 AMGCL Schur 压力修正；PETSc 适合更全面的算法对照，hypre 留作规模扩展候选。这些均为本轮分析后的建议，不是已批准的实施路线。

后续用户已批准上述 Rust 小实验，结果见下节。其余预条件器、外部求解库或 C++／C 模块边界仍须先选择方案；不自动实施完整 Stokes 联合分解或扩大长期测试。

### 后续小试：纯 SIMPLE 预条件得到负结果

用户批准“稍微试一试”后，以原普通 CG 为基线，在临时副本加入固定 `P = B diag(A)⁻¹ Bᵀ` 的精确稀疏逆和标准 PCG。其余算子、热启动、动态 `1e-4`、耦合、六次采样及几何复用保持；未引入 faer 或 CFD 库。两轮反序主计时及两条细分计时各 6 秒，未扩展调参。

每帧压力迭代由 14.911 增至 53.981；两轮流体均值由 6.102 / 5.483 增至 22.092 / 22.058 ms，整步由 11.240 / 10.230 增至 26.815 / 26.833 ms。独立细分中速度逆调用由 20.911 增至 59.981 次／帧，预条件器自身还耗时约 6.215 ms／帧。收敛和应用成本均变差，不推进此组合。

原有严格流体检查通过，新增独立核对 `B diag(A)⁻¹ Bᵀ z-r` 的最大绝对残差约 `5.5e-15`；测试恢复严格容差，动态使用原宽容差。六条短轨迹有限且无越壁，同配置保存观测复现。这个结果针对所测的 P 及精确施加方式，未测其他预条件器，也未测谱或长期表现。详细源码、命令、原始数据和限制见[小实验记录](experiments/2026-10-27-pressure-simple/README.md)；正式文件保持不变。

### 再后续：联合 Stokes 稀疏 LU 小试有效

用户随后批准对固定速度—压力原系统作联合分解，独立副本使用 faer 0.24.4 稀疏 LU，每个机械子步一次求解，因子跨子步复用。两轮六秒匹配流体约 5.32 / 6.94→2.95 / 2.95 ms，整步约 10.12 / 12.60→8.35 / 8.76 ms；增加初始化和内存，峰值进程 RSS 约 14.6→28.5 MiB。严格流体检查和从原 A／B 独立形成的块算子审计通过，完整数据及适用限制见[联合实验记录](experiments/2026-10-27-joint-stokes/README.md)。尚未进行长期或正式接入。
