# 流体研究索引

更新：2026-10-27。当前状态和后续任务统一见 [状态与待办](../STATUS.md)。本目录记录独立研究及后续接入。默认游戏仍使用网络解析驱动，显式 `--local-stokes` 已接入联合 LU 双区域原型。

## 当前候选

[RTX 3060 分段 profiling](experiments/2026-10-27-modular-mg/gpu-profile.md)：新增 off／host／gpu 可选诊断，区分编码／提交／回读／审核和设备 pass 类别。首轮 144 次回放全部通过，匹配输入的迭代与残差诊断相同；主机编码约占 host 组总耗时 45%–59%，设备侧以 MG 平滑为首。记录仪器化干预，未根据单个 SpMV 的速度宣称整体加速。

[Vast.ai RTX 3060 冻结输入回放](experiments/2026-10-27-modular-mg/vast-rtx3060.md)：按用户提供的 SSH 入口执行既有后端，两种 GPU 循环配置共 96 次全部通过。一次 V-cycle 的 small64／wide96／wide192 均值约 57／95／124 ms，CPU LU 约 0.77／0.60／3.85 ms；GPU 实时成本仍未解决。记录配额、交错顺序及 Linux／Windows 动态输入差异，不以跨机均值比计算纯硬件加速。

[可插拔流体后端与 GPU 分块多重网格](experiments/2026-10-27-modular-mg/README.md)：用户已确认并实现三个 crate、工厂接口与统一 capture／replay 入口。新路线为 FGMRES＋右分块预条件＋速度块连通聚合多重网格；默认局部 CPU LU、GPU 可选。原方程与耦合保留，新软件功能验证与物理 GPU 性能分开记录。

[首版 wgpu GPU Stokes 实验与 Windows 基线](experiments/2026-10-27-gpu-stokes/README.md)：保留真实数据格式、旧 GMRES32 算法与历史来源。GTX 1050 Ti 的 48 次真实求解均达到 400 次迭代上限且未通过残差门槛；后续模块化 FGMRES／MG 已另行实现。旧源码注入采集仅适用历史版本，新实验走上述统一入口。

[同域 48×48 的 192² 性能](experiments/2026-10-27-wide-192/README.md)：两轮各 20 秒，192² 流体均值约 12.79–12.91 ms、模拟整步约 17.69–18.01 ms，约为本轮匹配 96² 的 5.28／2.51 倍；双区进程峰值 RSS 约 142–144 MiB。仅提高分辨率，保留已知域内泵驱动缺失，未改正式参数。

[48×48／96² 大窗口实验](experiments/2026-10-27-wide-window/README.md)：两轮 20 秒匹配行驶中，流体约 2.61–2.92 ms、整步约 7.93–8.29 ms，与原窗口接近；但把泵段包入域内后，当前仅边界压力驱动缺少域内泵压差，初始流向反转。相同粗格距的小范围静态控制保持正向。保留大范围方向，先确认内部驱动方案；未改正式参数。

[联合 LU 接入与双区行驶验证](experiments/2026-10-27-region-switch/README.md)：用户确认后已进入实际 simulation，并以显式 Godot 参数启用。双区加载时预分解，交接保留点力历史和单一物理世界；20 秒真实输入完成六次切换，整步均值约 8.42 ms，额外交接均值／最大约 3.00／4.51 ms。局部场速度差最大约 0.179 单位／秒，尚待手动体验；当前只覆盖两个互动区，全图调度未实施。
[完整 Stokes 联合稀疏 LU](experiments/2026-10-27-joint-stokes/README.md)：用户批准后，用 faer 0.24.4 对固定 7,400 阶原方程作联合 LU 并复用。六秒对照两轮流体约 5.32 / 6.94→2.95 / 2.95 ms，整步约 10.12 / 12.60→8.35 / 8.76 ms；峰值进程 RSS 约 14.6→28.5 MiB，分解初始化更贵。原严格检查及独立块算子审计通过，保留为候选，尚未长测或正式接入。

[SIMPLE 压力预条件小试](experiments/2026-10-27-pressure-simple/README.md)：用户批准后只测固定 `P = B diag(A)⁻¹ Bᵀ`＋既有稀疏因子，保留原 Schur 算子与其他参数。六秒对照中每帧压力迭代 14.91→53.98、两轮流体 6.10 / 5.48→22.09 / 22.06 ms；严格检查及独立 P 作用核对通过。保留负例与原普通 CG，不继续调参，不外推为所有预条件器均无效。

[压力迭代与现成求解器调研](2026-10-26-stokes-sparse.md#压力迭代与现成求解器调研2026-10-27)：代码确认当前为无预条件的热启动 Schur-CG。AMGCL 提供 Schur 压力修正，PETSc 提供分块、selfp 与 LSC，hypre MGR 留作扩容候选；后续 SIMPLE 小试已得到负结果。尚未引入这些 CFD 库，faer 接入继续列入暂缓待办。

[faer 稀疏速度求解](2026-10-27-faer-speed.md)：用户批准后在独立副本试用 faer 0.24.4，保持压力 CG、`1e-4`、六次采样及几何复用。两轮整步约 11.97 / 11.06→10.99 / 10.77 ms，独立速度逆计时降低约 11.1%，初始化更快；30 秒细胞采样及通行一致，流场存在舍入级差异。每帧约 21.71 次速度逆仍是主要成本，正式依赖和后端未变。

[几何查询单次遍历复用](2026-10-27-geometry-query.md)：用户批准后已应用正式共享 map／graph 路径。六次采样研究候选的两轮解析驱动约 3.02 / 2.91→1.88 / 1.82 ms，每帧节省约 1.1 ms；独立距离查询计数归零，静态差分和轨迹保持一致。正式默认入口仍未切换流体或采样方案，项目检查通过。

[六次采样进一步 profiling](2026-10-27-six-profile.md)：五条 30 秒诊断轨迹复现既有观测。明确三个热点：重复最近管段／带符号距离遍历、反复稀疏速度逆、Rapier 约束求解。优先建议复用几何结果，计时约 2.00 ms 的重复几何部分只是机会量级；本轮只测量、未实施优化。报告区分嵌套阶段与两个速度分量的并行累计耗时。

[运行时分段与六次解析采样](2026-10-26-runtime-hotpaths.md)：后续优化第 1 项已完成，非流体主要成本为解析驱动约 6.73 ms、Rapier 约 3.53 ms；跳过零拖曳采样可减少约 15% 查询，保持记录一致。用户追加六次采样近似后，保留十二物理节点和四个流体标记，独立 profiling 解析驱动约 5.47→2.41 ms，两轮匹配整步约 17.61 / 14.34→11.41 / 10.89 ms。仅完成 30 秒对照，有轨迹和通行差异，正式入口未改。

[稀疏速度分解及候选方案记录](2026-10-26-stokes-sparse.md)：用户批准实验 1 后，以最小度重排序与稀疏 Cholesky 替换独立副本的速度逆。两轮流体均值 12.66–15.49 ms、整步 22.11–26.65 ms，匹配带状基线分别为 34.35–41.58 ms、43.70–51.49 ms；压力迭代未减少，短测数值一致。正式后端未切换。完整联合分解、压力预条件、多重网格与误差预算的候选及授权边界在报告中记录。

同报告的独立容差短测将压力停止参数放宽至 `1e-4` 后，迭代降至每帧 15 次、流体均值 7.41–7.84 ms、整步 17.41–18.62 ms；一秒中心差约直径的 0.0031%、开口最大相对流量不平衡约 0.006%。该组不满足原严格散度阈值，仅作为游戏精度候选，未改正式参数。

后续各 120 秒默认交通对照已完成：候选保持稳定、无越壁；分叉总通行均为 60，局部累计流入差约 0.052%、平均细胞路程差约 0.70%。个体轨迹明显分岔，不能将一秒的小位置差外推到长期画面。30 秒严格同参数重放记录一致；报告已分开说明宏观适用性、连续性缺口积分和玩家辨识限制。

[固定分叉窗口试接](2026-10-26-fixed-window-trial.md)：在 simulation 中实现了带状速度逆与压力 Schur-CG 数值原型，真实边界检查通过，但短测整步约 59 ms，按方案暂不接 Godot 默认入口。下述 6 ms 结果仅覆盖周期直管。

继续工作前先读[分叉段待解决的问题与交接](2026-10-26-fixed-window-trial.md#分叉段待解决的问题)：速度逆的含义及重复成本、压力迭代增加、开口流量标定、近壁和跟流限制，以及已批准和待选择的路线均已分开记录。后续稀疏实验已补充速度逆独立计时，不能将历史整个流体阶段耗时视为纯前回代耗时。

[压力初值与内核优化](2026-10-26-stokes-kernels.md)：沿用 ω=0.5，Rapier 四线程、预测接触距离 0.002；复用压力初值、预计算 Thomas 倒数并调整 FFT 循环后，64²/64 细胞六秒轨迹的流体均值 3.56–3.66 ms、整步 5.92–6.06 ms，尚未满足 5 ms。源码与复现见[实验目录](experiments/2026-10-26-stokes-kernels/README.md)。允许透流、仅规则周期直管，不是严格封堵或正式游戏后端。

## 研究过程与历史对照

下列数值对应各报告当时的场景、硬件与测量口径，不可跨轮直接计算加速倍数。旧报告中的“下一步”是当时的建议，当前待办以状态文档为准。失败案例和基线源码保留供复算使用。

- [Rapier 接触距离与并行](2026-10-26-rapier-parallel.md)：调整预测距离并启用四线程后，物理均值 2.02–2.27 ms、整步 6.34–7.10 ms；所测逐帧细胞记录与原方案一致。
- [点力欠松弛 Stokes](2026-10-26-stokes-relaxation.md)：ω=0.5 使所测 64 细胞六秒轨迹稳定，原整步均值 9.87–10.54 ms；后续已继续优化机械与流体开销。
- [有限阻力 Stokes 反馈实验](2026-10-26-stokes-feedback.md)：真实软体与 LBM 对照；16 细胞、32² 一次更新方案整步均值 2.26 ms、p95 3.25 ms，64² 仍超预算，尚未接入正式游戏。
- [Rayon 并行更新实验](2026-10-26-stokes-rayon.md)：四线程在 64²/16 细胞下净加速约 1.14 倍，均值 5.61 ms、p95 7.22 ms；数值与串行一致，但仍超预算并出现更大尖峰。
- [Stokes 热路径优化实验](2026-10-26-stokes-hotpaths.md)：复用缓冲和粗化并行任务后，64²/16 细胞四线程均值 4.61 ms、p95 6.52 ms；平均成本下降，稳定 5 ms 仍未达到。
- [64细胞密集场景验证](2026-10-26-stokes-64-cells.md)：同域、同大小下，一次更新反馈在第16帧失稳；自洽对照可完成，但整步均值约40.92 ms，后续欠松弛实验已处理所测场景的失稳。
- [稳定耦合候选调研](2026-10-26-stable-coupling-options.md)：比较点力欠松弛、有限校正、旧点力初值CG与联合求解，保留实验前的推导与取舍。
- [低雷诺数流体路线调研](2026-10-22-low-re-flow.md)：Stokes、LBM、边界积分与 Rapier 耦合的取舍；推荐原型及待决事项。
- [MAC + Stokes 专项实验](2026-10-22-mac-stokes-experiment.md)：真实速度—压力求解、精度收敛、两种解法的耗时及流固耦合接口核查；尚未接入游戏。
- [简化细胞耦合与不规则边界实验](2026-10-23-coupling-experiment.md)：少量阻力点、圆膜参照及体积惩罚的误差和成本；优先局部带流与受阻近似。
- [LBM 与少量阻力点对照](2026-10-23-lbm-experiment.md)：直管、曲墙、逐格步反馈及固定传播索引优化；32² 小域候选，整步 5 ms 尚未验证。
- [LBM 单细胞动态实验](2026-10-23-lbm-dynamics.md)：移动核、周期跨界、Rapier 挤压恢复及 f32 对照；单细胞 p95 仍在 5 ms 附近。
- [LBM 核复用与 4 / 16 细胞实验](2026-10-23-lbm-scale.md)：优化前后轨迹一致，16 细胞平均约 4.87 ms、p95 约 5.91 ms；主要耗时仍在流体阶段。
- [16–128 细胞规模与分级模拟](2026-10-23-many-cells-and-lod.md)：等密度扩展与固定小网格两组实测，区分流体覆盖和活跃细胞成本；建议先采用近处详细、远处区域指标两层。
