# MAC–Stokes 独立原型：离散、求解与验收备忘

2026-10-22。补充 [现有综述](../../2026-10-22-low-re-flow.md)，不改变产品架构。以下性能选择是待测假设，不是本项目耗时结论。

## 1. 先把离散问题定义清楚

常黏度、二维准稳态方程为 `−μΔu + ∇p = f, ∇·u=0`。矩形 MAC 网格把 `p` 放在单元中心，`u_x` 和 `u_y` 分别放在竖、横面；`D` 是每单元净面通量除以面积，`G` 应按相同内积构成 `−D*`。移走已知壁面速度的仿射项后，解 `[A G; −D 0][u;p]=[b;0]`，常黏度规则内部 `A=−μΔ_face`。这个结构、对物理速度边界的伴随关系与稳态极限由 [Cai 等，§2–3](https://arxiv.org/pdf/1308.4605) 直接支持。压力只出现梯度；纯速度 Dirichlet 或周期加固壁时每个连通流体域有一个常数零模。最简单是每次压力更新去体积加权均值，或固定一个压力自由度；右端必须满足净边界通量为零。不要把 `p=0` 同时强加到所有开口；指定开口压力/牵引会改变边界方程和 gauge。[Cai 等，§1、§3.2](https://arxiv.org/pdf/1308.4605)。

对已选的 x 周期、y 上下壁无滑移原型：`v=0` 位于壁面横面；壁边最近的 `u` 是切向自由度，壁外 ghost 取 `u_ghost=−u_inside`（非零壁速为 `2u_wall−u_inside`），使壁上插值恰为给定速度。周期端配对相应面的自由度，切勿把两端周期面计成两个未知量。这里无需独立施加压力边界值。若处理入口/出口，要分别定义速度/通量或压力/牵引及角点规则，检验各端口通量收支。非齐次速度值先移到右端，使 Krylov 看到线性算子；[Cai 等，§3.2](https://arxiv.org/pdf/1308.4605) 明确这样处理。

分岔墙面不等于矩形外壁：

| 墙表示 | 原型适用性与必须另验的量 |
| --- | --- |
| 阶梯 mask | 最容易保持同一面通量的局部守恒；把固液界面当作实际阶梯壁，对法向面设零通量、切向速度用适配 ghost。斜壁位置、截面面积、壁面剪切及分岔狭颈会有几何误差；不能拿矩形的二阶收敛推断斜壁也二阶。[Ye 等的交错网格曲壁研究](https://doi.org/10.1016/S0021-9991(02)00013-X) 报告相对阶梯壁的改进。 |
| cut cell / embedded boundary | 用真实面开口长度、流体面积和壁段通量构造 `D`，再按这些权重配 `G=−D*`；动量控制体和壁面黏性通量也要相应改变。小切格可能恶化条件数，不能只改压力 mask 后沿用矩形速度 Laplacian。作为技术参考，[二维 MAC cut-cell 工作](https://www.techscience.com/CMES/v119n1/29781) 明示壁面 Dirichlet 与守恒黏性项；[高阶 EB–Stokes 工作](https://arxiv.org/abs/2209.02840) 专门处理小切格，但采用不同的共点布局，不能直接复用离散式。 |
| IB 墙标记 | 可保留规则 MAC 算子，以标记的力/乘子施加墙约束；必须测墙面滑移、渗漏及压力/牵引误差。标准正则化 delta 会平滑界面，标记处速度满足约束也不等于几何墙上点态精确无滑移；[Kallemov 等](https://arxiv.org/abs/1505.07865) 的联立 IB 模型在标记速度意义下精确约束、总体仍报告一阶收敛。 |

独立核心原型建议先用精确矩形边界建立算子与求解正确性，再单独用倾斜通道/分岔测几何误差；不要把几何误差混入求解器验收。

## 2. 实时预算下怎样比较求解器

消去速度得到 `S=−D A⁻¹G`。在固定速度 Dirichlet 且正确 gauge 后，`S` 在零均值压力子空间为正定；但显式形成或精确求逆通常不划算。以外层 Schur–PCG、内层 CG 精解 `A` 可以做小网格正确性参照。**内层按残差容差停止的 CG 不是固定线性 `A⁻¹`，外层 PCG 的理论前提不再严格成立**；数值上须验原块方程真残差，不能只看外层递推残差。若后续用松内解追求速度，宜测允许变化预条件器的 Krylov 法，或直接对块系统用 GMRES。此处为线性代数推论，并非上述论文对本原型的性能保证。

[Cai 等](https://arxiv.org/pdf/1308.4605) 在均匀交错网格上用速度 Helmholtz/Poisson 子求解器及几何多重网格构成块预条件，对耦合系统跑 GMRES。其结果中，稳态测试的上/下三角块预条件比投影预条件每次迭代少一个压力 V-cycle；论文也指出投影**作为预条件器**与把一次投影当物理解不同。常系数稳态极限下近似 Schur 逆主项为 `μI`，但物理壁面破坏其周期域的精确交换关系，仍须外层迭代至真残差。论文测试的迭代次数/速度只适用于其网格、边界、实现与硬件，不能换算本项目的毫秒预算。

固定墙与固定 `μ,h` 时，可复用网格拓扑、`D/G/A` stencil、周期/gauge 映射和多重网格层级、限制/插值；变动的入口驱动、体力与 IB 显式散布只是新右端，可用上帧解作初值。若细胞被当作 cut-cell 障碍，活动面/体积及 `A,D,G` 都随位置改变，前述层级至少要更新受影响部分。若细胞用约束 IB，底层规则流体 `A,D,G` 可复用，但插值/散布矩阵 `J(X),J(X)*`、标记间 Schur 作用和其近似随细胞位置改变。[Kallemov 等](https://arxiv.org/abs/1505.07865) 的标记约束预条件研究支持这种区分。复用预条件器直到收敛变差可以实验，但不能假定新细胞排布下仍有效。

计时至少拆为装配、流体子求解、外层迭代、IB/固体耦合、整固定步；同时记迭代次数与真正的动量、散度残差。外层乘以内层工作量才是一次流场更新的成本，若每固体子步需多次耦合迭代还要再乘；不能用单次 stencil 或一次投影耗时代表整步。

## 3. 准稳态与 Rapier 的耦合风险要分开命名

纯准稳态 Stokes 令 `ρ∂_t u=0`，**没有经典流体压力附加质量**。低密度比显式分区的 added-mass 不稳定性证据，例如 [Lācis、Taira、Bagheri](https://arxiv.org/abs/1510.04806)，针对含流体瞬态惯性的不可压 FSI；不能直接当作本准稳态原型必然不稳定的证据。准稳态里仍存在瞬时的黏性流体迁移率：若 Rapier 节点显式接受 `F≈ζ(Ju−V)`，大的 `ζΔt/m_node` 可让速度交替过冲。若施加无滑移乘子，则固体质量/约束响应必须和流体迁移率共同决定本步速度；仅把流体解回传为速度或把同一力既加给 Rapier 又作旧的速度松弛，会使量纲及功率账目不清。标准 IB 的插值/散布互为伴随是交换功率一致的条件，[Peskin](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/95ECDAC5D1824285563270D6DD70DA9A/S0962492902000077a.pdf/the-immersed-boundary-method.pdf) 给出原始构造。

Rapier 0.36 [官方软体文档](https://www.rapier.rs/docs/user_guides/rust/soft_bodies/) 明确节点拥有质量、速度，边/面约束及表面碰撞与面积保持也作用于同一固体。原型需先声明二维深度、力/速度/时间比例、节点质量相对排液质量及哪套机制拥有细胞面积和接触；Rapier 的任意游戏质量不能仅凭名称与真实流体密度相容。最小诊断分三项：①规定运动边界，测 `||Ju−V||`、穿膜通量、流体回力/力矩；②自由刚体或简化质量节点，扫 `ζΔt/m`，比较流固同步与显式交替的稳定域；③再接一个原材料 Rapier 软体，记面积漂移、机械能/外力做功及子步敏感性。若改用非定常 Stokes，再单独扫固液密度比和 `ρΔx²/(μΔt)`，才可讨论 added mass。

## 4. 可直接交给实现 agent 的数值验收

已选域 `Ω=[0,1]²`，x 周期，y=0、1 无滑移，`μ=1`，在 32²、64²、128² 同一物理域求解。采用制造解

```
ψ = sin(2πx) sin²(πy)
u = ∂yψ = π sin(2πx) sin(2πy)
v = −∂xψ = −2π cos(2πx) sin²(πy)
p = cos(2πx) cos(πy)
f = −μΔ(u,v) + ∇p
```

把 `f` 按解析式在各速度面中心直接采样，壁/周期值按解析式施加。为避免实现中的微分复制错误，显式源为 `f_x = 8μπ³ sin(2πx)sin(2πy) − 2π sin(2πx)cos(πy)`，`f_y = −4μπ³ cos(2πx)[1−2cos(2πy)] − π cos(2πx)sin(πy)`。这里 `p` 均值为零；求得 `p_h` 后先减均值再比较。该解同时有两个非零速度分量、两个非零压力梯度，满足真实固壁及周期端；在方格 MAC 采样时 `D(u_exact,v_exact)` 甚至逐单元精确抵消（浮点舍入除外），能先独立检查离散索引。制造解法本身是直接将光滑解析场代入 PDE 构造右端，以上公式为本备忘的推导，非文献原样测试；MAC/边界理论依据见 [Cai 等，§3](https://arxiv.org/pdf/1308.4605)。

记录面速度的面积加权 `L2` 误差、中心压力去均值后的 `L2` 误差，以及二倍加密的误差比；本规则平壁二阶离散应接近 4，若内解或外解残差主导则先收紧容差。原方程真残差单独报 `r_m=Au+Gp−b`、`r_d=Du`；可给 `||r_m||₂/||b||₂` 与 `RMS(r_d)/(U/L)`，但须注明所用网格内积和 `U,L`，并检查净流量及 `u=v=0` 壁值。若某项 `b` 近零，改用 `μU/L²` 归一化动量，不以近零分母放大噪声。预条件残差或压力 Poisson 残差不替代这些量。分岔几何另测，不把本规则域误差阶当作 cut-cell/IB 的承诺。

## 5. 后续与 LBM+IB 的公平对照

固定相同几何、有效 `h/L`、驱动及 `Re=UL/ν`；明确游戏时间/物理时间比、瞬态指标 `L²/(νT)`、细胞弹性相对黏性尺度、固液质量/排液质量与 IB 标记间距。两法分别报墙面位置与滑移/渗漏、压力/流量误差、细胞轮廓及面积误差，再在达到**同一误差容许值**时量整固定步总时间。LBM 须计实现该时间比所需的所有 lattice 步、IB 迭代和同步；MAC 须计全部内外线性迭代、标记处理与 Rapier 子步。一次 LBM collide/stream 与一次 MAC stencil 或投影均不是可比工作单位。若一种方法做准稳态、另一种模拟流体瞬态，应分别标示模型差异，不能把运行差异解释成纯求解器差异。[Cai 等](https://arxiv.org/pdf/1308.4605) 对稳态/非稳态区分、[HemoCell 官方单位映射](https://hemocell.eu/user_guide/concepts/units_and_scaling.html) 支持此比较口径；具体取值仍由产品尺度选择。
