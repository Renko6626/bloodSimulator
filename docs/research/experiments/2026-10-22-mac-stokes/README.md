# Independent MAC / steady Stokes experiment

This directory is a standalone Rust standard-library experiment. It changes no product code or Cargo files. Build and run:

```sh
cd docs/research/experiments/2026-10-22-mac-stokes
rustc -O main.rs -o mac_stokes
./mac_stokes --scene all --sizes 32,64,128 --runs 1 --format csv
./mac_stokes --backend separable --scene manufactured --sizes 32 --runs 2 --format json
./mac_stokes --backend separable --scene localized --sizes 64 --runs 1 --format json --export-dir fields --samples-out samples.csv
```

`--scene` accepts `poiseuille`, `manufactured`, `localized`, or `all`; `--sizes` is a comma-separated list; `--runs` repeats each cold solve. `--backend cg` is the original nested-CG baseline (default), while `--backend separable` uses a standard-library radix-2 FFT in x and tridiagonal solves in y to invert the **same** discrete velocity Laplacian; it requires power-of-two `n`. This is a special inverse for this regular channel, not an irregular-wall solver. Pressure still uses the Schur-complement outer CG. JSON uses `null` for unavailable values; CSV uses `NaN`. `backend_init_ms` records FFT and tridiagonal precomputation; `init_ms_mean` separately records grid/RHS construction; `cold_ms_*` and `warm_ms_*` include only complete Stokes solves. `--samples-out PATH` writes every timed solve with backend, scene, grid size, repetition, cold/warm label, elapsed milliseconds, outer/inner iteration counts, and velocity-inverse call count. A warm solve is reported only for the manufactured case when `runs >= 2`; each next RHS shifts the spatial x phase by 0.31 radians, and the previous velocity and pressure become initial guesses. Warm timing includes the full solve and is allowed to be slower. No warm measurement is produced for identical RHS. Warm metrics compare its solution against the cold solution for the **same** changed RHS and independently report its divergence and momentum residuals. The separable inverse overwrites its velocity output, so the warm initial velocity brings no benefit for that backend; prior pressure still seeds the outer solve.

`--export-dir` writes the final cold solution after timing: `SCENE_N_cells.csv` has `(x,y,ux_center,uy_center,p)` at cell centers, while `SCENE_N_u_faces.csv` and `SCENE_N_v_faces.csv` retain the actual MAC face positions and values. The vertical-face file includes zero-velocity wall faces. The archived phase-zero 64² numerical fields are in `results/fields/`.

The physical domain is `[0,1]²`, viscosity `μ=1`, periodic in x, with no-slip at y=0 and 1. The velocity is stored on true staggered MAC faces: horizontal velocity at `(i h,(j+1/2)h)`, vertical velocity at `((i+1/2)h,j h)`; pressure is at cell centers. Vertical velocity is fixed to zero at wall faces. The horizontal velocity uses odd ghost values outside the walls, giving second-order no-slip enforcement. The discrete system is `A u + G p = f`, `D u = 0`, where `A=-Δ` and `D=-Gᵀ`; p is mean zero. CG on the pressure Schur complement `S=-D A⁻¹ G` enforces divergence. The CG velocity-inverse tolerance is `2e-12 max(||b||₂,1)` and outer tolerance is `2e-9 max(||rhs||₂,1)`. The final velocity comes from a fresh solve of `A u=f-Gp`; the reported momentum RMS computes `A u+G p-f` directly, and the reported divergence RMS computes `D u` directly. `u_l2` is RMS over all active velocity face degrees of freedom and `p_l2` is RMS over cell centers after pressure mean adjustment; these are discrete norms, not spatial-integral L2 values.

Analytic cases, with `k=2π`:

1. Poiseuille: `f=(1,0)`, `p=0`, `u_x=y(1-y)/2`, `u_y=0`. The exact flux per unit depth is `1/12`, peak velocity `1/8`, and wall velocity zero. The face-sampled profile has second-order error because of the discrete wall treatment.
2. Manufactured: `ψ=sin(kx+φ) sin²(πy)`, `u_x=∂yψ=π sin(kx+φ) sin(2πy)`, `u_y=-∂xψ=-k cos(kx+φ) sin²(πy)`, and `p=cos(kx+φ) cos(πy)`. The forcing is sampled from the **continuous** formula `f=-Δu+∇p` on the respective velocity faces, not generated by applying the discrete operator to the exact grid values. Specifically, `Δu_x=-(k²+4π²)u_x`, `Δu_y=-k²u_y-2kπ² cos(kx+φ)cos(2πy)`, `∂x p=-k sin(kx+φ)cos(πy)`, and `∂y p=-π cos(kx+φ)sin(πy)`. Velocity and mean-adjusted pressure L2 errors should fall by about four for each doubling of n; the analytic velocity is divergence free and satisfies no-slip.
3. Localized force: three fixed Gaussian components of physical width `σ=0.05`: `f_x=g(0.30,0.42)-0.7g(0.72,0.62)`, `f_y=0.8g(0.53,0.30)`, with `g(cx,cy)=exp(-[d_periodic(x,cx)²+(y-cy)²]/[2σ²])`. This has no analytic solution; velocity and pressure errors are `NaN`/`null`. It checks residual and solve cost for a spatially concentrated RHS whose width does not change with grid spacing.

Measured results (Xeon Gold 6330, `rustc -O`, f64, CPU 2, no exclusive machine): three warmup runs followed by 50 cold solves per scenario/backend/grid. Each manufactured case additionally measures 49 changed-phase warm solves. All timings below include the complete Stokes solve, excluding setup and output. Raw samples, summaries, source hashes and environment information are in `results/`. These are research measurements, not whole game-step acceptance.

| Grid | Nested CG localized mean / p95 ms | Separable localized mean / p95 ms |
| --- | ---: | ---: |
| 32² | 16.397 / 22.796 | 0.683 / 0.698 |
| 64² | 114.736 / 156.719 | 2.632 / 2.711 |
| 128² | 912.867 / 971.385 | 12.432 / 13.113 |

Manufactured velocity refinement ratios are 4.02 and 4.01; pressure ratios are 4.01 and 4.00. Poiseuille fluxes approach the continuum value 1/12. Complete interpretation and limitations: [Chinese research report](../../2026-10-22-mac-stokes-experiment.md).

Reproduce the measurement and plot from the repository root:

```sh
python3 docs/research/experiments/2026-10-22-mac-stokes/run.py --runs 50 --cpu 2
python3 docs/research/experiments/2026-10-22-mac-stokes/plot.py
```

The runner builds into a temporary directory and records all samples. The plot script independently recomputes their statistics and emits `results/analysis.json`, `overview.png`, and `overview.svg`; it requires the environment's existing NumPy and Matplotlib. Choose another allowed CPU if CPU 2 is unavailable. Re-running overwrites the experiment's result files.

An initial 64² localized-force cross-check exported both backends' fields: maximum pointwise differences were `1.1e-15` for horizontal velocity, `3.1e-16` for vertical velocity, and `2.1e-14` for pressure. The separable run's direct divergence RMS was `2.34e-12` and momentum RMS `1.53e-15`; its five outer iterations used seven velocity-inverse calls and zero inner-CG iterations. With manufactured phase changed by 0.31 radians at 32², the separable warm solve differed from its cold solve by at most `1.8e-15` in velocity and `2.7e-15` in pressure; its direct divergence RMS was `2.05e-14` and momentum RMS `1.27e-12`.

This is a regular channel solver with a CG baseline and a domain-specific separable inverse. It has no irregular vessel wall, branches, ports, immersed membrane, cell forces, Rapier coupling, or fluid transient/added mass. Its timings measure these particular algorithms and do not establish the performance of MAC/Stokes for irregular geometry. The localized RHS is only a forcing pattern, not a model of moving cells. Its pressure has arbitrary additive gauge; only mean-adjusted error is reported. Any later fluid-solid stability discussion must distinguish steady viscous resistance from transient fluid added mass.
