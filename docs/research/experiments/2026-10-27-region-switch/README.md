# 联合 LU 接入与双区域行驶验证

2026-10-27。用户批准把联合 Stokes 路线接入，并选择“先验证固定重叠区域切换”。本轮已修改实际 simulation 路径和显式 Godot 启动入口，采用真实生产步进进行行驶验证；此前独立矩阵实验及原始数据未改。

## 当前行为

两块 64²、网格步长 0.25 的固定流体域，边界为 `[-22,-8]..[-6,8]` 和 `[-18,-16]..[-2,0]`，覆盖出生分叉与上方相邻管段。每区在初始化时构建一次 faer 0.24.4 联合 LU，运行时显式 `Par::Seq`；Rapier 保持有界四线程。

机器人进入邻区更深处时切换：邻区至窗口边缘的最小余量比当前区大 1 单位才交接。共享一个 Rapier 世界，保留全部细胞与机器人句柄。交接复制现有按细胞索引保存的点力历史，在新网格投放这些历史力并求解一次准备场；准备只读物理世界，不推进物体或施加冲量。随后只有当前区域执行一次原耦合推进，解析驱动权重也使用同一区域。

十二物理节点保持，正式解析驱动接入此前六次采样及零拖曳查询省略候选；其他节点数仍走原采样路径。局部网格沿用原四标记、欠松弛与反冲量分摊，没有新增严格膜封堵或全局堵塞反馈。

当前仅为双区原型。两个区域之外继续解析血流，物体仍在原 Rapier 世界运行；未实施全地图详细流体覆盖、远处实体装卸、后台构建队列、通用缓存或磁盘因子。当前 16×16 窗口覆盖互动范围，并未覆盖整个 1280×800 镜头对应的世界范围。

## 实际行驶结果

release、固定 CPU 2–5、使用既有性能实验锁。默认 72 细胞、每帧两个机械子步；以真实 `MoveInput` 沿出生点—上支路往返行驶，不传送物体。20 模拟秒、1,200 帧，完成 6 次区域切换。

| 观测 | 结果 |
| --- | ---: |
| 初始化（两区与整个世界） | 353.427 ms |
| 模拟整步均值／p95／最大 | 8.419／11.285／25.906 ms |
| 流体阶段均值 | 2.785 ms |
| 额外交接均值／最大 | 3.002／4.513 ms |
| 切换帧整步均值／最大 | 11.330／16.234 ms |
| 交接时机器人位置的局部速度差均值／最大 | 0.144／0.179 单位／秒 |
| 进程峰值 RSS（包含初始化） | 38,168 KiB，约 37.3 MiB |

交接时间包括历史复制、标记准备及一次新区域求解，是流体阶段的子集，不能与流体耗时再次相加。没有在切换帧重新分解矩阵。共享主机有波动，计时不含 Godot 渲染、快照及 CSV 写出，不承诺固定设备帧预算。

切换的局部场差约 0.089–0.179 单位／秒，未消除时间上的场差，也未声称玩家无法辨认。没有混合两个独立速度场后宣称仍严格无散度。此阶段验证了预计算与状态交接的可行性；是否需要额外过渡应结合手动体验选择。

全部帧的细胞坐标保持有限，最大面积偏差约 1.997%，无越壁。记录到的帧末散度 RMS 最大约 `3.35e-14`、动量 RMS 最大约 `3.30e-14`、交换冲量误差最大约 `8.06e-10`。这些是帧末记录，并非所有机械子步／交接准备阶段的峰值。尚无长期、密集拥堵、真人操控或全地图验收。

## 验证与复现

已执行：

```bash
cargo test --offline --locked -p simulation runtime::region_tests -- --nocapture
bash scripts/check.sh
godot --headless --path godot --fixed-fps 60 --quit-after 180 -- --local-stokes
python3 docs/research/experiments/2026-10-27-region-switch/run.py
python3 docs/research/experiments/2026-10-27-region-switch/analyze.py
```

项目检查退出 0：8 项单元、5 项集成检查、扩展构建、Godot 导入及原世界／实验场 headless 加载通过；显式局部入口的 180 帧加载也通过。新增永久检查只覆盖真实双区交接：准备不改变物体位置／速度／句柄，往返选择正确，实际推进仍满足原残差和反冲量界。原有 3 项严格流体检查继续通过。一次范围限定的只读代码审阅未发现实质问题，无自动 UI 操作。

手动体验：

```bash
bash scripts/build.sh
godot --path godot -- --local-stokes
```

默认不传该参数时仍使用解析世界。可从出生分叉驶向上支路，再返回，使用已有流向显示；本轮没有新增 UI 操作流程。

新的数据输出应使用新目录：

```bash
python3 docs/research/experiments/2026-10-27-region-switch/run.py --out /tmp/regions-replay
python3 docs/research/experiments/2026-10-27-region-switch/analyze.py --results /tmp/regions-replay
```

`run.py` 构建真实 `region_probe` 示例并记录实际命令、源码／锁文件快照、二进制哈希、环境与退出码；输出拒绝覆盖。`analyze.py` 核对归档源码、切换、机械与数值诊断，并报告当前源码是否仍与测量时一致。`results/` 保留逐帧 CSV、项目检查日志和显式入口日志。相关 Python 语法、本地链接和空白检查通过。

下一阶段需先确定全地图互动区的布局、范围与内存预算，再决定预载多少区域。血管几何／离散算子变化时需要重建相应因子；玩家和细胞移动、既有外部压力幅度变化保持当前矩阵不变。旧独立实验的“正式文件未改”与根目录哈希描述测量时点，本轮正式接入不改写这些历史哈希。
