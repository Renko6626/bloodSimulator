# Marker coupling probe: read-only audit (2026-10-23)

Scope: `/tmp/sunyunbo/mac-stokes-b-20261022/markers/{main.rs,README.md,results/results.csv}`. No product code changed. The volume operator was audited separately.

## Confirmed

- `J` samples MAC faces using the same Peskin weights that `S` uses to spread each marker's **total** fluid force with `1/h²`; hence `h² (S F)·u = F·(J u)` algebraically. The code checks each actual stencil sums to one. `ds=2πR/m` enters exactly once in `F=κ ds(V-Ju)` and the diagonal `1/(κ ds)`. Sources: `main.rs:284-345,482-496,523-527`; `README.md:5-8`.
- Each mobility column is formed by spreading a unit marker force, solving the complete pressure-coupled Stokes system, and sampling its velocity. `solve_stokes` constructs the pressure Schur RHS, iterates `-D A⁻¹G`, and finally solves `A u=f-Gp`; this is `J K S`, not `J A⁻¹ S`. Sources: `main.rs:173-260,499-510`.
- The dense solver symmetrizes its input (`(H+Hᵀ)/2`) and requires positive Cholesky pivots. Before this, the program measures `||H-Hᵀ||F/||H||F` and aborts above `1e-6`; recorded values reach `5.03e-11`. The independent final Stokes solve followed by the actual force-law residual (at most `2.60e-13` RMS in these rows) provides a stronger check that symmetrization did not materially change these particular solutions. The `1e-6` guard itself is much looser than roundoff, so README's “roundoff-level antisymmetry” should describe observed rows, not a guaranteed acceptance criterion. Sources: `main.rs:353-387,408-410,512-535`; `results.csv` self rows.
- `reaction = -ΣF` and torque uses the same opposite-force sign. `ΣF·Ju=h²Σ(SF)·u` is checked. For a converged finite-resistance solution, `ΣF·V=h²u·Au+Σ|F|²/(κ ds)` is the correct steady work balance; reported self-row error peaks at `2.24e-12`. Units are consistent with `F` being a 2D marker total force and `κ` a resistance per arc length. Sources: `main.rs:335-345,424-442`; `results.csv`.
- `lagged` uses `F=κ ds V`, equivalent to one explicit step with prior fluid velocity zero. Its final force-law residual is `Ju` and is correctly nonzero; at `(32,24,32)` it is `0.4255` RMS, with slip `0.3549` RMS. The reported overshoot takes the maximum marker **x** velocity divided by `Vx=0.1`, so `6.36` means a maximum `u_x≈0.636`, not a 6.36-fold norm or a claimed steady coupled solution. Sources: `main.rs:407-410,540-559`; `results.csv` corresponding rows.
- The dense normal and tangential figures sample 720 circle points and sum absolute relative velocity projections times arc-length spacing. They measure local velocity mismatch integrated over the circle, not net flux or volume loss. Sources: `main.rs:411-423`; `README.md:32`.

## Timing and evidence limits

- `self total_ms` starts before grid/backend/marker creation and includes the stencil partition check, **2m mobility Stokes solves**, assembly, the mobility antisymmetry calculation, matrix copy/diagonal setup/Cholesky, and **one final Stokes solve**. It stops at `main.rs:534`, before `inspect`, force-balance reduction, field CSV export, overshoot sampling, printing, and the additional lagged solve. Thus the README sentence “excludes diagnostics” is imprecise: it includes the partition and antisymmetry checks but excludes post-solve diagnostics. `assemble_ms` includes the mobility solves; `factor_ms` includes matrix copy, diagonal modification, and Cholesky; `final_fluid_ms` includes final force spreading and final Stokes solve. Sources: `main.rs:482-559`; `README.md:21`.
- `lagged total_ms=final_fluid_ms` times only its force construction, spread, and one Stokes solve. It reuses the already initialized backend and runs **after** the complete self experiment and its diagnostics/export; it is a warm isolated call, not an alternative full cold-run total. A complete invocation executes `2m+2` Stokes calls across both CSV rows. Sources: `main.rs:545-559`; `README.md:11,21`.
- The CSV has six cases and one cold run per case on a nonexclusive host. It supports only exploratory single-run timings and the reported smooth-circle, fixed-geometry sensitivity trends. It supplies no repetitions, distribution, p95, real-time frame budget, moving-marker assembly cost, dynamics, or impermeability evidence. Sources: `README.md:3,21,32-36`; `results.csv` (12 data rows).

## Risk assessment

No substantive coupling, force-unit, reaction, power, or reported-residual formula error found in this fixed-circle probe. The key interpretation risks are treating `total_ms` as dynamic per-frame cost; treating the warm `lagged` number as a comparable cold total; claiming a p95 from single smoke runs; and promoting finite-κ slip reduction into a `κ→∞` no-slip or impermeability result. At `(32,24)`, self slip decreases from `0.01780` to `0.00569` as κ rises 16→64, but every tested κ remains finite. `README.md:23-36` states this limit correctly except for the diagnostics/timing wording noted above.
