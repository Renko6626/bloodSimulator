# LBM core 限定只读核查（2026-10-23）

对象：`/tmp/sunyunbo/lbm-20261023/core/main.rs` 与 `README.md`；只核对公式和口径，未改源码、未重跑全套。结论：所查范围未见会改变本轮结论的实质算法错误。下列两处比较口径须保留。

- D2Q9 的 `CX/CY/W/OPP` 配对正确。`equilibrium` 使用二阶平衡态；`guo = w(1−1/(2τ))[3(c−u)+9(c·u)c]·F`，与 `ρu=Σfc+F/2` 相配。`ν_lu=(τ−1/2)/3`、`dt=ν_lu h²` 在 `ν_phys=1` 下给出一致的物理速度换算 `u_phys=u_lu h/dt`（`main.rs:3-6,55-68,115-124,140-143`）。
- push-stream 对 y 外边界或固体邻点将 `post[k]` 放回本点 `OPP[k]`，x 用周期下标；每条被挡 link 保留其粒子质量，Guo 源的零阶矩为零，未见墙面丢质量。这个规则是 link 中点 bounce-back；弯曲通道由格心 solid mask 决定实际阶梯墙，不能等同旧 Brinkman 真曲线/有限渗透墙（`main.rs:125-133,144-150`）。
- blob 的每点物理总力为 `(Γ/4)(V−Ju)`；向格点散布密度 `wF/h²` 后，乘 `dt²/h` 变为 lattice force。反向积分乘 `h³/dt²` 恢复物理合力，`reaction=−ΣF`。这在参考密度 1、单位纸外深度下量纲一致。标记位于中心附近，未发生核触及壁面或周期折返；Peskin 四点核在该位置完整覆盖，未见权重截断（`main.rs:70-82,90-109,235-253`）。
- 每个 LBM 步先用当前分布及**上一力的 half-force** 算 `Ju`，再生成新点力进行碰撞。最后 `force_law_velocity_relative_rms` 则用最后状态速度和最近一次点力计算，能显露这一步滞后；这不是零初速单次 `lagged` MAC 行。烟雾结果该残差为 `9.40e−10`（无量纲，已除 `V=.1`），合力平衡为 `6.94e−18`；两者只支持这次固定标记稳态样本（`main.rs:90-109,209-253`；`blob4-g025-32-result.csv`）。
- 停机量为速度每 `window_steps` 差分的 RMS，除以实际窗口时长和物理速度尺度 `.1`，相当于以 `ν/L²=1` 归一化；强制物理时间 `steps·dt≥1` 且三次连续低于阈值。`solve_ms` 从首次 advance 到停止含每步力更新和窗口检查；`post_ms` 从停机后的状态连续执行并计时全部 `post_steps`，含每步点力更新，场导出在计时之外（`main.rs:161-202,273-286`）。

比较提示：LBM `div_center_fd_rms` 是格心中心差分，MAC `div_rms` 是原生面通量差，不可同名直比。LBM 与 MAC blob 的标记**物理位置、Γ 和目标 V**相同，但插值/散布位置分别在 LBM 格心与 MAC 速度面，且 LBM 有有限 Re 与瞬态逼近；反力接近可作为交叉核对，不是要求两场或反力相同的精度标准。LBM `post_ms` 是固定几何、已接近稳态的后续步成本，不包含从静止到稳态的 `solve_ms`、Rapier 或真实移动标记。
