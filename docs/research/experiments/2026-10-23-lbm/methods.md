# LBM 对照：尺度、力闭合与公平计时

2026-10-23。供独立 D2Q9/BGK 原型使用；沿用仓库 `docs/research/2026-10-23-coupling-experiment.md` 的二维单位域、`μ=1`、少量有限阻力点。本备忘只界定本轮实验与判读，不代表产品路线变更。

## 1. 格子单位与低 Re

设格距 `h=1/N`，一个格步代表物理时间 `dt`，固定的物理参考密度（单位换算常量）为 `ρref`，局部物理密度为 `ρphys(x)=ρref ρlu(x)`；参考运动黏度 `νp=μ/ρref`。D2Q9/BGK 的 `cs²=1/3`，`νlu=(τ−1/2)/3=νp dt/h²`，故 `dt=(τ−1/2)h²/(3νp)`；`ulu=up dt/h`，`Ma=|ulu|/cs`。`τ=1, ρref=νp=μ=1` 时，`dt=h²/6`。32² 与 64² 分别为 `1.6276e−4`、`4.0690e−5`；若模拟一个真实 `1/60` 秒，分别需约 **102.4**、**409.6** 格步，跨帧须保留小数时间余量。该映射直接决定持续演化成本；静态首次收敛另计。官方 [HemoCell 单位说明](https://hemocell.eu/user_guide/concepts/units_and_scaling.html) 也分别约束格速、`τ` 与物理单位。

`Re=UL/νp` 衡量对流惯性相对黏性；`Ma=ulu/cs` 衡量 LB 可压误差，两者不能互代。平直单位高通道均匀体力 `f=1`、`μ=1` 的 Stokes 峰速 `1/8=0.125`，以通道高为 L 时 `Re=0.125`；曲管把 `f` 降为 `0.1` 预计把特征速度及 Re 约降十倍，但曲管峰速须实测。规定移动 blob `V=0.1` 则用 `L=1` 有 `Re=0.1`，以直径 `0.3` 有 `Re=0.03`。这些虽小，MAC 的准稳态 Stokes 与 LBM 的非定常 Navier–Stokes 仍非同一方程；差异中包含约 `O(Re)` 的惯性尺度，系数由几何决定，不能把全部偏差归为离散误差。若要更接近 Stokes 且保持 `μ=1`、`Γ=0.25`、`V=0.1`，可降 `ρref`：例如 `ρref=0.1` 给 `νp=10`、参考 Re 降十倍、`dt` 也降十倍，故同一物理时间格步多十倍。必须同时改力单位及报告成本。另一选择是同一 `ρref,μ` 下扫 `V/f`，但要重新声明比较工况。

不能只把 `τ` 调得很大来减少格步：`νlu`、格速和边界误差一同变化，需要再次验剖面、通量、质量漂移、曲墙位置和稳定性。BGK 足以完成这轮方法对照；MRT 可调不同矩的松弛与边界误差，但并不免除物理 `dt` 和各格步，只有实测 BGK 稳定或精度问题值得下一轮提案。[Ginzburg 与 d'Humières 2003](https://doi.org/10.1103/PhysRevE.68.066614) 讨论多反射边界及松弛选择；此处不据此预设 MRT 必需。

## 2. Guo 力与少量点的同一步闭合

约定 `F_lu` 是格点的**格子力密度**，即每格步输入分布函数的一阶矩增量。Guo 形式采用 `ρlu ulu=Σ_i fi ci+F_lu/2`；碰撞源含 `1−1/(2τ)`，并以这个含半步力的速度计算平衡态。[Guo、Zheng、Shi 2002](https://doi.org/10.1103/PhysRevE.65.046308)。**给定物理力密度** `g_phys`（本实验的恒定体力也是此类）时，`F_lu=g_phys dt²/(ρref h)`，不额外乘局部 `ρlu`；**给定物理加速度** `a_phys` 时，先取 `g_phys=ρphys(x)a_phys`，才得到 `F_lu=ρlu(x)a_phys dt²/h`。定义点力 `P_j=(Γ/m)(V_j−J_j u_p)`，`P_j` 为二维单位深度的力；核权重 `w_{xj}` 满足求和为 1，格点 `g_phys(x)=Σ_j w_{xj}P_j/h²`。因此 `F_lu(x)=Σ_j w_{xj}P_j dt²/(ρref h³)`，不乘局部 `ρlu`。不可将总点力直接乘 `dt²/h`，也不可漏掉 `1/h²` 散布和参考密度除法。`u_p=ulu h/dt`；物体接收 `−Σ_jP_j`，与 MAC 的反力定义一致。

因为 `P_j` 又取当前含 `F_lu/2` 的流速，同一格步有一个小代数闭合。设 `u0_p(x)=(Σ_i fi ci/ρlu)h/dt`，令 `S` 表示核权重散布，`J` 表示相同权重插值，则

```
u_p = u0_p + [dt/(2ρref h²)] diag(1/ρlu) S P
[I + diag(Γ/m) · dt/(2ρref h²) · J diag(1/ρlu) S] P
    = diag(Γ/m) (V − J u0_p).
```

这是仅解 Guo 半步力的局部/小 `2m×2m` 系统，**并非**把流体未来碰撞、传播和稳态响应全部隐式化。可先在 `m=1/4, Γ=0.25` 检验该闭合及与 MAC 的差异。若取上格步速度估力，须标作 lag 近似，测最终 `RMS(P/(Γ/m)+Ju−V)/|V|` 及反力偏差；不能声称它无条件稳定。MAC 快照中 `Γ=0.25,m=4` 的一次滞后闭合误差 **4.48%**、反力偏差 **6.33%** 是参考量，不是 LBM 误差容限。流体每一格步的 `stream/collide` 都要使用该步定义的力；若选择冻结物体位置/速度若干格步，阻力也应每步据其约定速度和当前流速处理，或明确整个力冻结造成的时间滞后。机械模型降频可单列计时；不能把一次力乘以机械间隔误当每格步力。HemoCell 的[时间尺度分离说明](https://hemocell.eu/user_guide/concepts/units_and_scaling.html#time-scale-separation)也只说明降频有延迟取舍。

## 3. 墙、停机与成本口径

平壁 halfway bounce-back 把几何壁放在流体与固体格点的中点；对格线平行的 Poiseuille 流可得到二阶精度，但误差系数及部分有效壁位/滑移会受松弛和驱动细节影响，应扫 `τ` 与 `N`，不能从单一剖面外推到曲壁。[Zou 与 He 1997](https://arxiv.org/abs/comp-gas/9611001) 给出平壁结果；[Ginzburg 与 d'Humières 2003](https://doi.org/10.1103/PhysRevE.68.066614) 说明通过多反射处理斜壁；[Bouzidi 等 2001](https://doi.org/10.1063/1.1399290) 针对曲边链接插值。当前曲管 `lower=.12+.04sin(2πx)`、`upper=.88−.08sin(2πx)` 若只用二值固体格点与 halfway BB，实际是阶梯墙；几何壁偏差可达 `O(h)`，窄处通道宽度和阻力也会偏。报告掩膜面积、截面宽、中心线/通量与真实曲线的距离，不宣称曲壁二阶。平壁的人工滑移成因有不同分析；[Meng 等 2015](https://arxiv.org/abs/1508.02209) 指出平行壁方向分布的处理也重要，因此不把所有偏差武断归因于 BGK。

稳态初始静水要报 **格步数及对应物理时间**。不要用绝对 `max|u^{n+1}−u^n|<ε_lu`：这里 `ulu` 可仅 `10⁻⁵–10⁻⁴`，极易在尚无流动时触发。建议每 `K≈max(50, N²/10)` 步比较完整场和通量，定义 `E_u=RMS(u_p^{n+K}−u_p^n)/Uref`、`E_Q=|Q^{n+K}−Q^n|/Qref`，`Uref` 取解析或目标量级（平壁 `0.125`；曲管 `0.0125` 仅为预估；blob `0.1`），不取当前近零解范数；连续 2–3 个块满足预先给定容限（如 `10⁻⁴`）后，再查解析平壁剖面/通量、曲管跨截面通量与密度漂移。此阈值是实验停机建议，非精度证明；可按采样噪声与目标误差调整。应记录停机前后相隔一个扩散尺度的指标，防止慢模态假收敛。`L²/νp` 给保守时间尺度，实际最低模态因边界而异。

与 MAC 对照固定同一物理域、`h`、`μ`、驱动、障碍形状、`Γ,V`、输出位置和允许的速度/通量误差；区分 LB 对流/可压模型差异与离散/曲墙误差。分别列：①静态新场首次达到稳态的总毫秒及格步；②从已收敛场持续演化每 60 Hz 固定步所需格步、流体/点力/机械计时和整步 mean/p95；③如果用少于物理映射的格步，声明它是额外时间近似并报告流动相位/反力变化。单格步 MLUPS 只能作内部性能指标。5 ms 是**整固定步**目标，不能拿一次 collide/stream 与一次 MAC 求解直接相比。

### 下轮检查点

1. `32²/64²` 平壁 `f=1`：核对 `dt, F_lu, ρu` 半力、解析 `u(y)=y(1−y)/2`，报峰速、流量误差、密度漂移、`τ` 扫描和从静水到稳态的格步。
2. 曲管 `f=0.1`：同一真几何对照 MAC，记录阶梯截面误差、通量一致性、`Re/Ma`、首次稳态与每 1/60 物理秒成本；勿用静态初始化时间代替持续步成本。
3. `Γ=0.25, V=0.1, m=1/4`：验证点力总和/相反物体力、Guo 半力小系统与 lag 版本的闭合残差及反力；逐格步更新力，单列机械降频成本。达到这三个检查点再判断 BGK 是否足够及 5 ms 是否可行。
