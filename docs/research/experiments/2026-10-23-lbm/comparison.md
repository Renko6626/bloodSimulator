# LBM 局部实验可复用参照（2026-10-23）

范围：旧实验均为无量纲二维单位方域 `[0,1]²`，`h=1/n`，x 周期，y=0、1 静止壁；MAC 用 `μ=1` 解准稳态 `−Δu+∇p=f`。力和流量按单位纸外深度计。以下是现成数据的比较口径，不需重跑旧实验。

## 1. 平直通道 Poiseuille

在 `f=(1,0), μ=1, H=1` 下，连续解为 `u_x(y)=y(1−y)/2`、`u_y=0`、常数压力；峰值 `1/8=0.125`，单位深度体积流量 `Q=∫₀¹u_xdy=1/12≈0.0833333333`。一般式 `u_x=f_x y(H−y)/(2μ)`、`Q=f_x H³/(12μ)`。建议报告截面流量 `Q(x)=h Σ_j u_x(x,y_j)`、其沿 x 的最小/最大值及相对解析误差，另报格心速度对 `u_x(y)` 的 RMS/最大误差和壁面滑移。只有在 LBM 的物理单位映射确实给出同一 `f, μ, H`、相同墙位置后，这些数值才可直接比较。

旧 MAC 的 `mass_flux` 是 **x=0 的竖向 MAC 面**上 `h Σ_j u_face(0,j)`，不是格心场求和（`2026-10-22-mac-stokes/main.rs:370`）。`results/summary.csv` 已有 32、64、128 格对应 `0.08349609375`、`0.08337402344`、`0.08334350586`，分别比连续值高 `h²/6`；这是旧离散壁处理的误差，不是 LBM 的目标值。现成 `results/fields/poiseuille_64_cells.csv` 可看 64² 速度/压力，`poiseuille_64_u_faces.csv` 可复算旧 MAC 面流量；解析式本身适用 LBM 32² 等任何网格。旧场只有 64²，不必为获取旧 32² 场重跑实验。

## 2. 四点 blob 的同条件局部比较

直接读取 `docs/research/experiments/2026-10-23-coupling/results/fields/field_blob_n32_m4_p0.25.csv`（1024 个格心，列 `x,y,u,v,p`）及同目录 `markers-summary.csv` 中 `self,blob,32,4,gamma_total,0.25` 行。该 **self 自洽解**的四点位于 `(0.5±0.075,0.5)`、`(0.5,0.5±0.075)`，目标速度 `V=(0.1,0)`，总阻力 `Γ=0.25`，每点总力 `F_a=(Γ/4)(V−J_a u)`；散布到面上的体力密度为 `Σ F_a w/h²`。背景体力为零。`reaction=−ΣF` 是流体给标记的反力，每单位纸外深度；不能把 `Γ=0.25` 当成每点阻力。定义见 `markers/main.rs:264-289,354-395,474-479` 和 `markers/README.md:7`。

该行可直接作数量级参照：`reaction_x=−0.02351094083`、`reaction_y≈−1.37e−20`、`reaction_torque≈−3.25e−19`，因此施于流体的合力 x 为 `+0.02351094083`；标记相对目标速度的 RMS 滑移 `0.06649922258`；最大标记采样速率/`0.1` 为 `0.06208795447`；力律残差 RMS `1.07e−15`。这几个量只有在 LBM 使用同一四点位置、力律、权重/核、边界及稳态收敛口径时才能数值直比；否则列为不同模型的结果，不设“应等于 MAC”门槛。`lagged` 行是单次显式施力，不能代替 `self` 场或反力参照。

旧 MAC 导出的 `(x,y)=((i+1/2)h,(j+1/2)h)`，`u,v` 是相邻 MAC 面速度的算术平均，`p` 是格心零均值 gauge；见 `markers/main.rs:508-530`。故若 LBM 也以 `((i+1/2)h,(j+1/2)h)` 标记格心且数组按 y 行、x 列，可按坐标逐行配对，**坐标本身吻合**。场速度的逐格 RMS、最大绝对差、中心线/截面曲线和上游/下游扰动可比较，但 MAC 输出已作格面插值，格心速度不应要求逐点机器精度相等。压力只可在相同物理压力单位映射后分别去均值，再比较起伏/梯度；LBM 密度不能直接对比旧 `p`。旧 `div_rms=3.55e−12` 是原生 MAC 面通量差 `D u` 的格心 RMS，既不是导出格心场差分，也不是 LBM 密度守恒/有限差分散度；只可各自报告算法定义，不能按同名列直接比。`momentum_rms=1.12e−15` 同理是旧稳态离散方程残差。

## 3. 曲壁结果的边界

现成 `docs/research/experiments/2026-10-23-coupling/results/fields/volume_channel_32_1024.csv` 和 `volume-summary.csv` 是弯曲收缩通道的 **MAC+Brinkman 二值阶梯体积惩罚**：几何真墙 `y_b=0.12+0.04sin(2πx)`、`y_t=0.88−0.08sin(2πx)`，但固体指示函数采在速度面、惩罚系数 `κ=1024`，穿透非零。若 LBM 使用 bounce-back 墙，其有效墙位置、台阶形状和无滑移/渗漏误差机制不同。可并列报告真实几何位置、有效通道宽度、流量范围、壁面法向/切向速度误差，并说明墙模型；不能把两个方法在同 n 的误差差值称为求解器精度阶次。旧 `volume-summary.csv` 的 `fluid_q` 排除受罚面，`full_q` 包含整个盒子，先匹配积分域再比较。旧 `solve_ms` 排除了几何/预处理且是稳态一次求解，LBM 需多步达到稳态；不要据此计算“公平加速倍数”。定义见 `volume/README.md`。
