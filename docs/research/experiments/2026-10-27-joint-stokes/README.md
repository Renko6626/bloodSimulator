# 完整 Stokes 联合稀疏 LU 小实验

2026-10-27。用户批准试用固定窗口的速度—压力联合分解。**短测有效：两轮流体均值约 5.32 / 6.94→2.95 / 2.95 ms，整步约 10.12 / 12.60→8.35 / 8.76 ms。** 一次较大的因子求解替代原压力 CG 中的反复速度逆，代价是更贵的初始化和约增加 14 MiB 的进程峰值 RSS。

仅为独立候选，未接入正式源码、依赖或 Godot 默认入口；后续选择见[待办](../../../STATUS.md)。

## 方法与公平性

从[几何复用候选](../2026-10-27-geometry-query/run.py)生成冻结副本。保留原 `A`、压力梯度／散度、自然牵引开口、十二物理节点／六次解析采样、显式点力耦合、四线程 Rapier。当前几何和黏度固定，移动细胞只改变右端项，因子可跨子步复用。

联合候选直接组装 `K = [A, -Bᵀ; -B, 0]`，解 `K [u;p] = [f;0]`。窗口有 4,916 个速度、2,484 个压力未知量，矩阵阶数 7,400、非零条目 43,502。没有增加压力罚项、钉住额外自由度或修改方程；开口仍采用原单侧压力梯度。

使用 faer 0.24.4 的带行主元稀疏 LU，默认 COLAMD／AUTO 参数，每次分解与求解显式 `Par::Seq`。禁用 faer 默认特性，只启用 `std`、`sparse-linalg`。基线和候选采用相同依赖特性及锁文件，原锁定包版本均保留。参考 [faer 稀疏 LU API](https://docs.rs/faer/latest/faer/sparse/linalg/solvers/struct.Lu.html)。

基线仍为自写稀疏速度分解＋热启动压力 CG，动态容差 `1e-4`。联合候选直接解 f64 系统，不再使用 CG 容差和初值，没有通过进一步放宽精度获得加速；CSV 的 `iterations=0` 表示没有压力 CG，不表示没有计算。

候选运行时不构建、持有旧速度 Cholesky 因子。测试构建才保留旧速度因子与原 CG 方法，作为独立参照。运行时保留未使用旧模块及字段，release 编译有 4 条未使用警告；本轮没有将研究副本整理成正式接入版本。

两轮反序主计时和另两条独立 fluid profiling，每条 6 模拟秒／360 帧，共 2,160 帧；72 细胞、两个子步、默认无操作输入。CPU 2–5 固定，使用既有性能实验锁。计时只覆盖模拟 tick，快照和 CSV 写出在计时外。共享主机存在波动，不将短测收益当作目标设备保证。

## 性能

| 主计时，均值 ms／帧 | 原 Schur-CG | 联合 LU |
| --- | ---: | ---: |
| 第一轮流体 | 5.321 | 2.949 |
| 第一轮整步 | 10.121 | 8.352 |
| 第二轮流体 | 6.936 | 2.949 |
| 第二轮整步 | 12.604 | 8.764 |

两轮流体加速约 1.80 / 2.35 倍，耗时降低约 44.6% / 57.5%；整步减少约 1.77 / 3.84 ms。整步 p95 为 14.056→10.964、16.096→10.621 ms；候选仍出现 51.183 / 65.299 ms 的最大单帧，不能宣称已消除尖峰或完成游戏帧预算验收。

独立细分计时中，基线每帧平均 14.911 次压力迭代、20.911 次速度逆；联合候选每帧 2 次完整系统求解、0 次旧速度逆。调用所处理的矩阵规模不同，不能按次数比直接计算加速倍数。

联合求解本体合计约 2.302 ms／帧，约 1.151 ms／子步；网格求解约 2.582 ms／帧，完整流体约 2.954 ms／帧。剩余网格时间含原方程残差测量及右端组装等。求解尚每次分配 RHS、结果及 scratch，未混入缓冲复用优化。

## 初始化与内存

两轮联合矩阵组装与因子构建合计约 89.8 / 93.5 ms，其中符号阶段约 5.6 / 5.6 ms，数值阶段约 82.0 / 86.0 ms。因子固定后，逐子步没有重新分解。

整个 `Simulation::new_local_world` 为基线约 194.8 / 207.5 ms、联合约 250.6 / 217.5 ms；还包含地图、物理和初始背景场求解，存在主机波动，不能把差值全部归给分解。

主计时进程峰值 RSS 为基线 14,936 / 14,940 KiB、联合 29,208 / 29,108 KiB，即约 14.6→28.4–28.5 MiB。它包括初始化临时量、代码页和整个模拟，并非独立因子的精确驻留内存。faer 的此层公开 API 未提供完整数值因子条目统计，本轮未修改库源码获取它，也未声称测得精确因子载荷。每次求解的 scratch 布局为 59,263 字节，另有输入／输出向量。

## 数值检查与动态差异

普通 CG 构建通过 4 项检查，联合构建通过 5 项：原有 3 项严格流体检查、原有同矩阵速度逆对照，以及新增联合块算子与严格 CG 对照。所有测试保留原断言，CG 参照容差恢复为 `2e-9`。

新增审计用两组已知的非零 `u,p`，从原 `A`、原梯度／散度独立形成右端，包括非零约束右端，再由联合 LU 恢复已知解；最大绝对误差 `5.340e-14`。对实际零散度约束、非零力输入，联合解相对严格 CG 的速度最大差 `2.616e-10`、压力最大差 `1.505e-9`；联合解的散度 RMS 最大约 `3.49e-16`、动量 RMS 最大约 `5.67e-16`。

六条动态轨迹均完成，有限值与既有机械范围检查通过，同配置两轮及 profiling 的保存观测复现。跨算法有精度差异：累计流入相对差约 −0.00322%，每秒采样细胞中心最大差约 0.01983（参考直径 1.4），末帧所在管段相同。最大面积偏差为基线／联合约 3.362% / 3.353%，均无越壁。不能称为跨算法逐位等价或玩家不可辨认。

联合候选的动态散度 RMS 峰值约 `2.78e-14`，动量 RMS 峰值约 `3.02e-14`；基线散度约 `2.04e-4`。本次消除压力迭代，同时得到更严格的线性系统解；耦合模型本身仍采用原近似。

本轮只做默认交通的 6 秒小试，没有长期、密集拥堵、强操控、游戏 UI 或渲染验收。短测支持保留联合 LU 候选，不自动切换正式后端。

## 源码、复现与验证

- `joint.rs`：固定 faer 符号／数值因子及求解；`assembly.rs`：从原分量数据组装 K。
- `audit.rs`：独立原块算子回代及严格 CG 对照；仅注入临时测试构建。
- `run.py`：生成两个副本、恢复严格参照、构建及六条轨迹；`analyze.py`：核对哈希、数值、重放与统计。
- `results/`：原始 CSV、测试和构建日志、进程峰值内存、环境、独立锁文件、清单与统计。FACTOR 日志不出现在联合运行时，分析脚本也核对这一点。

```bash
python3 docs/research/experiments/2026-10-27-joint-stokes/run.py --out /tmp/joint-stokes-replay

rustfmt --check --edition 2024 docs/research/experiments/2026-10-27-joint-stokes/joint.rs docs/research/experiments/2026-10-27-joint-stokes/assembly.rs docs/research/experiments/2026-10-27-joint-stokes/audit.rs
```
