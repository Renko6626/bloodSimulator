# 独立数值与计时审计

日期：2026-10-26。审计对象是本目录下独立研究程序及其输出，不是正式游戏实现。`solver/`、`dynamics/` 由其他 agent 维护，本审计只写 `review/`。

## 代码与方程审阅

| 项目 | 发现 | 级别 / 限制 |
| --- | --- | --- |
| MAC 符号 | `A=-Δ`；周期 x 格面和固定 y 法向速度下，当前 `gradient` 与 `divergence` 满足 `D=-Gᵀ`，故 `S=-D A⁻¹G` 号向为正。需以最终解的原方程残差验真，不能只信内层迭代计数。 | 当前规则通道通过结构审阅；不代表不规则墙。 |
| 作用与反作用 | Solver 将 `F=γ(V-Ju)` 定义为点对流体的力；`spread` 以相同核权重并除以 `h²`，所以在网格面积内积下与 `sample` 互为伴随。动态 Stokes 分支给 Rapier 的反冲量是 `-F SUB_DT`；派生点速度是半个所选节点加半个 12 节点平均，冲量回传使用相同系数。 | 符号、面积和时间因子结构正确。准稳态流体不保留动量，`fluid_impulse` 只是积分的界面施力，不是储存流体动量变化。 |
| 最终残差 | Solver 的 `force_law_rms` 从最终全力重新解得的速度计算 `F/γ+Ju−V`，并另算 `A u+Gp−f` 和 `Du`；这比只报 marker-CG 递推残差可靠。20 行最终静态数据最坏分别是 `3.399e-11`、`2.881e-13`、`2.381e-11`（力律、动量、散度 RMS）。 | 已对该组输出验真口径和最坏值；绝对速度尺度约 `0.1`，不能改称真实 RBC 百分比误差。 |
| 嵌套容差 | Marker-space CG 的每次 `JKS` 乘法调用 Stokes，Schur 内层绝对停止阈值 `2e-9 max(||rhs||,1)`；点力方向变小时，压力解可能提前停止，算子随方向尺度变化。外层阈值 `1e-9 max(||V-Ju0||,1e-4)`。 | **理论限制，当前数据未触发实际失败。** 最终静态力律 RMS 最大 `3.399e-11`，动态自洽版最大 `9e-12`；将来换更密/更强点群时仍以最终残差判定，不为此预先扩建求解机制。 |
| 固壁核 | `stencil` 丢弃墙外速度面后检查各分量权重和；若核被截断便拒绝该 marker。 | 当前场景靠墙点不能求解；本轮点群在内部，不是近壁软体证据。 |
| 静态场景 | `probe.rs` 用单位方域、周期 x、平直 y 墙；16/32/64 个细胞各四个规定速度的阻力点。没有 Rapier，自洽阻力点按固定 V 求解。 | 可验证流场改变、受力及格距成本；不能证明自由软体耦合、分岔、窄缝或真实 RBC 精度。 |
| 动态时间层 | 每个 Rapier 子步从旧位置/速度冻结 marker，自洽 Stokes 即时求该状态平衡；滞后版用上一子步场算力后求一次新场，第一子步额外求无细胞基流。两者的 `-F SUB_DT` 冲量施于本子步，均属显式固体时间耦合。LBM 在同样冻结 marker 下推进多个格步，每格步重算阻力，并汇总 `-F dt_LB`。 | 机械输入和平均力的意义可比较，物理流体方程不同。固定 V 的 Stokes 自洽不等于含 Rapier 质量与接触的隐式强耦合；滞后版有意不闭合，不能以自洽阈值判作求解失败。 |
| 动态场景 | 16 细胞初始中心横/纵间距为 `0.2/0.22`；32 细胞为约 `0.1114/0.22`，半径 `0.045`。只驱动中间两细胞，力 `0.18` 持续 `0.5 s`。 | 16 细胞前 1.4 秒内无全局求解器接触，是无接触流体传力证据；32 细胞第 1 帧已有全局接触计数，不能据它单独声称纯流体效果。`solver_contacts_*` 还可能含自接触，`min_gap` 只采节点距离。 |
| 动态计时 | 最终版 `whole_ms` 从帧入口到诊断结束，含 marker 构建、流体和 Rapier、诊断；四种 CSV 写入均在计时之后，也不含初始化和可视化。`fluid_ms` 不含 Stokes 前的 marker 构建，Stokes 内部计时又把核准备单列。 | 应按整帧 `whole_ms` 判断本程序成本；尚非正式游戏固定步。 |

## 静态数据复核

已读 `solver/results/samples.csv` 的 20 行、8 个场景组合：32²/16 细胞、64²/16、64²/32 各 3 次；128²/64 各 1 次；每细胞四个规定运动阻力点。这些是重复求解同一静态场，3 次重复不构成动态 p95。最大点力与散布网格力积分之差 `2.442e-15`；所有核权重最小和为 `1.0`。平壁 Poiseuille 的最大速度误差依网格为 `1.221e-4 / 3.052e-5 / 7.629e-6`，约每次缩小四倍，只验证这一平壁基流。

| 场景 | 32² / 16 | 64² / 16 | 64² / 32 | 128² / 64 |
| --- | ---: | ---: | ---: | ---: |
| 静止点、背景驱动总耗时均值 | 4.940 ms | 28.443 ms | 25.273 ms | 177.720 ms（单次） |
| 同向移动点、无背景总耗时均值 | 5.399 ms | 33.122 ms | 26.893 ms | 208.741 ms（单次） |

`total_ms` 包含点核准备、耦合求解和诊断；不含每案例的 solver 构造与无细胞基流解，也不含场导出和 Rapier。64²/32 较 64²/16 快的行，其 marker 布局从 4×4 改为 8×4，且压力迭代更少；不是增加细胞数能提速的证据。静态点 offset 为 `0.045`，动态点由半径 `0.045` 的机械节点与质心中点得到，两者不能逐点比。每帧两个子步的实际成本见下节。

静态滞后 `lagged_samples.csv` 以无细胞场为 prior，32²/16 一次完整 Stokes 更新约 `1.04–1.07 ms`，但新场阻力律 RMS 为 `0.02641–0.02667`，约为规定运动速度 `0.1` 的 26%；运动场通量 `0.034119` 对自洽 `0.024344`。这是从无细胞场起步的一次快照；连续动态的上子步场误差明显小得多，不能把 26%外推到所有时间点。单细胞同输入对照中 matrix-free 的流体点合力 `+0.023510940832189` 与旧 dense reference 的物体反力 `−0.02351094083` 符号相反、幅值一致。

完整 Stokes 的全域动量由背景体力、点力与固定墙牵引平衡。`grid_force_balance_abs` 只核对 `S` 的点力积分，不包括墙力；静止点案例的背景驱动也不能记成纯细胞对墙的牵引。

## 动态数据复核

九组最终 `frames.csv` 各 360 帧，前 30 帧剔除计时，余 330 帧的 p95 用 nearest rank。独立逐行检查帧号连续、`t≈frame/60`、16 细胞组的总直接驱动冲量均为 `0.18`，并重算整步 mean/p95/max。以下均为单次 6 模型秒轨迹的研究程序测量，未包含地图、机器人、渲染与正式游戏系统。

| 组别 | 整步 mean / p95 / max（ms） | 最高力律 RMS | 首次全局 Rapier 接触帧 |
| --- | ---: | ---: | ---: |
| 16 细胞、32²、自洽 Stokes | 9.190 / 14.359 / 14.723 | `6e-12` | 105 |
| 16 细胞、32²、滞后 Stokes | 2.262 / 3.255 / 3.313 | `7.846e-5` | 105 |
| 16 细胞、32²、LBM | 4.320 / 5.843 / 5.991 | 不适用 | 105 |
| 16 细胞、64²、自洽 Stokes | 36.530 / 52.344 / 61.606 | `9e-12` | 105 |
| 16 细胞、64²、滞后 Stokes | 6.146 / 9.987 / 10.556 | `7.978e-5` | 105 |
| 16 细胞、64²、LBM | 51.821 / 69.467 / 70.046 | 不适用 | 105 |
| 16 细胞、32²、无反馈 | 0.579 / 0.789 / 0.999 | 不适用 | 87 |
| 32 细胞、32²、自洽 Stokes | 11.220 / 16.613 / 18.705 | `2e-12` | 1 |
| 32 细胞、32²、无反馈 | 1.456 / 1.962 / 2.531 | 不适用 | 1 |

32² 滞后版是唯一三项整步耗时都低于 5 ms 的本轮流体案例；64² 滞后版的 mean/p95/max 均超 5 ms。此结论限于这台非独占机器、当前输入和研究程序。动态 `stokes_momentum_rms` 输出格式为固定 12 位小数，极小残差在 CSV 中四舍五入为 `0.0`，不能仅靠动态 CSV 复算它的真实上界；静态 CSV 用科学计数保留了值。自洽与滞后版的离散散度按最终场验算，最大约 `6.2e-11`；所有耦合组的反冲量不平衡最大 `1.76e-10`，含 f32 Rapier 回传舍入。`fluid_impulse` 对 Stokes 只是 `ΣFΔt` 的接口交换积分，绝非流体储存动量变化。

**接触前的实际传力：** 16 细胞第 15 帧全局接触数为零，驱动/非驱动粒子表面最近距约 `0.0955`；非驱动最大 `|vx|` 自洽/滞后/LBM 分别为 `7.690e-5 / 7.351e-5 / 4.963e-5`，无反馈控制为零。第 30 帧也无接触，约 `0.0807` 间隙。由此可认定该段未直接施力细胞受到流体传力；之后第 105 帧流体组首次报告全局接触，不能把整条轨迹都解释为纯流体效果。32 细胞组第 1 帧已有全局求解器接触计数，虽驱动组到非驱动组采样节点间隙仍为正；其来源可能含其他细胞、自接触或预测接触，因此该组不构成无接触传力的独立证据。

同网格自洽与滞后的 360 帧逐细胞中心最大距离差为 32² `5.984e-6`、64² `6.450e-6`，最大速度差分别 `2.292e-5`、`8.256e-6`。它们说明**这条弱阻力短轨迹**的滞后误差较小，与静态无细胞起步 26% 闭合偏差不冲突；无一般误差界。自洽与 LBM 的中心最大差为 `1.342e-4 / 6.831e-5`，包含准稳态与瞬态流体模型差别，不能叫 Stokes 数值误差。

实际运行的只读复核命令为：

```bash
python3 docs/research/experiments/2026-10-26-stokes-feedback/review/audit_data.py
```

脚本输出与 `summary.json`、`comparisons.json` 一致，并逐行比较 `cells.csv` 的 5760 个对应单元中心和速度。它通过读取已有数据复核统计与时间戳，未执行新的流体 CPU 基准；本审计未改 `solver/` 或 `dynamics/`。

## 未验证项

- 不规则固定墙、分岔与开放端口的算子及边界力；规则通道 FFT 速度逆不能直接外推。
- 活跃近景真实细胞数、窄缝分辨率、长期接触和拥堵、正式游戏整步 `<5 ms`。
- 真实红细胞百分比误差；二维有限阻力穿透模型缺少与真实三维 RBC 的标定及独立验证。
- UI、正式游戏交互与目标玩家硬件；本轮按约定不运行这些流程。
