# 有限阻力 Stokes 反馈实验

日期：2026-10-26。用户批准独立调研和实验，探索近景几十个软体细胞下的真实局部流体反馈；允许可渗透的细胞近似，不要求精确膜封堵。正式游戏后端、依赖及模块边界保持原状。

结果见[总报告](../../2026-10-26-stokes-feedback.md)。静态与动态实验已运行，九条动态轨迹共 3240 帧；局限及独立核查见各子目录。`plot.py` 从最终动态 CSV 生成 `figures/overview.png` 和 SVG，不重新运行物理模拟。

## 本轮问题

1. 相比持续推进 LBM，准稳态 Stokes 的有限阻力耦合是否能用较细网格获得可接受的整步成本？
2. 推动局部细胞群时，流体能否对没有直接施力的细胞产生可观察的影响？需要区分流体传力与 Rapier 接触传力。
3. 规则通道结果的适用范围是什么，不规则血管壁、开口边界和窄缝还缺哪些证据？

## 产物分工

- `solver/`：MAC Stokes 求解器、有限阻力自洽耦合、静态精度和规模实验。
- `dynamics/`：真实 Rapier 软体动态实验，以及匹配输入的 LBM / 无流体对照。
- `review/`：一手资料研究与独立数值、计时核查。

各目录的说明记录实际命令、已完成案例和限制；此文件中的研究问题不代表已通过验收。

## 共用边界

- 沿用 12 节点软体、每细胞四个内部流体标记和总阻力系数 0.25；若某个对照更改参数，必须单独标出。
- Rapier 负责机械积分；流体反馈以相反冲量回传，不叠加正式游戏的速度松弛驱动。
- 流体内部单位沿用旧研究，尚未对应正式游戏。静态不同网格使用一致物理几何；若改变细胞大小或密度，不称为等精度对照。
- 规则周期通道不代表分岔或开口血管。机械接触墙若没有进入流体算子，不算流体墙面验证。
- 准稳态 Stokes 与具有惯性的 LBM 方程不同；匹配输入的输出差异不全部归因于离散误差。
- 正式性能测量使用 `flock /tmp/blood-stokes-feedback-bench.lock taskset -c 2 ...` 串行运行，单线程 release；机器非独占。初始化、求解、机械推进、诊断及文件输出分别说明。
- 5 ms 是希望达到的整个模拟固定步预算。流体单次求解、降频后的平均成本和耗时峰值不得相互替代。
- 不运行 UI 自动交互，不添加正式产品测试或 CI，不安装新的重要依赖。
