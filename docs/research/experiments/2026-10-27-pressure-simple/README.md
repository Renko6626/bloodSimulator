# 压力 SIMPLE 小实验

2026-10-27。用户批准“稍微试一试”后，在临时副本上评估 diffusive SIMPLE 类压力预条件。**结果为负：每帧压力迭代从 14.91 增至 53.98，流体均值从约 5.48–6.10 增至 22.06–22.09 ms。保留原普通 CG，不接入此候选。**

正式源码、依赖和默认入口未改。faer 接入继续留在[暂缓待办](../../../STATUS.md)；本轮不混入 faer，也没有新增外部依赖。

## 做法与范围

从[几何复用候选](../2026-10-27-geometry-query/run.py)生成两个副本。两者保留自写稀疏速度因子、原 Schur 算子 `S = B A⁻¹ Bᵀ`、压力热启动、`1e-4` 动态停止条件、十二物理节点／六次解析采样、耦合与有界四线程调度。候选构建一次固定 `P = B diag(A)⁻¹ Bᵀ`，用同一自写稀疏 Cholesky 精确施加 `P⁻¹`，将压力 CG 改成 PCG，仍按未预条件残差停止。

`pressure.rs` 装配 P，包括自然牵引开口的单侧压力梯度。`run.py` 仅将这些方法、一个压力因子字段和标准 PCG 更新注入临时 Grid；压力因子采用未埋点的既有稀疏实现，避免污染速度逆的细分计时。`audit.rs` 从原梯度、速度对角、散度独立计算 `B diag(A)⁻¹ Bᵀ z`，核对它与输入残差一致。

这属于文献中的纯 diffusive SIMPLE 近似，未测试加权混合、LSC、AMG、AMGCL 或 PETSc；原理见 [Pimanov 等的交错网格研究](https://arxiv.org/html/2307.05266v2)。文献的周期狭窄多孔几何与本项目自然牵引开口不同，不外推其性能结果。

每变体两轮反序主计时、另各一条 fluid 细分计时，每条 6 模拟秒／360 帧，共 2,160 帧。72 细胞、两个子步、默认无操作输入；CPU 2–5 固定，使用既有性能实验锁。计时为模拟 tick，快照和 CSV 在计时外。共享主机仍有明显长尾，这个短测只判断方向，未追加长时测试或参数搜索。

## 结果

| 主计时，均值 ms／帧 | 普通 CG | SIMPLE-PCG |
| --- | ---: | ---: |
| 第一轮流体 | 6.102 | 22.092 |
| 第一轮整步 | 11.240 | 26.815 |
| 第二轮流体 | 5.483 | 22.058 |
| 第二轮整步 | 10.230 | 26.833 |
| 每帧压力迭代，两轮相同 | 14.911 | 53.981 |

两轮流体变慢约 3.62 / 4.02 倍，整步约 2.39 / 2.62 倍。对应每机械子步压力迭代约 7.46→26.99。第一轮整步 p95 为 15.045→34.909 ms，第二轮为 13.469→34.494 ms。

独立细分计时：

| 均值／帧 | 普通 CG | SIMPLE-PCG |
| --- | ---: | ---: |
| 速度逆调用 | 20.911 次 | 59.981 次 |
| 速度逆墙钟 | 3.837 ms | 10.209 ms |
| 预条件器应用 | 0 次 | 53.981 次 |
| 预条件器墙钟 | 0 ms | 6.215 ms |
| 网格求解 | 4.753 ms | 19.321 ms |

不仅增加了约 6.2 ms 的预条件器应用开销，收敛本身也变差，导致速度逆调用约增加 2.87 倍。迭代数是直接观测，不能将负结果只归于线程或共享主机噪声。本轮未测谱，不能声称已确定具体特征模态或条件数。

额外压力因子有 2,484 个未知量、30,891 个存储数值项，持久数值与索引数组有效载荷 494,256 字节（约 0.47 MiB，不含 Vec 头、容量和临时量）。两轮该因子构建约 31.9 / 34.0 ms。整个世界初始化的原始计时已保存，存在主机波动。

## 数值与限制

普通 CG 构建通过 4 项检查，SIMPLE 构建通过 5 项：原有 3 项严格流体检查、原有同矩阵速度逆对照，以及候选新增 P 作用核对。测试构建恢复 `2e-9`，未放宽原断言；动态构建恢复 `1e-4`。独立 P 核对最大 `|Pz-r|` 为 `5.506e-15`，两组非平凡 RHS 的 `rᵀP⁻¹r` 为正。严格真实分叉冷启动压力迭代同样从 23 增至 108。

六条短轨迹完成，有限值及既有机械范围检查通过，同配置两轮与 profiling 的保存观测复现。跨算法轨迹存在差异：每秒采样中心最大差约 0.02724（参考直径 1.4），末帧所在管段相同；累计流入相对差约 −0.00203%，上支路流体份额差约 0.00128 个百分点。最大面积偏差普通 CG／SIMPLE 约 3.362% / 3.349%，均无越壁。不能把这组结果称为逐位等价，或当作长期／玩家辨识验证。

本轮否定的是这一固定 P 及其精确稀疏求解组合在当前窗口的性能；没有据此否定其他压力预条件器或 CFD 库。按照用户的小实验范围，到此停下，不自动扩大求解路线或调参。
