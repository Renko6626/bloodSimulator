# 点力欠松弛实验独立审计

日期：2026-10-26。本审计只检查独立研究程序与定稿 CSV；`solver/`、`dynamics/`、旧实验及正式游戏均未由审计方修改。

## 实现和时间层

新 `solve_relaxed` 的试探力逐点为 `F_trial=drag·(V_current−J_current u_old)`；`prior.marker_forces` 按固定标记索引提供 `F_old`，然后计算 `F_new=(1−ω)F_old+ωF_trial`。**同一份 `F_new`** 通过当前标记位置的核散布进完整 Stokes 右端，也放进返回的 `Solution.marker_forces`。动态 harness 每个机械子步只取这份力，给 12 个 Rapier 节点施 `−F_new·(1/120 s)`，并用 `+F_new·(1/120 s)` 记界面交换。原有点到节点的半个所选节点、半个质心权重未变；节点合冲量及关于质心的力矩与该标记反冲量相符。没有仅滤流速而把原始力回传给 Rapier，也没有重复加力。

`prior=None` 的首子步先解无细胞背景流，按零历史点力混合，再解施力后的新场；首帧两子步合计 3 次完整 Stokes 解，之后每帧 2 次。`ω=1` 直接走原 `solve_lagged`。`prior` 的标记数被核对，实验中细胞及每细胞四点的顺序固定；只核对长度不能辨识同长度数组被换序，属于当前固定对象实验的明确边界。

动态代码相对上一轮 64 细胞 harness 保留半径 `0.045`、质量 `1`、每细胞总阻力 `Γ=0.25`、膜和面积参数、阻尼、驱动力 `0.18`、前 `0.5 s` 驱动、每帧两次 Rapier 子步和原 `1e-6` 冲量阈值。非有限节点与面积翻转检查仍在。实验没有降低阻力、缩小细胞、放宽阈值或改变正式游戏模块。

新增诊断定义准确但需分清含义：

- `force_law_rms` 是最终场下所有 `F/drag+Ju−V` 分量的 RMS，`force_law_max_component_abs` 是其单分量绝对最大值，均为速度单位。欠松弛不保证这两项为零。
- `exchange_power=Σ F_new·(Ju_new−V)` 是该子步界面的流体与机械交换合功率；`exchange_power_mean` 是两个等长子步的算术平均，**不是一帧累计功**。正值不等于力/反力不守恒，非正帧均值也不证明每个子步严格耗散。
- `point_force_update_ms` 只计旧场采样完成后的点力向量分配、试探力和混合循环。它不含点采样、散布、完整流体解或 Rapier；不能从旧版本整步用时中直接相减作为净新增成本。

## 冻结几何核对

冻结 probe 读取旧轨迹的第 1 帧真实节点轮廓，固定标记位置、速度零，并撤去扰动源；没有运行 Rapier。Poiseuille 和局部点力种子的流场原由别的源产生，probe 特意给当前细胞历史点力填零，因此种子本身不是 `u_old=K S F_old` 的自洽状态。判断衰减时应避开首次过渡。程序对有 prior 的每次更新记录 1 次完整 Stokes 解，独立从最终返回的力和点速度复算 RMS、最大分量、功率和散布合力。

| 16 / Poiseuille | `6.36e-11` | `3.66e-14` | `4.16e-9` | `0.2714` |

64 细胞两个种子的中段观测比与冻结单模态估计 `|1−0.5(1+1.82053)|≈0.41026` 相符；初始场包含其他模态，尤其 ω=.3 的局部点力比率不是单一常数。此结果证明指定固定几何/扰动下衰减，不是任意移动接触场景的谱界或稳定保证。冻结 probe 的 ω=1 输出与本次旧接口逐位一致；动态负例对旧归档的独立比较见下。

## 动态结果独立复算

定稿 manifest 的 11 个源码/锁文件 SHA-256 与当前文件一致，保存的 release 二进制 SHA-256 也与 manifest 相同。五条正例均完成 `360` 帧、`6` 模型秒；ω=1 负例在第 `16` 帧触发原有冲量失配 `2.70109e-6`，仅保存 15 帧，未进入完整性能统计。正例逐帧有限，最大界面冲量不平衡为 `2e-11`，没有面积翻转或非有限节点；64 细胞从第 1 帧就有全局 Rapier 接触计数，不能用它证明无接触传力。前 30 帧剔除后，每条正例以 330 个完整帧求 nearest-rank p95，阶段 p95 未相加。

两轮同 ω 的逐细胞轨迹字节一致，计时差异不能归为不同物理结果。与旧自洽参考的最大中心差按固定直径 `0.09` 归一，64 细胞 ω=.5/.3 分别约为直径的 `0.000507 / 0.001245`；最大速度差 `5.10e-4 / 6.21e-4`。这些只属于本次短时、低速、周期直管模型，尤其不能用小位置差遮蔽最大单点力律残差 `0.00833 / 0.01169`，也不能称作真实红细胞的物理误差上界。帧平均交换功率五条正例均无正值，但只有帧平均被归档；冻结诊断中正功率曾出现，不能推断每子步总是耗散。

ω=1 负例前 15 帧与旧 64 细胞 lagged 失败归档的 **23 个公共非计时 frame 字段逐值相同**，960 行 cell 文件的 **12 个公共字段逐值相同**；第 16 帧同一阈值失败。这证明该新 API 的 ω=1 行为在所测动态输入下保留旧结果，新增诊断没有混入比较。历史自洽轨迹是不同时间的运行；不能将其 40.922 ms 与本轮约 10 ms 直接相除宣称精确生产加速倍数。旧自洽参考中 Rapier 均值约 `3.812 ms`，而本轮 64 细胞 Rapier 均值约 `4.14–4.40 ms`；5 ms 整步预算即使流体更快也很紧。本轮 16/64 细胞正例的整步均值和 p95 均大于 5 ms。

```bash

```

脚本退出码 0，直接重算每条完整轨迹的整步和点力更新时间、力律残差、与旧自洽中心/速度差、重复轨迹和负例公共字段；也复算冻结范数。另用只读 Python 对当前保存二进制和 manifest 的 SHA-256 作了核对。未重新运行流体算法或大性能测试。

## 结论范围

ω=.5 和 .3 在本次 64 细胞密集布局完成六模型秒，避免了旧 ω=1 的快速反馈放大；ω=.5 在这个输入下有更小的中心差和力律残差。二者仍有时间滞后、有限穿透与接触，并且整步 p95 未达 5 ms。结果不支持直接推广到其他高密度排列、强推动、近壁血管、长期拥堵或正式游戏后端；这些技术路线仍需由用户另行选择。
