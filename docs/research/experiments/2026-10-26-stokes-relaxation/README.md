# 有限阻力 Stokes 点力欠松弛动态实验

日期：2026-10-26。本目录是独立研究程序；没有改正式游戏、旧实验或部署。`dynamics/` 从 [64 细胞原动态探针](../2026-10-26-stokes-64-cells/dynamics/src/main.rs) 复制场景，依赖仅 Rapier 0.36.1 和本目录的 `solver/`。新求解器只在点力更新上作欠松弛：以前一子步的点力 `F_old` 与按旧流场计算的试探力 `F_trial` 混合，`F_new=(1-ω)F_old+ωF_trial`，再对 `F_new` 做一次完整 Stokes 流场求解。首子步没有历史点力，先求背景场，所以流场调用数多一次。`ω=1` 对应原一次更新方案。

每个子步将同一 `F_new` 散布到流体，并将 `-F_new × (1/120 s)` 按原点到 12 节点的相同插值权重返还 Rapier。没有另建点力状态，历史点力来自上一子步 `Solution.marker_forces`；标记顺序始终为固定细胞索引和节点 0/3/6/9。Rapier 是唯一机械积分器。

## 场景与范围

- 64² 单位方域，x 周期、y 上下无滑移；这里只验证规则直管。每细胞半径 0.045、接触粒子半径 0.0045、12 节点、质量 1、膜 12 Hz、面积 30 Hz、阻尼 0.5。细胞直径为 5.76 格。每细胞四内部阻力点，总 Γ=0.25；允许流体穿过细胞。
- 64 细胞排 8×8；16 细胞排 4×4。只驱动各布局中央附近两个细胞，每细胞 x 向力 0.18，前 0.5 s 施加后撤去。60 Hz，每帧两个 Rapier 子步，每子步更新点力与流体一次。没有改变半径、材料、阻力、驱动或诊断阈值。
- 64 细胞分别用 ω=0.5、0.3 运行两轮 360 帧，第二轮反序；16 细胞用 ω=0.5 运行一条 360 帧。ω=1 的 64 细胞负例只跑最多 32 帧，预期可能失败，失败文件照实保留，不算作成功性能测量。
- 与完整自洽解比较使用旧归档的逐帧 `cells.csv`：64 细胞是 [四线程自洽参考](../2026-10-26-stokes-64-cells/reference-results/optimized-t4-r1/cells.csv)，16 细胞是 [64² 自洽参考](../2026-10-26-stokes-feedback/dynamics/results/stokes64-16/cells.csv)。逐帧逐细胞比中心、速度、面积。位置差另除以固定直径 0.09；不对接近零的参考位移做相对除法。旧计时不参与新方案的精确加速倍数计算。

## 数据和计时口径

`results/<case>/frames.csv` 包含流体、Rapier、整步及诊断计时；每帧流场调用数、最终场力律 RMS、最终场最大单分量力律误差、流体/节点交换冲量、面积、节点跳动、接触、网格速度和非驱动细胞速度。`point_force_update_ms` 只计既有旧场采样后点力向量分配及 ω 混合循环，两个子步求和；它不含采样、Stokes 求解或 Rapier。`exchange_power_mean` 是两个子步 `ΣF·(Ju−V)` 的平均，正值仅说明此非自洽更新瞬时可向机械系统供能，不自动视为失败。`cells.csv` 记录每细胞中心、速度、面积，`outlines.csv` 和 `fields.csv` 保存第 1、15、30、60、120、360 帧的真实轮廓与 16×16 采样流场。

整步 `whole_ms` 包含构造标记、流体求解、Rapier 和帧诊断，不含 CSV 写入和快照输出。完成的 360 帧轨迹剔除前 30 帧，剩余 330 帧算均值和 nearest-rank p95，同时单列全帧最大值。每轮在 Xeon Gold 6330 上用共享锁固定 CPU 2–5 同插槽四个物理核，主机非独占。`results/manifest.json` 记录源/锁/二进制 SHA-256、命令、CPU 拓扑、进程用时和退出码。失败案例的部分 CSV/日志保留，`analyze.py` 不把它计作完整性能结果。

## 结果

冻结求解器后，五条松弛轨迹均完整运行 360 帧；ω=1 短负例在第 16 帧因交换冲量失配 `2.70109e-6` 停止，仅保存前 15 帧，不计作完整性能。两轮相同 ω 的逐细胞中心输出完全一致，计时有明显长尾波动。下表数值单位 ms，三元组均为剔除前 30 帧后的**均值 / p95 / 最大值**；末列另列 360 帧全帧整步最大值。

| 场景 | 整步 | 流体 | Rapier | 全帧整步最大 |
| --- | ---: | ---: | ---: | ---: |
| 16，ω=.5 | 5.485 / 6.640 / 76.926 | 4.658 / 5.629 / 75.861 | 0.732 / 0.967 / 1.085 | 76.926 |
| 64，ω=.5，第一轮 | 9.875 / 12.846 / 14.687 | 5.562 / 6.711 / 7.923 | 4.175 / 7.012 / 7.571 | 14.868 |
| 64，ω=.3，第一轮 | 10.624 / 14.080 / 81.754 | 6.079 / 7.636 / 75.041 | 4.402 / 7.377 / 9.020 | 81.754 |
| 64，ω=.3，反序第二轮 | 10.555 / 14.634 / 52.256 | 6.258 / 7.954 / 43.127 | 4.142 / 6.742 / 11.933 | 52.256 |
| 64，ω=.5，反序第二轮 | 10.539 / 16.953 / 118.957 | 6.268 / 10.343 / 111.540 | 4.132 / 6.897 / 12.049 | 118.957 |

正常松弛案例首帧有 3 次完整流场求解，其余每帧均为 2 次（每子步一次）。点力向量分配与 ω 混合的帧均耗时约 0.0011 ms（16 个细胞）和 0.0039–0.0045 ms（64 个细胞）；该埋点不含旧流场采样和 Stokes 求解，不能从旧实验耗时中直接相减当作净开销。64 细胞两种 ω 的整步均值、p95 和最大值均超过 5 ms；16 个细胞 ω=.5 的均值也超过 5 ms。本机非独占，不能把两轮差异归因于算法，也不能和旧自洽实验的 40.92 ms 跨运行直接算精确加速倍数。

64 细胞 ω=.5/.3 的最大面积相对偏差分别约 **0.1486% / 0.1485%**，最大节点帧位移约 0.00128；流体/节点交换冲量误差不超过 `2e-11`。全局 Rapier solver contact 从第 1 帧非零，不能将计数逐个归给具体细胞对。最大最终场力律 RMS 分别为 `7.135e-4 / 9.662e-4`，最大单点单分量 `|F/drag+Ju−V|` 分别为 `0.00833 / 0.01169`，说明它们并非自洽力解。完整场景中帧平均交换功率没有正值；ω=1 负例在写出的 15 帧中有 11 帧为正，不能单凭功率符号断言稳定性。

与旧自洽参考逐帧逐细胞比，64 细胞最大中心距离：ω=.5 为 `4.56e-5`（直径的 `0.000507`），ω=.3 为 `1.12e-4`（直径的 `0.001245`）；最大细胞速度差分别为 `5.10e-4`、`6.21e-4`。16 细胞 ω=.5 最大中心距离 `7.37e-5`（直径的 `0.000819`）。这是指定低速、短时轨迹的数值差异，不是普遍物理误差上界。ω=1 负例前 15 帧与旧一次更新负例的 `frames.csv` **23 个公共非计时字段**完全一致，960 行 `cells.csv` 的 **12 个公共字段**也完全一致；新增诊断字段没有混入该相等性检查。

静态 solver 验证与动态轨迹属于不同证据；现有周期直管、可穿透细胞与固定核不能验证窄血管、分叉、真实膜排液或游戏目标设备的性能。完整逐帧数据和统计见 `results/`。

## 复现

在仓库根目录运行：

```bash
python3 docs/research/experiments/2026-10-26-stokes-relaxation/run.py
python3 docs/research/experiments/2026-10-26-stokes-relaxation/analyze.py
```

`run.py` 用 `cargo build --release --offline --locked` 和 `/tmp/sunyunbo/blood-stokes-rayon-target`，再以 `flock /tmp/blood-stokes-feedback-bench.lock taskset -c 2-5` 执行每条轨迹。`--case omega05-16 --frames 2 --out /tmp/...` 可做短功能检查，不会覆盖正式结果。程序没有浏览器或 UI 交互，也没有新增永久测试。
