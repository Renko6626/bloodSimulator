# 同域 48×48：96² 与 192² 性能对照

2026-10-27，按用户要求测试 192²。**相同 48×48 范围下，192² 的流体阶段约 12.85 ms／帧、模拟整步约 17.85 ms／帧，分别为本轮 96² 的约 5.28 倍、2.51 倍。** 两个窗口预计算时的进程峰值 RSS 约 142–144 MiB。当前机器上的模拟本身已超过 60 FPS 的 16.67 ms 帧预算，尚不含渲染。

本轮保留此前发现的域内泵驱动缺失问题，只测量分辨率成本，不实施新驱动模型，不修改正式参数。

## 方法

沿用[大窗口实验](../2026-10-27-wide-window/README.md)的生成器和探针，在两个冻结副本中保持相同物理范围与中心：

- 两个 48×48 域，中心 `[-14,0]`、`[-10,-8]`，原点 `[-38,-24]`、`[-34,-32]`。
- 本轮基线为 96²、h=0.5，候选为 192²、h=0.25；两组实际流体源码仅 N、H 两行不同，力密度和冲量积分随 H 一致变化。
- 保留联合 LU、自然牵引开口、72 个十二节点细胞、六次解析采样、四个流体标记、两个机械子步和相同驾驶目标／控制逻辑；各自流场会影响实际输入和轨迹。
- 固定 CPU 2–5、使用既有性能锁，release／offline／locked 构建；96→192→192→96，各 20 模拟秒／1,200 帧，共 4,800 帧。

计时包含各自轨迹下的真实流体耦合与 Rapier 步进；快照、写盘和额外观测在 tick 外。使用本轮匹配 96² 数据比较，不与上一轮的不同主机负载直接换算收益。

## 性能

| 指标 | 48×48／96² | 48×48／192² |
| --- | ---: | ---: |
| 流体均值，两轮 ms／帧 | 2.413 / 2.457 | 12.788 / 12.905 |
| 模拟整步均值，两轮 ms／帧 | 6.993 / 7.248 | 17.695 / 18.014 |
| 模拟整步 p95，两轮 ms／帧 | 8.943 / 9.387 | 24.495 / 25.835 |
| 整个模拟初始化，两轮 ms | 263.5 / 327.8 | 719.5 / 967.4 |
| 进程峰值 RSS，两轮 MiB | 34.86 / 33.54 | 142.25 / 144.29 |
| 两域速度＋压力未知量 | 8,191 / 7,309 | 33,192 / 29,565 |
| 额外交接均值，两轮 ms | 2.162 / 2.545 | 13.883 / 14.597 |
| 额外交接最大，两轮 ms | 3.511 / 5.093 | 21.776 / 34.046 |

额外交接已包含在整步／流体计时中，不应重复相加。192² 整步最大帧为 60.77 / 73.28 ms；共享主机存在波动，本轮不构成目标硬件帧率保证。RSS 是持有两域及初始化临时量的整个进程峰值，不是单个因子的精确存储。

网格每边翻倍，实际未知量约增至四倍，流体耗时增至约五倍。本轮没有进一步拆解 LU 回代、诊断、标记或内存访问时间，不能将所有增量都归为某个内核，也不凭两点外推复杂度。192² 保留了原小窗口的 h=0.25 空间分辨率，但扩大到 48×48 后成本已明显增加。

## 检查与适用限制

两种冻结副本各通过 8 项既有单元、5 项集成检查；四条行驶均完成，分别有六次交接。同配置两轮的保存细胞、流场和机器人坐标观测完全复现。

192² 帧末散度／动量 RMS 峰值约 `1.42e-13 / 1.55e-13`，冲量交换误差最大 `6.53e-9`，最大面积偏差 12.71%，无越壁。原有范围检查通过不代表驱动正确或精度足以满足玩法。

在共同采样点 `[-16,0]`，初始水平速度 96²／192² 分别为 −5.101／−5.347 单位／秒，仍然反向。提高分辨率没有解决[此前定位的域内泵驱动缺失](../2026-10-27-wide-window/README.md#发现泵进入域内后缺少驱动)。未改背景驱动或开展长期、真人手感、Godot 渲染验收；这些性能属于当前未修正模型。

PYTHONDONTWRITEBYTECODE=1 python3 docs/research/experiments/2026-10-27-wide-192/run.py --out /tmp/wide-192-replay

`run.py` 复用未改动的前项生成器／探针；`analyze.py` 复用前项观测检查，本目录数据中的 `base` 表示 96²、`wide` 表示 192²。分析退出 0 表示来源、数值范围及归档数据检查通过，不表示反向流可接受。

`results/` 保存正式来源与两组实际修改源码、所有被调用实验脚本、锁文件、构建／既有测试日志、命令、环境、二进制哈希、原始 CSV 和统计。运行／分析、Python 语法、来源哈希、参数差分和本地链接检查通过；正式代码、依赖和 Godot 参数保持。未新增正式测试，未重跑 Godot／全项目检查。
