# faer 稀疏速度求解实验

日期：2026-10-27。用户批准试用 faer，范围是独立替换速度块求解；完整 Stokes 联合分解与正式后端切换不在本轮范围。源码、数据与复现命令见[实验目录](experiments/2026-10-27-faer-speed/README.md)。

## 结果

faer 有稳定方向的收益，幅度有限。两轮匹配主计时的流体阶段减少 0.35–0.86 ms，整步减少 0.29–0.99 ms；整步耗时降低约 2.6%–8.2%。独立细分计时中，速度逆从 4.787 降到 4.257 ms／帧，约降低 11.1%。共享主机有明显调度波动，不把这两轮换算成固定设备承诺。

| 主计时，均值 ms／帧 | 自写稀疏 | faer | 节省 |
| --- | ---: | ---: | ---: |
| 第一轮流体 | 6.769 | 5.908 | 0.860 |
| 第一轮整步 | 11.973 | 10.986 | 0.986 |
| 第二轮流体 | 6.257 | 5.903 | 0.355 |
| 第二轮整步 | 11.057 | 10.769 | 0.288 |

整步 p95 两轮为 15.334→14.611、15.179→13.905 ms。faer 的最大单帧仍达 53.532 / 31.670 ms，不能据此宣称已经消除尖峰或稳定满足某个帧预算。以上只计模拟，未包含 Godot 渲染、快照及 CSV。

## 对照口径

沿用固定 64² 真实分叉窗口、每个速度分量 2,458 个未知量、72 个物理细胞、每帧两个机械子步、十二物理节点／六次解析采样、压力 Schur-CG 容差 `1e-4` 和几何查询复用。压力初值、耦合、外层四线程池及 u/v 并行方式保持。

基线为研究候选中的自写最小度重排序＋稀疏 Cholesky。faer 固定为 0.24.4，禁用默认特性，只启用 `std` 与 `sparse-linalg`；低层稀疏 LLT 使用默认 AMD 排序与 AUTO 选择，每次分解和求解显式 `Par::Seq`。本场景自动选择 simplicial。矩阵只在初始化分解，后续右端项变化时复用因子；每次求解分配结果和 faer scratch，本轮未加入缓冲池等额外机制。

两变体临时副本都包含相同 faer 依赖／特性，已有锁定包版本保留。正式 Cargo.toml、Cargo.lock 及 crates 源码哈希前后相同。两轮各按相反顺序测量，每条 30 模拟秒；另各一条 fluid 细分计时，共 10,800 帧。Linux CPU 2–5 固定，使用既有性能实验锁。实际命令、二进制哈希、来源哈希及工具链／CPU 信息已归档。

## 速度逆仍占大头

| 独立细分计时，均值 | 自写稀疏 | faer |
| --- | ---: | ---: |
| 压力迭代／帧 | 15.711 | 15.711 |
| 速度逆调用／帧 | 21.711 | 21.711 |
| 单次速度逆墙钟 | 220.491 µs | 196.091 µs |
| 全帧速度逆墙钟 | 4.787 ms | 4.257 ms |
| 网格求解 | 5.848 ms | 5.301 ms |
| u/v 因子求解累计工作 | 6.418 ms | 5.772 ms |
| 完整流体 | 6.231 ms | 5.690 ms |

分量累计工作会重叠，不能加到速度逆墙钟上。自写版本还保留已有前代／回代内部计时，faer 只记录整体调用；因此细分计时用于定位，最终收益以关闭 deep span 的两轮主计时为准。

faer 下，速度逆仍占网格求解约 80.3%。每帧调用数等于压力迭代数加 6，库替换没有减少这一数量。当前自写候选已经使用稀疏 Cholesky，faer 在此规模继续做同类分解与三角求解；排序后的数值存储项减少约 7.0%，没有出现复杂度层面的变化。

## 初始化与内存

自写两个分量分别存储 30,507 / 31,247 个数值项，faer 为 28,646 / 28,785。仅数值数组合计 494,032→459,448 字节，减少约 7.0%。faer 两分量每次求解申请的 scratch 布局各为 19,775 字节，另有结果向量。

归档 `FACTOR` 日志中，自写的 988,064 字节包括因子数值与索引数组载荷，faer 的 459,448 字节只计数值数组，未计符号结构；这两个数字不具有直接可比性。未测分配器开销或精确完整因子驻留内存。主计时进程峰值 RSS 自写约 14,028–14,044 KiB，faer 约 15,876–15,880 KiB，包含代码页、初始化临时量与其他模拟数据，不能解读为单独因子的内存。

分量初始化（排序、组装与分解）的观测为自写约 26.7–29.2 ms，faer 约 3.4–4.9 ms；两个分量并行，不相加作为墙钟。整个 `Simulation::new_local_world` 两轮为 189.3 / 189.8→166.9 / 181.5 ms，仍含基础压力求解、地图和物理初始化。初始化收益比持续求解更明显。

## 数值与动态结果

两种临时构建分别通过 5 项检查：3 项原有严格流体检查、原有带状解对照、真实分叉上与自写稀疏解的对照。测试构建将压力容差恢复为 `2e-9`，未放宽原断言；动态构建恢复 `1e-4`。

同矩阵审计覆盖两个分量各四个非平凡 RHS。faer 相对自写解的最大绝对差 `4.580e-16`，从原矩阵独立计算的最大 `|A*x-b|` 为 `3.997e-15`。额外的原带状解对照最大速度差 `1.582e-15`，残差 `3.819e-15`。

30 秒跨后端对照中：

- 每帧压力迭代次数一致；每秒保存的细胞中心、面积、所在管段、累计路程文件逐字节相同，通行事件文件相同，分叉上／下通行为 9 / 3。
- 累计流入相对差约 `2.89e-15`，上支路流体份额差约 `5.55e-17`；保存的箭头速度最大差约 `1.29e-15`。
- 包含所有轮廓点与箭头的完整快照指纹不相同，不能宣称跨后端逐位一致。相同后端的主计时重复及 profiling 重放则保存记录一致。
- faer 的最大面积偏差约 3.362%，无越壁；最大流量相对不平衡约 0.00781%，动量残差峰值约 `1.46e-14`。全场有限值检查通过。宽容差的散度仍按既有游戏精度口径观察，未拿它通过原严格阈值。

这些结果支持本场景中替换速度求解的数值正确性。本轮只覆盖 30 秒默认交通，没有新增长期、强操控或真人视觉辨识验收，也没有自动操作 UI。

## 后续判断

faer 可以保留为候选：初始化更快，持续求解有约一成收益，可减少自写数值代码的维护。当前整步仍约 11 ms，单靠这一替换尚不能接近之前周期直管的 6 ms。

若继续追求明显降耗，下一决策应关注压力迭代与速度逆的重复次数。压力预条件或完整 Stokes 系统因子复用可能改变这项成本；完整速度—压力系统含不定约束块，不能直接把本轮 SPD 速度块的 LLT 套上去。这些路线需另做方案选择，本轮未实施。也没有自动切换正式默认入口。

faer API 与算法口径见官方 [sparse Cholesky 文档](https://docs.rs/faer/latest/faer/sparse/linalg/cholesky/index.html)和[特性清单](https://docs.rs/crate/faer/latest/features)（本轮查阅均为 0.24.4）；实际实现依据下载并锁定的对应版本源码。

## 验证

`run.py` 完成两种 release 构建、每种 5 项数值检查及六条 30 秒轨迹；`analyze.py` 退出 0，核对哈希、重复结果和数值比较。`rustfmt --check --edition 2024`、Python 语法、44 个本地文档链接和空白检查通过。自写基线的保存观测也复现上一轮几何复用候选。正式文件未修改，因此未重跑 Godot、全项目检查或 UI 验收。
