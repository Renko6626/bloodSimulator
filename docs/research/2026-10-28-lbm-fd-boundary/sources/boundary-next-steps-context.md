# 给定速度边界的后续两步

2026-10-28，会话记录。用户要求记录以下两条研究路线；本文不代表方法已验证，也不启动实现或云端实验。

当前约束：短期继续给定边界速度，保留 Rust／wgpu、D2Q9 MRT＋Guo 路线。当前出口重建在低格子黏度下存在增长模，见[独立调查](hardware-rtx3060-20261028/independent-investigation.md)。更换边界速度来源不能自动消除这一失稳。

## 1. FD：基于速度梯度的正则化边界重建

优先研究用给定边界速度和内部邻域速度估计梯度，由梯度构造非平衡应力，再重建边界分布。它与此前失败的“从出口自身分布提取应力后局部投影”不同。

需要明确密度闭合、靠墙格点的梯度计算，以及 MRT、Guo 半步力和 shifted populations 的一致处理。文献稳定性结果不直接覆盖当前生产参数。

参考：[Wissocq 等，Regularized characteristic boundary conditions（2017）](https://arxiv.org/html/1701.07734)。这里只评估其梯度重建思路，不默认引入会改变给定速度约束的特征边界。

## 2. NEQ：非平衡外推及精确修正

从邻近内部流体格点外推非平衡部分，与给定速度对应的平衡部分组合。普通 NEQ 作为简单基准；eNEQ 作为带精确边界修正的主要对照候选。精确施加速度不等于保证稳定或全域质量守恒，不能预设 eNEQ 比 NEQ 更稳定。

参考：[Guo 等，NEQ（2002）](https://doi.org/10.1088/1009-1963/11/4/310)；[Ju 等，eNEQ（2021）](https://doi.org/10.1016/j.compfluid.2021.105163)。

## 最小比较范围

保持现有碰撞参数和给定速度，先复用已知出口增长模诊断；候选通过后检查原始直管的稳定性、实际边界速度／积分通量及质量漂移，再检查已有分叉和斜向开口。先形成具体数值方案，按项目约定确认后实施。

固定密度出口保留为因果对照。粗 NS 耦合、窗口几何调整和全局反馈不纳入这两步。边界切过分叉时解析速度场是否相容，仍是独立的后续问题。
