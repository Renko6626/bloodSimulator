# LSQ-FD 单例 1000 帧长程实验

2026-10-28，源码基线 `e08b8b0`，沿用 `fork_a Fine`：水平入口、26.565°／116.565°支路，70%／30%分流。仅本机 llvmpipe；无机械耦合、迁移或实卡性能测量。

## 结果

命令退出码 **0**，完成 **1000 帧／14000 格子步／约16.67秒模拟时间**。每步检查所有流体格点的正密度和密度／速度有限性，未发现坏格。前160帧日志与已归档短程实验逐行一致。

以下极值来自帧末采样，不是全部格子步峰值：

| 指标 | 结果 |
| --- | ---: |
| 密度范围 | [0.9565817, 1.043419] |
| 最大格子速度 | 0.068306156 |
| 边界速度最大误差（世界单位/时间） | 1.1920929e-6 |
| 各开口积分通量最大误差（世界单位²/时间） | 5.722046e-6 |
| 总质量相对初始值的变化范围 | [-0.011014%, +0.099377%] |
| 末帧质量变化 | +0.080395% |

格子速度在160帧短测之后超过原0.05参考值。没有调整dt、黏度或松弛参数来隐藏这一现象。

按每50帧一个脉动周期统计，平均质量变化从首周期的+0.001750%升至末周期的+0.089784%，20个周期均值依次上升。这支持“质量尚未进入稳定周期”的判断；尚未区分启动压缩过程与边界引起的长期质量漂移，不能据此直接认定泄漏机制或外推更长时间。

**结论：该单例1000帧未发散，给定速度/通量仍准确；质量稳定性、物理精度及速度运行范围仍未验收。** 没有据此推广到全部角度/分叉，未自动运行更多案例或修改数值方法。
