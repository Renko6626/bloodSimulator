# LSQ-FD 有限邻域候选

2026-10-28，基线 `206ab65`，独立实验副本；全部为本机 **llvmpipe，software=true**。本轮五个选定案例均完成160帧，原45°开口缺失的采样得到覆盖。没有生产集成，也没有证明任意斜率全覆盖或首发精度。

## 方法与范围

保留给定开口速度/离散流量、主rho闭合、MRT+Guo及nu/dt。与[原FD实验](../README.md)分开保存，原源码/结果未改动。[具体计划](../../../superpowers/plans/2026-10-28-lbm-fd-boundary.md)末尾记录本轮授权和方案。

在半径4格的固定圆盘内，用内部流体速度和同一开口的不可变目标速度拟合二次向量场。固定ub，对每个分量拟合：

```text
u(s,z)-ub = a*s + b*z + c*s²/2 + d*s*z + e*z²/2
(s,z) = (delta·n,delta·t)/4
Dn u = a/4, Dt u = b/4
```

距离权为 `1/(1+|delta|²)`。CPU用NumPy SVD/lstsq预计算导数权重，要求真实rank5、归一化矩阵condition≤1000；GPU只累加权重乘 `(uj-ub)`，再送入原应力重建。没有扩大半径、降阶、clamp或正则化fallback。条件门限是研究取舍，不是物理精度/稳定定理。

采样线段用网格supercover排除穿固体的点；边界样本读取目标buffer，避免读取同一pass正在重建的分布。权重文件带完整n、周期诊断标志、mask和开口side图，构造器逐字节核验；错误几何加载实际返回 `LSQ geometry identity mismatch`（预期exit2）。几何改变必须重新生成权重。

文献依据是[Latt等2008的FD边界](https://journals.aps.org/pre/abstract/10.1103/PhysRevE.77.056703)及[前轮来源记录](../sources/literature.md)；局部二次拟合是本次研究适配，不能借用文献或旧FD全谱声称本算子稳定。[NumPy主文档](https://numpy.org/doc/stable/reference/generated/numpy.linalg.lstsq.html)说明秩和奇异值接口。没有增加线性代数依赖。
