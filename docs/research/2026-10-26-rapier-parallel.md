# Rapier 接触距离校准与并行结果

2026-10-26。用户确认调整参数并启用 Rapier 并行后，在既有 64²/64 细胞、Stokes 点力欠松弛 ω=0.5 场景中比较。正式游戏及旧实验保持原样。

**当前场景优先使用预测接触距离 0.002、Rapier 四线程。两轮物理均值为 2.27 / 2.02 ms，整步为 7.10 / 6.34 ms，仍超过 5 ms。**

## 改动与原因

旧实验沿用 Rapier 的 `length_unit=1`、预测距离 0.02，而细胞直径为 0.09。第一子步细胞表面尚相隔约 0.0124，就已生成 224 条预测接触约束。预测约束用于防止未来穿透，不代表已经发生实体挤压。

本轮将 `normalized_prediction_distance` 调为 0.002，其他材料、质量、阻力、节点数量、迭代与子步数不变。Rapier 0.36.1 的 `parallel` feature 在新实验中默认开启；明确限制全局 Rayon 线程数为 4，已有流体四线程池保留。依次执行流体与机械，不逐步创建线程池。串行对照通过 `--no-default-features` 构建，不把“并行构建只用一线程”当成原串行实现。

## 测量

同一共享 Xeon Gold 6330、CPU 2–5，同插槽四个物理核，release、锁定离线依赖，无内部细分计时。每组六秒、360 帧，前 30 帧热身；主要四组正反顺序各一轮，线程数量补充比较各一轮。表中为均值 / p95，单位 ms。

| 配置 | Rapier 第一轮 | Rapier 第二轮 | 整步第一轮 | 整步第二轮 |
| --- | ---: | ---: | ---: | ---: |
| 串行，预测距离 0.02 | 5.030 / 6.431 | 5.246 / 6.303 | 13.096 / 16.099 | 14.194 / 16.203 |
| 串行，预测距离 0.002 | 2.886 / 4.327 | 2.544 / 3.494 | 9.956 / 14.559 | 8.737 / 10.883 |
| 并行四线程，预测距离 0.02 | 3.457 / 4.943 | 3.403 / 3.925 | 8.683 / 11.825 | 8.257 / 9.362 |
| 并行四线程，预测距离 0.002 | 2.272 / 2.400 | 2.017 / 2.224 | 7.101 / 7.780 | 6.339 / 7.481 |

预测距离 0.002 时，并行构建一线程的 Rapier 均值 / p95 为 4.262 / 5.521 ms，双线程为 3.081 / 3.857 ms，均没有优于四线程。线程档补充测量只有一轮，不能据此推断其他设备的最优线程数。

缩短预测距离后，热身后的接触约束从平均每子步 269.9 条降到 6.5 条。初始约束降为零，后续仍产生接触。所测两轮均观察到调参与并行的物理阶段收益；主机非独占，流体阶段也有明显计时变化，不能把整步的全部下降归因于 Rapier。

## 数值与边界

十条轨迹均完成。逐帧记录的细胞中心、速度、面积以及保存的轮廓、流场快照完全一致；串行原参数组也与上一轮欠松弛基线一致。这是记录精度下的相等，不是完整内部状态逐 bit 相同的证明。

最大面积相对偏差约 0.1486%；保留原有交换冲量、有限值和面积方向检查。驱动细胞与非驱动细胞之间的粒子间隙诊断未变化，但该诊断不能代替所有表面之间的最大穿透测量。没有验证持续窄口拥堵、高速碰撞、分叉或目标玩家设备。

正式世界细胞直径为 1.4，预测距离相对尺度不同，不直接照搬 0.002。流体本身仍是主要开销，单靠 Rapier 优化不能保证整体低于 5 ms。
