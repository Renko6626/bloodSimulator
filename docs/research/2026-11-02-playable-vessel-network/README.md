## 重建

在仓库根目录执行：

```bash
python3 docs/research/2026-11-02-playable-vessel-network/draw_draft.py
```

重建两幅SVG及`audit.json`，只使用Python标准库。`audit.json`也重算六条外部中心线最短路径，并按主动速度4换算理想步行秒数；没有流体、碰撞和心室内部时间。若要同时生成PNG，使用机器已有的系统Python、PyGObject/librsvg与cairo：

```bash
/usr/bin/python3 docs/research/2026-11-02-playable-vessel-network/draw_draft.py --png
```

本次实际执行后一条命令成功；两幅PNG分别为1230×1430和960×1740。未安装依赖。两幅PNG已静态查看，详图绘图区做裁切，外围道路不会穿过图例。

## 本次自查与局限

最终外网32条命名折线、89顶点、111线段、29个分支点、两个连通分量、24个独立环。89顶点包括普通折线转弯与宽度接续点；只有邻居数至少3的29个分支点画空心路口，不将所有折线点当成路口。

脚本实际检查结果：

- 非共享顶点的中心线相交0，单条外部道路自交0。
- 不同道路非共端点线段的管壁净间距小于2单位为0。管径用24/12/6/3实际比例绘制。
- 肺供能经明确局部道路到肺回；体供能经明确局部道路到体回；两片外网互不连通。
- 删除所有明确供回局部道路（`lung`、`local`）后，两侧各自没有供回主干短接。
- 删除任一顶点后，没有出现不含四端口、只靠被删顶点挂接的孤立口袋。此检查用于排除单点悬挂的无流闭环，不证明各路流量足够。
- 以生产代码相同的每三次曲线段32点采样实际心腔轮廓，外部管壁对心腔最小净空约16.431单位，相碰0。窄导引侵入非所属心腔0；外管与窄导引除共享接口外的非预期相碰0。

绘制过程中发现南内回流支环穿越心室，已移到心室下方，并移开B西弯路与窄联络；增加心腔检查后重新生成产物。西北供血支环原先仅单点接入，已把C北弯路接到其远端(300,450)，保留C南入口(210,600)，使两端均能接入区域通路。

相交审计采用直线段、圆管半宽距离与共享坐标；图中颜色不提供隔离。共享路口的邻接段未验汇合角/最小壁厚，未做圆角后形状、SDF、细胞净空、四腔内部再验或实际流量求解。原窄接口接24级宽段需要后续几何渐变。肺下口短环可能抢占流量，长途走路约两至四分钟；这些是设计审阅点，未用人为限速或新机制弥补。具体估算和未验收范围见设计说明。
