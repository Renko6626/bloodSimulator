# 第一批 CPU NS：大网格推进与软体负载

2026-10-27。范围是已确认 CPU MAC 投影路线的首批实验。[路线图](roadmap.md)、[实施计划](ns-plan.md) 与[执行记录](progress.md)另存。本批完成后，阶段一仍有复杂血管几何、实际驱动和耦合精度问题；尚未接入游戏或启动 GPU LBM。

## 实验设计

实现放在独立 [lab](lab/Cargo.toml)，复用 Rust、faer、Rapier 和 Rayon，不改变游戏主程序。f64 MAC，RK2 回溯／双线性半拉格朗日对流，隐式 Euler 黏性，标量 Poisson 压力投影。两个速度 Helmholtz 矩阵和一个压力矩阵在初始化时 Cholesky 分解，随后只换右端项；数值因子与求解工作区常驻。压力通过去掉一个参考格的行／列消除零空间，不加压力罚项。

x 周期、y 固定无滑移壁。一个 1/60 s 周期做两个 1/120 s 流体和 Rapier 子步。流体惯性、对流与历史均实际推进；没有按静态 RHS 重放代替 NS。

| 配置 | 范围 | 压力格数 | 格距 | 参考平均速度 | 运动黏度 | 宽度 Re |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 完整 192² | 48×48 | 36,864 | 0.25 | 10 | 4.8 | 100 |
| 完整 256² | 48×48 | 65,536 | 0.1875 | 10 | 4.8 | 100 |
| 窄通道 192×30 | 48×7.5 | 5,760 | 0.25 | 10 | 0.75 | 100 |
| 窄通道 256×40 | 48×7.5 | 10,240 | 0.1875 | 10 | 0.75 | 100 |

方域和通道的几何、黏度不同，不是同一物理工况的快慢对照。通道只占包围方域 15.625% 的面积，报告时保留实际活跃格子数。每类再分别测试空流体与 72 细胞；初始为解析抛物线流叠加小幅散度自由扰动，并先投影。

细胞采用现有半径 0.7、质量 1、十二节点软体，四个内部阻力点，总 Γ=0.25，初速度为零；点位于所选节点与质心之间，各半。插值与反作用散布使用相同 MAC 权重，二维流体面密度为 1，速度自由度质量为格子面积。细胞冲量回传也使用节点／质心插值的转置权重。每子步同时计算显式阻力，再做流体和 Rapier 推进。

## 性能结果

计时见下方生成汇总及原始数据链接。完整方域的当前实现明显超预算，窄通道才接近 60 Hz 模拟上限；两者的流体加耦合 p95 均未达到约 5 ms 候选预算。72 细胞增加的 Rapier 成本不足以解释完整方域的超时。加细胞组部分均值反而更低，说明轮次／主机波动仍影响计时，不能解读为细胞让流体更快。

| 活跃网格 | 细胞 | 流体+耦合 mean / p95 ms | 完整 mean / p95 ms |
| --- | ---: | ---: | ---: |
| 192×192 | 0 | 60.91 / 86.99 | 61.60 / 88.04 |
| 192×192 | 72 | 56.71 / 79.51 | 60.51 / 84.59 |
| 256×256 | 0 | 109.00 / 146.66 | 110.19 / 148.44 |
| 256×256 | 72 | 101.00 / 136.02 | 105.48 / 143.61 |
| 192×30 | 0 | 4.64 / 7.03 | 4.74 / 7.16 |
| 192×30 | 72 | 4.53 / 6.65 | 6.97 / 9.75 |
| 256×40 | 0 | 8.94 / 11.95 | 9.11 / 12.22 |
| 256×40 | 72 | 8.48 / 11.29 | 11.19 / 14.44 |

测量固定 Xeon Gold 6330 的 CPU 2–5，4 个 Rayon 线程负责对流，faer 求解为顺序执行。每配置两轮反序，各先热身 30 帧再记录 240 帧，共 480 个测量样本，物理推进共 4.5 s／次。均值与 p95 按逐帧观测计算，整步 p95 不用阶段 p95 相加。完整时间包含流体、耦合、Rapier 与研究诊断；CSV 格式化、写盘及渲染不计入。初始化另报。

共享主机未独占，不能把这些数值当成目标桌面硬件预测。运行中记录过约 24–30 的系统 load average；首轮部分测量与约 2.5 s 的本实验测试编译／执行重叠，第二轮没有这项额外工作。两轮单独 p95 均保留，结论只针对本实现和环境；不与历史另一轮、另一掩码的 Stokes 计时计算精确加速倍数。

当前成本同时分布于对流、黏性和投影。只优化压力无法消除其他阶段已经超过预算的成本；“把联合系统换成标量压力”也不意味着整个 NS 会自动变便宜。该结果不足以判定所有 CPU NS 都不可行，仍受当前半拉格朗日实现、三次直接求解、线程布局和主机影响。

## 数值结果与物理含义

- **稳态管流**：在解析解上初始化，推进 2 s；Re=0.1、100、300。192×30 的相对速度 L2 误差约 0.152%、0.071%、0.053%；256×40 约 0.086%、0.040%、0.030%。网格加密后减小。这里验证保持与离散误差，没有验证从静止建立充分发展流的全过程。
- **脉动通道**：Re=100，平均驱动加 80% 的 1 Hz 谐波，解析正弦级数初始化后推进一个周期。以半宽定义的 Womersley 数约 10.85。基准 dt 下两网格全时段最大误差均约 0.082%；dt 减半后约 0.076%／0.045%。逐时刻平均流量与解析值已保存，可查看相位和幅度。
- **带平移 Taylor–Green 涡**：双周期 2π×2π，平移速度 (2,0.7)、扰动幅度 1、ν=0.05，推进 1 s。误差按涡流扰动归一化，避免背景平移掩盖误差。dt=1/120 时，64²→128²→192²→256² 的误差为 11.04%→4.78%→2.60%→1.50%；网格加密改善明显。dt 减半后分别为 11.90%→5.71%→3.53%→2.43%，没有时间步收敛改善，显示反复插值耗散仍明显。RK2 回溯不等于整个推进具有二阶精度。

直管中的轴向对流项为零，不能仅凭直管误差小就认定动脉惯性已经验证。涡流包含实际非线性对流，是本批额外检查；仍未覆盖分叉回流、狭窄射流、弯壁和强脉动下的局部结构。

投影测试直接核对真实 MAC 散度，黏性测试核对动能下降，耦合测试核对真实网格和 Rapier 的反向动量。运行交换误差是局部交换瞬间的网格冲量与请求施加的 f32 细胞冲量之和，不是完整 NS／壁面／碰撞过程的总动量误差。面积观测只是该短时负载下的变形，不是细胞膜拟真认证。

## 现阶段判断

后续 [Vast CPU profile](profile/README.md) 已完成：确认对流权重计算与三个串行因子求解为主要热点，云端复测仍超预算。

当前预分解 MAC 原型提供了可复现的 NS 对照，但完整 192²／256² 尚不具备实时性。下一次 CPU 实验值得先定位各阶段实际算术、内存和调度成本，再决定是否改变求解或对流方案；本批没有额外引入 FFT、多重网格、GPU NS 或新耦合算法。

普通半拉格朗日的耗散已出现可观察限制。即使后续压低时间，也需要在相同物理条件下保留涡流与脉动误差对照，不能只用稳态管流的漂亮误差作验收。GPU LBM 的后续对照同样需要记录一整个物理周期所需的所有子步、交换和等待。

这批二维游戏单位尚未标定为人体尺度。宽度 7.5 只约五个当前细胞直径，不能直接称为真实动脉。四个内部点允许透流；固定线性阻力、Rapier 自身阻尼和背景黏度共同决定有效流变。未处理不可渗透膜、薄层润滑、毛细血管挤压、细胞聚集阻塞和真实血液黏度。周期换位不包含跨接缝细胞接触。
