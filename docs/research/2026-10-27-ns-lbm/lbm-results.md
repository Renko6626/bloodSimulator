# GPU MRT LBM 首批结果

2026-10-28（Asia/Shanghai）。用户确认 wgpu＋MRT 后完成本批。新 Vast 实例 57988490 的 RTX 3060 已完成实验，结果取回核验后确认 stopped／exited，保留磁盘。独立研究程序未接入 Godot 或替换游戏默认后端。

## 后续采用决定

2026-10-28 用户已明确：GPU LBM 方案可行，将应用于游戏，见[阶段决策](lbm-decision.md)。下文保留首批实验时的测量结论与限制；正式游戏尚未接入，GPU NS 对照不再作为采用 LBM 的前置条件。

## 首批实验结论

在本批 Re=100 规则域中，完整 192²／256² 加 72 细胞的流体、耦合与必要等待 p95 分别约 2.44／3.93 ms，低于候选 5 ms 预算。包含 Rapier 与研究诊断的整步 p95 为 6.77／8.83 ms，不含渲染及游戏逻辑。GPU LBM 值得保留并与后续 GPU NS 比较；暂不能据此保证复杂血管或整个游戏达标。

低 Re=0.1 的窄通道即使没有细胞，流体加耦合 p95 仍为 5.57／9.98 ms。相同物理条件需要大量格子步，不能用一次 kernel 的速度评价低 Re 完整成本。

## 模型与对照条件

代码：[lbm](lbm/Cargo.toml)；设计：[实施计划](lbm-plan.md)、[参数准备](lbm-preflight.md)。独立 Rust workspace，wgpu 27.0.1／WGSL、GPU f32、CPU f64 MRT 参照，Rapier 0.36.1。D2Q9 正交原始矩 MRT＋Guo 外力，守恒模态松弛率 0，剪切模态由 ν 决定，e=1.1、epsilon=1、qx=qy=1.2。外力在矩空间乘 (I-S/2)，宏观速度包含半步力。存储 f_i-w_i 减少 f32 底值相消。

x 周期、y 半格反弹；涡流双周期。双分布缓冲驻留 GPU，每个机械子步的多个 dispatch 在同一 compute pass，随后回读完整宏观场。每帧两个 1/120 s 机械子步、两次提交与回读。完整方域每帧回读约 1.13／2.00 MiB，转换和等待都计入成本。

72 个细胞沿用半径 0.7、质量 1、十二节点、四内部点、总 Γ=0.25 及原膜／阻尼参数。每机械子步显式交换一次，与 CPU NS 频率一致；同位双线性取样和散布，网格收到守恒动量 kick。MAC 与同位网格空间权重不同，不能称为逐位同耦合。仍允许透流，无不可渗透膜或排液机制。

物理范围、参考流速和黏度沿用 [CPU NS](ns-results.md)。完整方域为 48×48、ν=4.8，窄通道为 48×7.5、ν=0.75，均 Umean=10、Re=100；两类几何不是同一个流动问题。Re=0.1 窄通道保持 Umean=10、ν=750。

按格子速度参考上限 0.05、tau_nu 上限 2 的本轮候选限制选择 dt，并整分 1/120 s。Re=100 的 192／256 每帧推进 28／36 格子步，低 Re 窄通道为 400／712 步。tau 上限不是普遍稳定定理，未证明子步数最优；没有更改物理参数来减少工作量。

## 性能

RTX 3060 12 GiB、NVIDIA 580.159.03、Vulkan；Xeon E5-2630 v4，固定 CPU 2–5、4 个 Rayon 线程，cgroup 配额 19.2 核，主机非独占。每配置两轮反序，各热身 30 帧、记录 120 帧；每条轨迹 2.5 s。合并两轮 240 帧计算 nearest-rank p95。

72 细胞完整方域的设备 pass 平均为 0.714／1.497 ms，主机编码 0.162／0.179 ms，等待 1.192／2.090 ms，回读转换 0.274／0.447 ms，耦合 0.513／0.831 ms，Rapier 3.111／3.159 ms，研究诊断 0.830／1.439 ms。时间戳一直开启，未额外做关闭 profiling 的优化实验。

未在这台新主机重跑 CPU NS；不同硬件、时段、算法与采样长度的旧结果不用于计算精确加速倍数。

## 数值

18 个解析工况完成，观测状态有限、密度为正。误差相对连续解析解；没有预设全面玩法验收门槛。

| 稳态 Re=100，2 s 末态 L2 | 0.1166% | 0.0725% |
| 稳态 Re=300，2 s 末态 L2 | 0.1155% | 0.0685% |
| 脉动，1 s 最大 L2 | 0.1223% | 0.0682% |
| 脉动，格子步减半最大 L2 | 0.1233% | 0.0692% |
| 平移涡流，1 s 末态扰动 L2 | 0.0258% | 0.0198% |
| 平移涡流，格子步减半末态扰动 L2 | 0.0240% | 0.0131% |

稳态从解析抛物线初始化，不验证静止启动；Re=0.1 全程最大误差 0.4130%／0.2310%。脉动 Re=100、80% 的 1 Hz 谐波，半宽 Womersley 数约 10.85，解析级数初始化。涡流沿用 2π×2π、ν=0.05、平移 (2,0.7)、扰动幅度 1，密度由解析压力初始化，误差按扰动归一化。其文件名 re100 为未使用的通道参数，不能作涡流 Re 解释。

涡流 64²／128² 基准误差 0.2275%／0.0521%，支持空间加密改善。旧 CPU NS 同一连续涡流的 192²／256² 误差约 2.60%／1.50%，本例 LBM 耗散误差较小，不能外推所有血管。脉动和粗网格涡流的步长减半没有改善，不宣称全面时间收敛。

小规模实卡与 CPU f64 对照各 60 步，含一次 kick；速度相对差 9.30e-7／9.39e-7、最大绝对差约 1.1e-7。72 细胞测量帧的最大面积相对变化 0.0047%–0.0332%，密度约 0.9999668–1.0000299，最大 Mach 不超过 0.0642。uploaded_exchange_mismatch 最大 6.05e-9，核对主机细胞请求与上传 f32 kick 的平衡，未直接测量每次 GPU kick 后总动量。

未覆盖强封堵、薄层润滑、毛细血管挤压、跨周期缝细胞碰撞、分叉／弯壁／开口／域内泵、区域交接、机器人或渲染。游戏单位未标定为人体尺度，短时轨迹不代表长期稳定。按路线图下一阶段为 GPU NS，尚未在本轮实施。
