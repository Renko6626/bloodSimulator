# 第一批 CPU NS 实验执行记录

计划：[ns-plan.md](ns-plan.md)。用户于 2026-10-27 明确安排开始 NS，并要求直接关注 192²／256²。

## 实现与核查

- 独立 lab 已实现 f64 MAC、RK2 回溯／双线性半拉格朗日、隐式黏性、压力投影；两个 Helmholtz 与一个 Poisson 固定矩阵使用 faer Cholesky，复用工作区。
- 核心检查：实际 MAC 散度、无驱动黏性耗散、解析管流的网格收敛、真实网格与 Rapier 的反向动量交换。最初核心缺失时编译失败，核心实现后 4 项检查通过；未声称每项都经过独立的行为红绿过程。
- 物理场景已运行：Re=0.1/100/300 解析稳态通道；Re=100、Womersley 半宽参数约 10.85 的脉动；带平移的双周期 Taylor–Green 涡。后两项包含 dt 减半。
- 72 个十二节点 Rapier 细胞、四内部阻力点、总 Γ=0.25；有限透流与显式弱耦合近似保留。世界 x 方向整细胞周期换位，跨接缝细胞接触未实现；本批用于负载与交换核查，不能充当跨周期碰撞验收。
- 固定 CPU 2–5、4 个 Rayon 线程、faer 顺序求解；两轮反序，共 16 次性能运行。源代码、锁文件、脚本和二进制 SHA256 在 manifest，源代码另有归档。

## 执行判断

本批选规则周期域以隔离推进成本，完整方域与同格距窄通道分别报告。它们几何不同，各按自身宽度设 Re=100，黏度分别为 4.8 与 0.75，不能作为同一流动问题的直接快慢对照。之前大窗口的泵／开口错误不带入此批基准。

未扩展生产接口、依赖路线、耦合算法、压力算法、云端或 UI。结果若超预算，先报告瓶颈；新算法仍按路线图后续安排。
