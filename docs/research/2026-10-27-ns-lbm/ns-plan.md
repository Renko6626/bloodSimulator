# 第一批 CPU NS 实验

2026-10-27。依据 [roadmap.md](roadmap.md) 及用户本轮明确安排执行。首批直接回答 192²／256² 的成本问题，完成后再扩展复杂几何和耦合精度。

## 实验范围与实现

在本目录 `lab/` 建立独立 Cargo workspace，使用项目已有版本的 Rust、faer、Rapier、Rayon、serde_json；不改游戏接口或依赖。研究程序自行实施与核对，运行记录保存在本目录，不覆盖历史实验。

采用已经讨论的 CPU MAC 投影候选：f64 交错速度、RK2 回溯与双线性半拉格朗日对流、隐式 Euler 黏性、压力投影。固定几何、黏度和子步下预分解两个速度 Helmholtz 矩阵及一个标量压力矩阵，使用 faer Cholesky，复用求解工作区。每个 60 Hz 周期先按两个 1/120 s 子步测量。普通半拉格朗日是首批耗散基线，尚非最终对流选择。

首批采用规则固定域，x 周期、y 无滑移壁；涡流验证采用双周期。压力固定一个参考自由度并对称消元，无压力罚项。规则域有助于先区分算子规模与旧联合 Stokes 的成本，不代表分叉域或全地图验收。

主要规模是完整 48×48 的 192²、256² 网格。另设同格距的 48×7.5 通道，分别为 192×30、256×40 个活跃压力格，表示包围矩形中的窄通道占比；必须单独报告，不能把它们称作完整 n² 负载。两分辨率保持同一物理范围。动脉代表参数先取 Umean=10、通道宽 7.5、Re=100，即 ν=0.75（游戏单位）；不声称已作人体单位标定。

## 执行任务

- [x] **MAC 推进核心**：`lab/src/{grid,factor}.rs` 实现采样、边界、隐式黏性和投影，独立于 Rapier；`lab/src/tests.rs` 检查投影实际降低散度、无驱动黏性耗散和解析管流。
- [x] **物理基线**：`lab/src/cases.rs` 定义稳态管流、脉动管流与带平移的 Taylor–Green 涡；解析预期独立于离散算子，检查时间步／网格影响与流场误差，不只检查代数残差。
- [x] **软体负载**：`lab/src/coupling.rs` 复用十二节点膜参数与四内部阻力点，使用相同插值／散布权重及反向冲量；72 个细胞、两个 Rapier 子步，记录面积与交换误差。保留有限透流和显式弱耦合近似，不增加新耦合机制。
- [x] **测量与归档**：`lab/src/main.rs` 输出逐帧阶段耗时与数值观测；`run.py` 运行 release／offline 固定 CPU 的两轮反序对照，保存日志、实际命令、环境、锁文件及源码／二进制哈希；报告初始化、数值检查与整步 p95，写盘在计时外。
- [x] **分析与结论**：`analyze.py` 汇总原始数据，`ns-results.md` 说明测得成本、通过的物理检查和未覆盖项，更新路线图状态。首批如未达预算，保留负结果，不自动扩展优化路线。

## 验证与解释边界

已有游戏代码未改，仅运行独立 lab 的格式、测试和实际实验。新增测试限于投影、黏性、耦合等关键行为；解析场景本身承担主要物理核查。不得按源码字符串验证数值实现。

计时分开记录对流、黏性、压力、耦合、Rapier、研究诊断和整个模拟周期，p95 直接取整步样本；初始化另报。候选流体预算仍为 p95 约 5 ms，整帧上限 16.67 ms 且需给渲染留余量。共享 Xeon 的结果不等同目标桌面性能，也不与旧轮次计时计算精确加速倍数。

首批未覆盖：真实分叉／弯壁、域内泵与开口、动脉人体尺度标定、毛细血管薄层／膜不可渗透、机器人控制、区域切换、Godot 渲染、GPU LBM。后续按首批证据推进这些问题。
