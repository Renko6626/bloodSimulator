## Exact timing, signs and units

- Every lattice step captures raw shifted populations before collide/stream (`G0`), after streaming and all bounce placeholders but before reconstruct (`G1`), and after reconstruct (`G2`). A dedicated read-only-input compute pass writes a snapshot buffer; CPU sums every fluid population as f64. `Mk=Nfluid+sum(Gk)`; compute differences from shifted sums to avoid subtracting a large background.
- `delta_bulk=M1-M0`; `delta_reconstruct=M2-M1`. Global closure residual is `(Mfinal-Minitial)-sum(delta_bulk+delta_reconstruct)`. This push implementation bounces outward links before rebuilding openings, so bulk should nearly conserve. **Reconstruction increment includes intended reservoir exchange, not automatically a leak.**
- At each opening let n point inward. Partition actual `G2-G1` by c.n=+1 (unknown incoming), −1 (known outgoing),0 (tangent/rest). Their sum must equal reconstruction's global increment; all other fluid populations must be unchanged by that pass.
- Add only a diagnostic store of each actual collided `post[q]` with c.n=−1 before push. These are the real outward-link populations. Check bitwise that their bounced `G1[opp(q)]` placeholders agree. Define `Lout=sum(post_out+wq)` and `Lin=sum(G2_in+wq)`, inward-positive discrete link exchange `E=Lin-Lout`. Then `delta_reconstruct = E + delta_known_out + delta_tangent + residual` if placeholder mapping is verified. This distinguishes replacing bounced outflow from rewriting known populations; none of the measured terms is called unphysical by definition.
- Also record `B1=sum(G1+w,cn=-1)` (known outward populations arriving from interior), `C1=sum(G1+w,cn=+1)` (bounced actual outward placeholders), and actual post-reconstruction inward momentum `jn2=I2-B2`. Exact algebra: `delta_reconstruct = jn2 + (B1-C1) + (delta_tangent+2*delta_known_out)`. At F=0, jn2 is the nodal rho-weighted inward flux in lattice units. The primary rho closure should make the last compatibility term small, up to f32 rounding. This explicitly observes the boundary-chain/placeholder difference instead of equating macro flux to exact link exchange. Nonzero known rewrites alone cannot identify the drift cause: unknown-only and all9 at the same rho both assign the same total boundary density, and channel changes can cancel.
- Macro opening volume `Q=sum(u_world.outward*h*D)` and mass `J=sum(rho*u_world.outward*h*D)`, D=1, outward positive. `u_world=u_lattice*h/dt`. Report all openings separately. Approximate continuum mass increment in lattice-sum units is `-dt/(h*h*D)*sum(J)`; sample pre/post and use trapezoidal integration as a comparison only. **It is not an exact LB identity.**
