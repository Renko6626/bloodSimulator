## 当前可运行内容

- Rust `simulation` → `godot_bridge` → Godot 展示，锁定 Rapier 0.36.1、godot-rust 0.5.5；本机使用 Godot 4.7.1。
- 默认世界包含 11 个节点、12 条血管段、心脏和两个器官位置样板，72 个每个 12 节点的软体细胞，以及可控制机器人、跟随镜头和 HUD。
- Rust 内置地图定义共用于血管几何、碰撞及流向采样。正式游戏仍使用小型阻力网络与局部解析速度近似。
- 原实验场继续保留；暂停、单步、重置及关键物理行为已有检查。
- 当前全部 72 个细胞详细运行。战斗、治疗、区域激活与远处指标演化尚未落地。

世界实现与限制见 [实施记录](2026-10-22-world-small-map.md)，已确认的系统边界见 [整体架构](../specs/2026-10-21-world-architecture-design.md)。

## 已确认的研究取向

用户希望整体模拟尽量低于 5 ms，为其他系统保留余量；允许百分之几量级误差，前提是没有明显奇异运动。流固耦合先追求局部带流、受阻等效果，允许近似。重要后端、模块边界和产品接口改动仍需单独确认，研究授权不等于已经决定替换正式求解器。

独立研究程序位于 `docs/research/experiments/`，未纳入正式 Cargo workspace：

| 研究 | 当前认识 |
| --- | --- |
| [MAC + Stokes](../../research/2026-10-22-mac-stokes-experiment.md) | 规则周期通道可用 FFT / Thomas 加速；不规则边界和耦合后的成本需要单独评估 |
| [少量阻力点与边界近似](../../research/2026-10-23-coupling-experiment.md) | 少量内部点适合弱反馈原型，不能自动代表不透流的细胞边界 |
| [LBM 对照](../../research/2026-10-23-lbm-experiment.md) | D2Q9 小网格和固定墙传播索引具备继续研究价值，分辨率提高后的时间成本明显 |
| [单细胞动态耦合](../../research/2026-10-23-lbm-dynamics.md) | 移动核、Rapier 冲量回传、反向驱动与挤压恢复完成短时实验；f32 未显示可靠整体提速 |
| [采样核复用与 16 细胞](../../research/2026-10-23-lbm-scale.md) | 子步内复用核保持轨迹一致，整体提速有限，流体阶段仍占主要成本 |
| [16–128 细胞与分级](../../research/2026-10-23-many-cells-and-lod.md) | 等密度扩大流场时整步均值约 4.42 / 8.75 / 17.37 / 35.22 ms；固定小网格时约 4.45 / 5.46 / 7.96 / 17.21 ms |

最新两组实验各有 16 / 32 / 64 / 128 个细胞，每例 6 模型秒、360 帧。固定小网格组使用半径 0.025 的小细胞，直径仅 1.6 格，属于容量测量；不能和半径 0.075 的等密度扩展组作等精度比较。各组 p95 均超过 5 ms。没有观察到此次同向运动下的数值失稳，但尚未验证百细胞持续拥堵，也未标定正式游戏单位。

## 后续工作与未决事项

1. 继续拆解流体及点力阶段的成本，并针对实际近景负载选择优化。packed-128 出现大量预测接触约束，其 Rapier 成本也值得检查；目前未做预测距离调参对照。
2. 已批准的世界方向为近处详细、远处区域指标，相邻活跃区域共用 Rapier 世界。近期建议先两层，暂不预建可见代理或多分辨率网格框架。
3. 局部 LBM 窗口与全局血管网络的开口边界、单位对应、初始化和切换仍需研究；周期通道实验不构成这些问题的验证。
4. 尚未确定典型镜头内需要多少可见细胞、多少必须真实推挤，也未决定是否允许部分可见对象使用简化代理。用户此前对此尚未给出具体数量或选择。
5. 本轮没有实施 LOD，也没有替换正式流体后端；战斗仍属于后续批次。
