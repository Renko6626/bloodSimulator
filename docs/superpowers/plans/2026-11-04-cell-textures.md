# 血细胞纹理样板实施计划

> 使用 superpowers:executing-plans 在当前会话执行；按用户要求限制验证规模。

**目标：** 将已确认显微美术基准落实到红细胞和中性粒细胞；其他细胞共享平滑显示轮廓。
**路线：** 沿用 Godot CellMesh 和 draw_mesh；增加静态 UV 与两张细胞内部纹理。Rust、snapshot、碰撞与模拟均不改。
**技术：** 现有 GDScript / ArrayMesh / PNG，不添加依赖或渲染后端。
**依据：** docs/art/microscopy/README.md；用户已批准混合素材来源并要求开始血细胞实装。

## 约束与取舍

- 纹理来源为公有领域真实涂片的 AI 辅助重建，准确记录，不称直接原像素裁切。
- 本轮用一张内部纹理表达胞质与核，不增加内部器官模拟；核细节会随整个细胞变形。
- 采用沿轮廓局部二次曲线圆角，显示轮廓略向内收，不增加物理节点；真实碰撞线单独保留。
- UV 与节点编号绑定，随节点运动；不使用每帧世界坐标或包围盒映射，避免游动时纹理滑动。
- 只验收世界场景；lab 保留原始物理诊断画法。血管、组织和其他物种纹理后续处理。
- 不做云实验、全量性能研究或自动按键交互，不提交或合并主分支。

## 用户修正：核仅作独立渲染层

上一版整张纹理形变被否定。用户明确选择纯渲染的核，否决额外核物理或纹理模拟。

- 胞质与透明核分别出图；胞质以细胞中心/方向为局部坐标、固定尺度采样，膜只裁切边界。
- 核保持固定显示尺寸与比例，只随整体平移/转动；中心包络碰到膜时等比缩小。保守的居中适配，不引入搜索、核运动状态或碰撞模型。
- Rust与细胞本体力学不改。现有轮廓平滑保留，红细胞沿用此前纹理路径。
- 复用网格检查验证普通/中度挤压核保持大小、严重挤压等比缩小、胞质颗粒尺度稳定；更新生产渲染截图。只运行受影响检查。


## 第三轮：出生外观差异与胞质斑驳

用户批准放大核占比、非对称排列与更强胞质层次，并要求生成时固定小幅核叶排列/角度随机。

- 用三张核排列变体保留连接桥，不增加核叶关节或模拟；按已有实体ID播种局部RNG，在首次渲染或槽位换ID时固定选择，离开视野/休眠不改变外观。
- 核额外旋转范围±0.6弧度，大小由胞质显示半径0.65改为0.88；仍仅在居中包络触及膜时等比适配。
- 胞质改为更强多尺度灰紫/米白斑驳，固定采样尺度保持不变。
- 仅运行导入、已有网格检查（补出生外观稳定性）、战斗短加载和截图；没有Rust或物理改动。
