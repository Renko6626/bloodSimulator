# wgpu 回读资源复用单项实验

用户已明确要求先试现有 wgpu 下的资源复用。沿用当前架构，只在 GPU MG 求解器准备时创建 32 字节状态回读缓冲和 n×4 字节解回读缓冲；每次读取结束释放 mapped view 并 unmap 后复用。

- [x] 保存现有已测版本的二进制和哈希，作为同机匹配对照。
- [x] 修改 `MgSolver` 的回读资源生命周期，保持每次拷贝、提交、poll、shader、算法及容差不变。
- [x] 运行已有模块测试、已知解／零 RHS smoke 和反复读取的真实样本，核对原方程及基线诊断一致。
- [x] 启动已授权的 Vast 实例，复用同一冻结数据，交错 baseline／reuse 与 off／host，测试三个规模、两个区域、1／2 次 V-cycle、两轮。
- [x] 取回源码／输入／二进制哈希和原始记录，比较总耗时及等待是否迁移；完成后停止实例并确认退出。

本轮不合并命令提交、不修改 pass 边界、不更换后端，不新增通用内存池或异步恢复机制。复用能消除求解中的 create_buffer 调用，但不预先保证原 API wall time 全部变成净收益。

完成记录：六组正常模式均值降低约 8%–22%；192 对数值诊断和 dispatch／提交／回读计数一致。准备阶段的等待部分转移到 map／poll，未将其全算成净收益。云实例已经确认 exited／stopped。完整结果见 docs/research/experiments/2026-10-27-modular-mg/readback-reuse.md。
