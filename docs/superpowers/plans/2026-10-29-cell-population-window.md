# 细胞群体窗口实施提案

> **For agentic workers:** 仅在配套设计获确认后使用 `superpowers:executing-plans` 逐项执行；用户已以“ok 开干。”确认配套具体设计并授权实施；不授权启动云实例。

**Goal:** 保留近场真实软体/接触/LBM耦合，远场用数量输运，减少全世界软体开销。

**Architecture:** 单一simulation持有一个Rapier世界。cell_population模块保存远场库存并决定交接，runtime唯一拥有活跃handle；Godot只展示本地轮廓及明确的全局/近远数量。

**Tech Stack:** 现有Rust/Rapier/wgpu/Godot；无新依赖。

**Spec:** [窗口方案](../specs/2026-10-29-cell-population-window-design.md)。

## Global Constraints

- 用户已确认远场数量/密度及具体范围、混合模型、区间库存和接口，按此路线实施。
- 默认全量模式与旧probe/validation保持，初版用显式--local-cells进入；不将新模型和旧模型声称逐帧等价。
- 近场材料、物理子步、LBM算法和全局流量求解不变；不自动减少总量以换性能。
- 接触与窗口交接是核心功能，相关新测试应简短覆盖真实逻辑；不为跨层重复同一用例建立额外测试框架。
- UI只截图，不自动键鼠/按钮交互。硬件费用与实例安排单独确认；先取回核验再停止。

## Review Focus

- 一个血管边可能被详细框切成多段远场，Task1保留区间分隔，不瞬间混合两端库存。
- 当前背景速度与LBM二维通量口径不同，Task1明确群体通过率，避免相同Q被当成两个不同速度同时输运。
- 边界构造阻塞、分数库存、移窗重分配可能破坏数量，Task1/2统一数量归属和守恒断言，不以生成补满掩盖。
- 首帧可见区与外缘新来细胞不同，Task2区分初始构造与运行期外缘交接，截图/人工体验不漏验。
- 旧质量/位移指标假定固定个体，Task4不复用其逐个身份断言作为新群体模式验收。

### Task 1: 先完成CPU群体数量与输运

- [x] 定义 `CellPopulationOptions`（激活半边36、保留半边40、粗更新周期0.2s），显式Full/Local模式和区间库存类型。实际字段名由实施者按现有类型习惯收敛，不重复保存密度。
- [x] 从当前MapDefinition中心线按弧长构造窗口外连续区间及图节点/近场入口连接；保留同一edge多个不相邻区间。
- [x] 按设计固定 `u=Q/(πR²)` 与 `ΔN=N×min(1,|u|Δt/L)`，同次更新只用旧库存；节点按下游|Q|分配，进入窗口内区间则停止抽象输运并待构造。CPU独立算例确认量纲，不修改流体公式。
- [x] 实现非负的同时入/出流更新与按弧长重叠比例的移窗库存重分配；所有未构造份数都在同一份区间库存内，HUD和总量不重复加一份“边界余额”。

## 实施结果

已在现有分支完成Task1–3及Task4本地部分，见[实现、原始记录与限制](../../research/2026-10-29-cell-population-window/README.md)。

- CPU真实MoveInput回放各60秒：Full 72软体，Local 28–55；生成66/退休68，总量误差最大2.84e-14。单次同机成对solve均值6.335→3.755ms、p95 7.552→4.684ms，保留全部帧与未归因长尾。
- 当前默认项目检查通过；审阅修补后7个相关测试与feature lib检查通过（23通过、9显式GPU忽略）。Full/Local各2帧llvmpipe仅作LBM功能检查，不作性能证明。
- 唯一Important审阅项为负Q候选顺序：实际复现失败后按流向排序修复并通过；不新增入口队列或库存类型。
- 本地CPU只对比solve/snapshot/exchange，没有增加通用阶段计时API。Rapier/背景/LBM/完整渲染帧的实卡成对证据仍未完成，不能勾选为已验收。
- 实施期间没有启动云实例或执行集成操作；随后用户明确安排本阶段文档、提交和推送，见[阶段交接](../../research/2026-10-29-performance-checkpoint.md)。默认Full与原loop保留，模式改变不宣称个体轨迹等价。
