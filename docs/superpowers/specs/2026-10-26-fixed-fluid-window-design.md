# 固定局部流体窗口接入试验方案

2026-10-26。用户已确认在现有世界试接固定局部流场，并明确同意本方案的带状速度分解、压力 Schur-CG 与自然牵引开口。不加入移动窗口、LOD 或全局堵塞反馈。实施结果见[试接报告](../../research/2026-10-26-fixed-window-trial.md)：数值通过、性能未满足实时试用，按本文停点保留显式数值原型。


后续更新（2026-10-27）：用户已确认联合 LU 接入，并选择先验证固定重叠区域切换。当前显式原型已采用 faer 0.24.4 联合分解、两块加载时预计算的区域和原单一 Rapier 世界；本文件下面的带状／CG 部分为最初试接方案。当前方案及验证见[联合双区实施记录](../plans/2026-10-27-joint-regions.md)。

## 目标与范围

在现有分叉世界的机器人出生点附近接入一个固定 64² 窗口，复用地图几何、Godot 展示、统一 Rust 物理步进和既有暂停／单步／重置。窗口内计算细胞与机器人的局部流体反馈，窗口外继续网络解析驱动。

首个窗口建议中心 `(-14, 0)`、边长 16 游戏单位、网格步长 0.25，覆盖出生点与分流节点。细胞直径约占 5.6 格，接近此前 5.76 格的研究精度。该布局是本方案建议，不把 6 ms 直管计时当作接入后的保证。

## 求解选择与取舍

保留准稳态 Stokes、交错 MAC 网格、压力 Schur-CG、f64、点力欠松弛与压力初值复用。固定地图需要改变速度算子，原周期直管的 FFT/Thomas 逆不再适用。

建议速度子问题采用**固定带状矩阵的 Cholesky 分解**：构建时分解一次，运行时用前代和回代求速度；u/v 分量分别处理。规则网格按行编号保留有限带宽，不构造全量稠密逆矩阵，不增加外部求解库。其优点是每次速度逆保持固定、线性和对称，便于继续使用原压力 Schur-CG；代价是实现与内存访问比原一维 Thomas 更多，初始化及运行性能需要新测量。

不推荐直接退回嵌套速度 CG：旧 64² 局部受力对照曾测得完整求解均值约 114.74 ms，且内层按容差停止使外层作用不再严格是固定线性算子。该历史测量不是新窗口性能预测，但足以排除未经验证就直接实时接入的做法。依据见[原实验](../../research/2026-10-22-mac-stokes-experiment.md)。

保留原 FFT 再用罚力近似墙面，需要另外选择罚力强度、壁面漏流和开放边界处理；目前没有证据说明它能以更小成本满足本次真实分叉窗口的目标。首轮不同时引入这条路线。

## 地图与边界

- 由现有 `MapDefinition` 的通道并集识别流体格，考虑当前碰撞墙厚。首轮采用阶梯近似，不宣称斜壁具有与矩形同样的二阶精度，也不增加 cut-cell。
- 固液界面的法向面速度固定为零，切向黏性项使用与无滑移一致的 ghost 处理；不能只在旧矩形解后把墙内速度清零。
- 窗口周界与血管相交处为开口。外部压力由对应管段节点压力沿中心线插值提供，以 Laplacian 黏性形式的自然牵引 `(μ∇u−pI)n=−p_ext n` 施加；保留开放面速度未知量，不同时强制内部边界压力与零法向速度梯度，不使用周期回绕连接不同开口。这是选定的开口近似，不宣称等价于完整对称应变率应力边界。
- 二维局部场独立满足散度约束；不强行同时指定全部开口压力和流量。实际开口流量与圆管网络预期可能有差别，首轮报告差别，不把局部结果反馈成全局阻力。
- 按相同黏性能量和边界半控制体权重装配对称速度矩阵，梯度与散度在同一加权内积下互为负伴随。开放连通域的压力参考由外部压力载荷确定，不沿用旧周期求解器的压力去均值投影。首轮构建时拒绝无开口的流体连通块，明确报错，不增加封闭腔压力规范或恢复机制。

初始建议使用研究等效局部黏度 1。圆管与平板直管的均速公式不同，开口压力可从 `3 μ_local / (8 μ_network)` 的比例开始校准；这是直管匹配起点，不保证分叉的流量比例。固定几何、固定阻力、单泵标量允许预求单位泵压下的背景局部场，随后按脉动压力缩放。

## 受力与窗口衔接

沿用每细胞四内部标记，采样与散布共用权重，同一份标记力反向以冲量返还 Rapier。细胞面积约束、材料、节点数和机械子步不变。机器人仍以原移动目标速度控制，在此基础上接受局部流体扰动；推进次序固定，不能在回传后再覆盖该冲量。

每个机械子步更新一次局部流场与反馈，按该子步 `dt` 回传冲量；默认仍为每帧两次，不改成每帧只更新一次流体。

研究 Γ=0.25 与旧速度松弛率 20 不是可直接互换的参数。首轮从研究弱反馈强度开始，在带背景血流下观察细胞跟流速度；不能为维持旧手感未经验证就把反馈阻力放大 80 倍。

窗口外围设置少量空间过渡距离：解析驱动与局部耦合按位置权重分摊，不能把两套完整驱动同时施加。同一细胞的历史点力按现有细胞索引保存；退出窗口清零，进入时从零开始并渐增权重。当前固定数量的细胞不新增通用实体身份或生命周期框架。

## 模块与依赖

| 部分 | 本次责任 |
| --- | --- |
| simulation 内部 `fluid` 模块 | 固定网格与管壁、速度分解、压力求解、标记采样／散布及局部字段 |
| simulation 的 runtime | 网络更新、收集物体状态、选择驱动权重、施加冲量、唯一 Rapier 步进 |
| circulation 与 map | 提供图压力和同一地图，不由流体另造分叉几何 |
| godot_bridge 与 Godot | 转换快照，显示窗口范围及流向，不持有第二套模拟状态 |

内部接口建议为构造固定域、按当前泵压和标记状态求一步、按世界坐标采样速度、返回物体反冲量及少量调试统计。Rust 类型、数组布局及文件拆分属于实现细节；不建立可插拔求解器框架。

正式代码不依赖 `docs/research` 路径。沿用 Rapier 0.36.1、Rayon 1.12.0；把已批准的 Rapier `parallel` 用于该接入试验，线程池按应用生命周期复用并限制线程数，不能在每次重置时调用一次性全局池初始化。

## 实施与验收边界

1. 先验证固定几何求解：直管与独立解析值、零压差静止、分叉开口净流量和固壁零通量；检查原方程真残差。
2. 再接真实细胞与机器人，检查反冲量、有限值及窗口内外驱动没有重复全量施加。使用少量有针对性的检查，不建立大型新测试框架。
3. 运行已有项目检查与短时真实模拟探针，分别报告初始化、流体、Rapier 和整步时间。画面最多截图，不自动输入或操作 UI。
4. 若速度分解或压力迭代无法满足试用成本，报告实测后停在数值原型，不擅自换物理模型、GPU、FFT 库或大型预条件器。

本方案确认后，实施固定窗口接入试验。成功依据是现有世界中可观察到局部受力与分流、无明显数值异常，并如实报告实际成本；不要求复现原周期直管的 6 ms，不承诺严格膜封堵或原有手感完全不变。

## 只读可行性检查

独立 builder check 认为上述自然牵引与统一权重可使 u/v 独立带状对称求解与压力 Schur-CG 相容；速度连通块仍须具有无滑移约束以保证正定。已补齐开放压力参考、拒绝无开口连通块和机械子步更新频率。该检查是设计审查，不替代实现后的数值与性能验证。
