# 白细胞行为与免疫警觉度草案

日期：2026-10-30。状态：用户于本轮确认墙边入场方案并授权实施；具体试玩参数可按实际效果局部调整。

用户已选定第一种白细胞以贴身接触攻击为主，并要求加入类似 GTA 通缉强度的“免疫系统警觉度”。本次进一步按用户反馈，将高警觉时的通缉式识别纳入试行方向，并提出“高警觉＋发现玩家”触发的局部增援方案。墙边入场按管腔侧合法生成的游戏化方案实施；下文数值为试玩起点。

## 目标与范围

让玩家能感受到中立巡游、制造损伤后的局部响应、追逐、拥堵中的围堵，以及停止制造损伤后的压力回落。白细胞与红细胞、机器人共用现有物理，交通与地形影响追逐结果。

首版只有红细胞和一种游戏化白细胞。白细胞参考单核细胞的血管内巡逻，以及中性粒细胞的接触、吞噬尝试和局部杀伤；不将这组混合行为宣称为某一种真实细胞的完整模型。免疫警觉度是游戏抽象，并非人体存在的单个生理指标。

不加入浓度场、全图寻路、包抄队形、事件总线、完整血管穿越模拟、额外细胞亚型、完整吞噬、抓取关节、强制减速、NET、远程攻击、碎片、自然衰老或免疫细胞繁殖。不安排性能研究、云实验或扩大 UI 自动测试。

## 方案与取舍

### 警觉度与目标识别

| 方案 | 行为 | 取舍 |
| --- | --- | --- |
| 全局警觉度＋局部识别（此前建议） | 全局变量调节感知范围和追击记忆；白细胞仍需局部证据认定机器人是威胁 | 保留“发现损伤不等于知道攻击者”的既有方向，便于理解局部因果；远处白细胞不会仅因数值上升就攻击机器人 |
| 高警觉时共享通缉身份（本次试行方向） | 警觉度至少 50 时，任何白细胞在自身感知范围内遇到机器人都能认出它 | GTA 感更强，逃离一场冲突后仍可能再次遇到追捕；这是目标身份识别的游戏抽象，仍不共享实时坐标 |

本次试行建议：警觉度低于 50 时，沿用局部证据识别；至少 50 时允许白细胞在自身感知范围内识别机器人身份。没有感知到玩家时只能调查已知位置。警觉度跌回 50 以下后，未参与冲突的白细胞恢复局部识别规则，正在追逐的个体仍按自己的感知和记忆结束追逐。这里共享的是可识别的威胁身份，不是实时位置；不另加一份全局通缉名单或等级状态。

### 移动与攻击

建议采用二维平面中的爬行近似。相较严格限制在管壁上活动，它更容易与当前管腔中央的机器人发生推挤和追逐；这是空间压缩的游戏选择。白细胞受血流和碰撞影响，也有自主推进，不能直接修改位置来追上玩家。

首版采用持续接触后造成伤害。相较立即碰一下扣血，它有可读的准备过程；相较真正包裹吞噬或物理抓取，它不需要新的身体拓扑或约束机制。短程分泌与捕网留到其他版本分别讨论。

## 免疫系统警觉度

### 状态与增减

Rust `Simulation` 持有全局 `immune_alertness`，范围为 0～100，开局及重置为 0。另保存距上次玩家造成有效损伤的模拟时间，用于自然回落；无需按区域保存一套警觉度。

建议先使用以下记分起点：

| 玩家造成的结果 | 警觉度增加 |
| --- | --- |
| 红细胞受伤 | 每实际损失 1 点生命值，增加 0.04 |
| 红细胞从存活变为死亡 | 额外增加 4，一次结算 |
| 白细胞受伤 | 每实际损失 1 点生命值，增加 0.12 |
| 白细胞从存活变为死亡 | 额外增加 10，一次结算 |

例如，红细胞生命值为 100，受到两次 50 点攻击后死亡，总共增加 `2 + 2 + 4 = 8`；对只剩 20 生命的红细胞造成 50 点攻击，按实际 20 点伤害计分。空挥、攻击尸体、普通碰撞和推挤都不增加警觉度。白细胞攻击机器人也不增加或刷新该数值，避免交战本身不断制造升级反馈。

玩家连续 6 个模拟秒没有造成新的有效损伤后，警觉度以每模拟秒 2 点下降，最低为 0。局部追逐本身不阻止下降；已经识别机器人的白细胞仍按自己的感知和记忆行动。暂停冻结警觉度及安静计时，单步只推进一个固定步。

### 影响范围

警觉度连续影响感知距离与失去目标后的记忆时长；达到 50 后额外启用上述通缉式识别及局部呼叫增援资格：

```text
q = immune_alertness / 100
感知半径 = 6 + 4 × q
失去目标后的记忆时长 = 2 + 3 × q
```

感知半径按双方中心距离做候选筛选，再由固定血管壁遮挡检查决定能否感知。该检查是游戏近似，不模拟生物视觉或化学浓度。

HUD 显示“免疫警觉度 0～100”及简单强度变化即可。若显示平静、警戒、高度警戒等文字，它们只解释连续数值，不建立另一套有状态等级。警觉度不增加攻击伤害、生命值或移动速度；只有达到阈值且实际发现玩家后，才允许尝试有限增援，见下节。

警觉度不提供目标坐标或全图事件历史。高警觉时可识别身份，仍须通过自身局部感知获得当前位置。仅通过感知、调查或追逐不会自行刷新最后一次损伤时间。

## 局部刺激与目标识别

白细胞起初对机器人中立，红细胞始终作为正常交通参与者。发现可疑现场和识别攻击者分开处理：

| 局部情况 | 反应 |
| --- | --- |
| 机器人正常路过或推挤细胞 | 低警觉且没有局部敌意时继续巡游；警觉度至少 50 且实际感知到机器人时可识别并追逐 |
| 白细胞直接受到机器人攻击 | 立即识别机器人并接近反击 |
| 同一次攻击发生在感知范围内，白细胞能感知受击位置和机器人 | 将机器人作为当前威胁 |
| 能感知受击位置，但机器人被固定墙遮挡或已超出感知范围 | 只记录事发位置，短暂调查，不获得机器人身份与实时位置 |
| 未感知到本次事件 | 不获得事件位置或玩家坐标；高警觉时仍可在之后自行感知到机器人时识别其身份 |

伤害由现有 Rust 近身攻击结算。协调器在有效伤害发生时，将来源、受击位置与结果直接交给附近白细胞判断；无需建立通用事件分发框架。感知范围使用本次伤害结算前的警觉度，先处理所有局部响应，再汇总并增加警觉度，避免同一攻击命中多个细胞时受遍历顺序影响。

无身份的事发位置最多保留 3 个模拟秒；到达其附近后结束调查。已有追击目标优先于新出现的无身份事件。首版只保留一个当前事发位置，也不让白细胞递归传播警报。

## 移动规则

白细胞使用与红细胞相同的封闭软体构造，保留十二个边界节点。可见外形和颜色区分类型。建议首版放置 4 只，生命值 150、半径 1.0；这些为试玩参数，不是生物测量。

| 情况 | 运动意图 |
| --- | --- |
| 巡游 | 以约 0.6 单位/秒的自主速度，沿一个持续方向缓慢移动；每约 2 秒轻微调整方向 |
| 调查 | 以约 2.0 单位/秒靠近事发点 |
| 追逐 | 以约 3.0 单位/秒接近当前能感知的机器人；玩家默认自主速度为 4.0 |
| 失去感知 | 停止读取机器人坐标，向最后感知的位置继续移动；到达该处附近或记忆耗尽后恢复巡游 |

朝向在约 0.3 秒量级内转向期望方向，避免帧间瞬间掉头。追逐时的记忆时长，在每次确实重新感知目标时按当时的警觉度刷新；失去感知后只倒计时，不因全局数值变化重新延长。

失去感知后的追击因到达最后位置或记忆耗尽而结束时，清除这只白细胞本次追逐的局部身份与位置记忆。警觉度低于 50 时，再次遇到机器人需要新的局部攻击证据；警觉度至少 50 时，再次自行感知到机器人即可重新识别追逐。曾经直接受击也不形成独立的永久仇恨记录。调查结束同样清除事发点。

自主运动在机械子步中生成有限的推进响应，保留物理约束与接触结果；现有流体驱动继续存在。首版沿用当前流体拖曳/耦合规则，不额外模拟壁面黏附，不把流场速度直接清零，不给白细胞“穿过红细胞”的能力。3.0 指自主运动意图，实际世界速度由流体与碰撞共同决定，不作为跨流体模式的精确速度保证。

受红细胞、同伴或墙壁阻挡时，先允许出现挤压、滑动和堵塞。第一版不加脱困状态机或局部路径搜索；人工试玩确实发现持续顶墙后，再提出针对性调整。几只白细胞各自接近目标，依靠身体尺寸和碰撞产生围堵，不预分配包抄位置。

## 贴身接触攻击

机器人需要生命值才能接收伤害，建议初始 100。第一版不加入护盾、无敌帧、恢复、额外资源或受击强制位移。

攻击只对已识别的机器人生效。用机器人圆形到白细胞实际软体轮廓的最小间距判断接触，容差取现有表面厚度加小余量；同时沿用固定墙遮挡规则。不能用两者初始半径之和代替当前软体形状，也不能隔着红细胞仅凭中心距离扣血。

建议的第一组时间和伤害参数：

- 连续接触 0.3 模拟秒完成准备，再造成第一次 8 点伤害。
- 维持接触时，每隔 0.6 模拟秒再造成一次 8 点伤害。
- 接触中断、目标不可感知或白细胞死亡时，准备进度清零；攻击冷却继续按模拟时间下降，重新接触不能绕过冷却。
- 同一只白细胞同一时刻只结算一次伤害，不按接触点或粒子数量重复扣血。多只白细胞的攻击独立结算。
- 白细胞在当步被玩家击杀时，当步不再攻击机器人。

表现上用身体颜色/收缩或短闪光表达准备和命中。玩家仍能正常推进、攻击或尝试挤出接触；不增加强制减速或抓取约束。机器人生命归零后停止本次现场推进并显示损毁提示，R 重置后恢复；普通暂停/继续不能使机器人复活。

白细胞死亡复用已确认的变软、变瘪、随流、保留碰撞和 6 秒清理规则。首版不将白细胞尸体自动变成新的持续警报源。

## 高警觉时的局部呼叫增援（新提案）

### 触发与信息

建议以警觉度至少 50、白细胞存活并实际感知到已识别的机器人为呼叫条件。连续维持感知 1 个模拟秒完成一次呼叫，用细胞闪动或局部脉冲提示。完成前失去感知或死亡就中断；不能在玩家已离开后继续读取其坐标。

完成呼叫时记录一次玩家的最后感知位置。增援先前往该位置，再依靠自身感知追逐；呼叫不会为全体白细胞持续更新玩家坐标，也不建立持续广播或浓度场。

建议每次成功呼叫只增加 1 只白细胞，共享 8 秒呼叫间隔，现场白细胞身体上限为 8（包括尚未清理的白细胞尸体）。达到上限、没有合法入场位置时本次不生成、不排队，等待正常下一次呼叫机会；冷却与呼叫资格检查由协调器统一处理，避免同帧多只白细胞同时突破上限。完成一次尝试即消耗共享间隔，普通视觉提示不等于保证生成。原有 4 只与增援使用同一套身体、生命、行为及死亡规则。

这些间隔和上限用于明确增援节奏与场景规模，不引入预约、任务队列或请求恢复机制。被击杀的白细胞数量清理后会空出名额，高警觉且持续被发现时可再次补充。

### 从哪里出现

白细胞能穿越血管壁，但常规炎症招募的主要方向是“血液 → 血管外组织”。血管外组织返回血管的逆向穿越确有观察，涉及特定炎症/损伤环境，不能据此把任意管壁描述为常规增援出口。骨髓中的释放入血又是另一种特定部位过程。

| 入场方案 | 表现与取舍 |
| --- | --- |
| 上游或支路驶入 | 增援本来就在血中，从已有血管通路接近；空间关系较自然，但到场较慢 |
| 管腔侧贴壁位置出现，表现为从壁面挤出（已确认的游戏化方案） | 保留用户希望的墙边增援效果，明确将未模拟的储备/动员压缩成入场表现；不宣称任意组织中的白细胞通常都会反向穿壁入血 |
| 真实组织侧穿壁 | 需要组织空间、穿越位置和选择性通行规则，超出当前封闭血管地图与局部物理边界 |

推荐方案只在管腔内的合法贴壁位置创建完整软体，先沿壁出现提示，再向管腔内推进；身体必须完整位于可通行区域，并与机器人及已有身体留出间距。没有空位就跳过本次，不在玩家身上或已有细胞内部生成。

墙边出现的视觉效果不要求在物理墙上打孔、暂时关闭碰撞、把节点放到墙外再强拉进来，或修改流体固体边界。入场点优先取呼叫现场所在通路附近的可用管壁，具体候选查询和坐标交给实施者依据现有共享几何选择；不能隔着不连通的相邻血管只按直线距离选点。暂不新增地图存储格式或完整增援点编辑器。

### 生物学依据

- 中性粒细胞通过 LTB₄ 信号接力招募更多同伴，有活体实验依据；本草案用一次局部呼叫近似这部分效果。[Lämmermann 等，2013](https://pubmed.ncbi.nlm.nih.gov/23708969/)
- 黏附、管腔内爬行、穿壁并在组织中趋化是已观察的招募过程，主要方向为血管内到组织。[活体成像方法与观察，2011](https://pubmed.ncbi.nlm.nih.gov/21968530/)
- 逆向穿壁进入血液存在，但在该研究中与缺血再灌注损伤及 JAM-C 改变相关，不能作为任意管壁正常招募的说明。[Woodfin 等，2011](https://pmc.ncbi.nlm.nih.gov/articles/PMC3145149/)

## 状态归属与现有代码衔接

这是实体行为、局部反应与 HUD 的一组内容功能，沿用 Rust → bridge → Godot 的既有边界，不新增依赖或独立物理世界。

- 共用 `Cell` 继续保存身份、身体、生命和死亡时间。加入红/白类型；仅白细胞拥有运动方向、当前目标或事发点、记忆/调查时间、接触准备和攻击间隔。
- `Simulation` 保存全局警觉度、安静计时和机器人生命。伤害、局部响应、白细胞意图、机械推进及死亡清理由协调器安排；白细胞不自行修改 Godot、地图或流体内部状态。
- 本帧顺序建议为：清理/更新生命与计时 → 读取已有局部信息并生成白细胞推进意图 → 机械与流体子步 → 玩家攻击结算及局部刺激/警觉增加 → 活白细胞接触攻击结算 → 快照。这样保留现有近身攻击在物理推进后结算的时点，同时保证死亡白细胞不补打一击。
- 轮廓快照继续保留。按同序显示元数据增加细胞类型与必要的准备提示，新增机器人生命和警觉度显示；行为的权威状态仍只在 Rust。
- 默认世界开局放置 4 只白细胞，位置从可通行空间中选定，留足机器人和细胞间距；具体坐标由实施者结合现有小地图选择。重置恢复这组初始位置和生命。原 loop lab 不主动加入白细胞。
- `--local-cells` 的红细胞继续按数量抽象。少量白细胞保持单独身份及完整身体，纳入同一个 Rapier 世界，不汇总进红细胞数量池；第一版不为它们新增远场冻结、调度或重建机制。
- 现有流体代码有按统一 `cell_radius` 选择覆盖范围的入口。接入半径更大的白细胞时，须在现有适配位置使用各身体的实际尺度，不能仍把所有细胞当成半径 0.7；不改变 LBM 算法、机械子步数、节点数或默认后端。LBM 专用验证场保留原固定种群，以继续复现既有测量，默认不添加白细胞。

## 生物学依据与游戏化边界

1. 单核细胞沿健康内皮爬行巡逻有活体依据；本草案的自由二维运动是对活动表面的压缩。[Auffray 等，2007](https://pubmed.ncbi.nlm.nih.gov/17673663/)
2. 白细胞能探测局部孔隙、选择较容易通过的路径；本草案暂用主动推进和软体接触近似，不声称已经复现该机械感知。[Renkawitz 等，2019](https://pubmed.ncbi.nlm.nih.gov/30944468/)
3. 中性粒细胞对无法吞下的目标可铺展、扩大接触；它支持贴近与接触的表现参照，不提供“接触机器人便能造成固定伤害”的事实依据。[吞噬受阻实验，2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC9748254/)
4. 对抗体包被肿瘤细胞的反复膜摄取与机械损伤已有实验，但不能直接推广到所有目标或金属机器人。[Matlung 等，2018](https://www.sciencedirect.com/science/article/pii/S2211124718308635)

所有速度、感知距离、伤害、警觉分数和秒数均是试玩起点。普通红细胞损伤会触发本草案中的免疫警戒，是游戏规则，不等于任意真实红细胞清除都会触发炎症。
