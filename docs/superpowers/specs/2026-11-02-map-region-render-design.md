# 坐标区域地图示意图工具

用户已选择“单纯坐标”，要求实装供后续地图细节开发使用的基础工具。沿用已展示的独立命令行SVG导出方案，不做游戏内框选、区域预设或编辑器。

## 范围

- 新增 `simulation` 的 `map_render` example，仅构造 `MapDefinition`，不创建Simulation、GraphNetwork、Rapier世界、Godot或流体后端，不运行穿行。
- `--rect X Y WIDTH HEIGHT` 必填，使用世界坐标，Y向下；负坐标正常支持，宽高必须有限且为正。
- `--output FILE.svg` 必填；默认地图heart，可用 `--map heart` 或 `--map small-world` 选择已有定义。这是两项固定工厂选择，不新增地图注册机制。
- 可选 `--grid STEP` 按世界原点对齐网格并给坐标参照，`--labels`显示可见管段编号/内径及心腔名称。默认不叠加这些图层。标注保持简单，不做避碰排版算法。
- 输出完整SVG，采用实际心腔边界和定宽圆角管道，保持纵横比例及实际管径。默认画布长边约1200像素，局部很小时仍可读；像素设置是工具展示参数，不改变世界单位。
- 图形裁切必须包括穿过区域但端点在区域外的血管；不能按端点是否位于区域内决定整条管是否绘制。标签锚点落在可见中心线部分，SVG文本需转义。
- 非法/缺失参数、无法写文件时清楚报错并非零退出；提供help。过密网格用简单的清晰度/输出数量限制拒绝，避免无用海量SVG，不增加恢复或采样机制。

示例：

```sh
cargo run --release --locked -p simulation --example map_render -- \
  --rect -48 -150 288 390 --grid 16 --labels --output .worktrees/heart-detail.svg
```

## 实现边界

复用现有诊断图的SVG几何写入逻辑，抽到 `examples/support/map_svg.rs`，只供两个例子使用，不新增simulation公共接口或通用渲染框架。`heart_preview_probe`保留原有CSV、Q提示、三个固定区域、心脏域标记和全部移动/守卫行为；只替换重复的几何写入代码。

新工具只输出几何，不求解或标注流场。PNG预览沿用现有外部转换命令，不新增Rust依赖，不在CLI内绑定ImageMagick或引入服务器。命名区域、中心点选区、交互页面、持久化配置、热重载、实体布置、地图编辑及自动部署都不在本次范围。

## 验证

少量例子级测试覆盖参数/负坐标矩形、世界对齐网格和穿越视口的管段及标签。检查SVG真实输出，不检查源码字符串，不搭新测试工程；共享模块不重复放测试，避免两个例子各跑同一套用例。

运行新例子测试、fmt及workspace all-target feature编译。实际导出心脏、微管和小地图的坐标区域，使用XML解析与静态PNG查看；旧探针仅执行 `--diagnostics-only` 验证兼容，不跑长回放、Godot、GPU实验或全量模拟套件。产物及简短使用说明归档，用户未要求本阶段推送/合并。
