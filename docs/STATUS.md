最新云端验证见 [Vast.ai RTX 3060／Xeon 回放](research/experiments/2026-10-27-modular-mg/vast-rtx3060.md)：96 次 GPU 求解全部通过，两种配置交错测量。一次 V-cycle 的三规模均值约 57／95／124 ms，CPU LU 约 0.77／0.60／3.85 ms；本轮无新增 CPU 配额节流，仍不是独占宿主 CPU。GPU 仍明显慢于固定因子 LU，下一步先分段 profile 命令编码、提交、GPU 执行及审核。未改求解算法；Linux／Windows 后续动态 RHS 不全同字节，跨机对比限制已记录。

## 当前结论

**周期直管研究候选是有限阻力 Stokes + 点力欠松弛 ω=0.5，流体与 Rapier 各四线程，预测接触距离 0.002，复用压力初值并启用局部内核优化。** 该候选约 6 ms 的性能不覆盖真实分叉边界，尚未决定替换正式后端。接触距离针对直径 0.09 的研究细胞，不能直接照搬到直径 1.4 的正式原型。

最新匹配对照中，64²/64 细胞组合候选的流体均值两轮为 3.56 / 3.66 ms，整步为 5.92 / 6.06 ms，整步 p95 为 7.97 / 6.82 ms；原流体基线在相同 Rapier 参数下整步为 7.17 / 6.63 ms。正常每个机械子步仍只做一次完整流场求解。5 ms 整体目标尚未达到。共享主机存在明显长尾，不构成目标设备性能保证。

用户已确认当前约 6 ms 可以接受，本阶段先保留这一方案，暂缓进一步流体性能优化；不再为原 5 ms 目标自动追加实验或更换算法。

用户随后要求试接真实地图。固定窗口改用带状速度逆后，固定 CPU 2–5、72 细胞、60 步测得流体 48.336 ms、整步 59.249 ms（窗口仅 3–5 个细胞，另含机器人）；解析世界对照 8.376 ms。压力迭代平均约 37.33 次/帧，明显高于周期直管约 7.02 次。该数值原型不继承 6 ms 基线；按已确认设计暂缓 Godot 接入，不擅自增加其他求解路线。

分叉段的主要难题是通用边界下的速度逆成本及其在压力迭代中的反复调用。后续独立实验确认每帧 43.33 次速度逆，匹配 profiling 单次均值由带状 0.930 ms 降至稀疏 0.265 ms；严格容差下压力迭代仍为 37.33 次/帧。两轮主性能流体均值由 34.35–41.58 ms 降至 12.66–15.49 ms，整步由 43.70–51.49 ms 降至 22.11–26.65 ms。原方程与短测轨迹检查通过；不将旧 48.336 ms 都归给纯前回代，也不跨轮换算加速倍数。

用户随后提出游戏可降低精度。追加同一稀疏候选的压力停止参数对照：`1e-4` 将每帧压力迭代降至 15 次、流体均值 7.41–7.84 ms、整步 17.41–18.62 ms；一秒内细胞中心相对严格参照最大差约直径的 0.0031%，窗口开口最大相对流量不平衡约 0.006%。散度残差超出原严格阈值，不能称为通过原严格验收；正式参数未改。

后续 120 秒默认交通验证中，`1e-4` 窗口内实际反馈细胞为 3–21 个，速度与标记力没有持续增大，最大面积偏差约 3.370%（严格约 3.366%），无越壁。最大瞬时流量不平衡约 0.00841%，累计有向连续性缺口占累计流入约 −0.004585%；这只是通量诊断，模型未积累流体密度。累计上支路流体份额相差约 0.0963 个百分点，分叉细胞上／下通行为严格 44/16、候选 43/17。相同细胞 ID 的路径会明显分岔；30 秒同参数严格重放记录一致。该证据支持背景血流候选，不能证明玩家无法辨认、强操控手感或更长时间的表现。完整记录见[稀疏及容差报告](research/2026-10-26-stokes-sparse.md)。

最新热启动相对原冷启动的六秒最大中心差约为直径的 0.00126%，面积偏差和交换冲量诊断基本不变。原 ω=0.5 与自洽参照的最大中心差约为直径的 0.051%；这与本轮冷启动对照是不同误差口径。瞬时力律仍有残差和滞后，六秒低速轨迹不能证明长期稳定或普遍物理精度。模型只有每细胞四个内部阻力点，允许透流，尚未实现真实膜排液或严格堵塞。

镜头规模按用户描述是大几十至数百细胞，近景可为几十个。详细模拟数量、视野物理尺寸和预算仍需结合玩法确定；不可把此前小直径 packed-LBM 容量测量当成当前同大小 64 细胞的等精度对照。
